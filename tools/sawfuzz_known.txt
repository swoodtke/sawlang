# sawfuzz's XFAIL ledger (design 192 unit 3).

# A signature listed here is a finding that has been FILED as a DF and PINNED
# in examples/ with a cited XFAIL, and is not yet fixed. sawfuzz still reports
# every hit — the count is on the summary line — but does not fail the run for
# it, so the battery's fuzz lane stays a signal rather than a wall.
#
# The rules are the suite's XFAIL rules:
#   - an entry MUST cite a DF number, and that DF MUST have a pin in examples/
#   - an entry that no longer fires is STALE — delete it in the landing that
#     fixes the bug, exactly as you delete the XFAIL marker
#   - `--ignore-known` re-reports everything here, which is how you check
#
# Format: DF-NUMBER <TAB> signature   (the signature sawfuzz prints for it)
