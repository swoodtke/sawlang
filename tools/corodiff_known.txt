# DF-217p (reported 2026-08-13) — NEW, and the widest thing in this file:
# 61 cells of ONE mechanism. A frame-resident local in a driven body is
# released at FRAME TEARDOWN rather than at the end of the scope that owns it.
# Deterministic destruction is a language guarantee, so a resource held past
# its scope is a real behavioral difference and not a cosmetic one — the counts
# always balance, which is why this is DEINIT-ORDER and never LEAK.
#
# Two faces, both from the same cause:
#   - @ loop — a loop-body local survives into the NEXT iteration (and the last
#     iteration's survives the whole loop). Reaches essentially every binding
#     construct, which is what makes it a mechanism rather than a construct bug.
#   - @ linear — a scope that ends INSIDE the body: the replaced binding of a
#     same-scope redefinition (design 107 drops it AT the redefinition point),
#     an `if let`/`guard let` body's end, a `match` arm's end.
