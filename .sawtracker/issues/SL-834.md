## Description

**`while borrow var x = e { … }` is refused in typecheck** ("`syntax.expr.while.borrow` is not in the bootstrap slice yet"; found by p686, SL-686 step 1, Oct 23). The spec (the "Unwrapping an optional place says `borrow`" section) defines it: the loop runs while the place is present, the window is the loop body, and the head is evaluated again at each iteration after the previous body's window closes.

**Scope:**
- the typecheck slice;
- the MIR lowering on SL-686's conditional-lend machinery (`window_open_term`, the guarded `close_window`, `window_open_after`);
- pins: an accessor whose epilogue prints (it runs once per present iteration, and not at all on the absent exit), `break` and `continue` inside the body, an owning payload, a suspending body.

After SL-686.
