## Description

**Release v0.21.0** (user, Nov 8: bump the version once SL-956 lands, so sawos can pin past v0.20.0).

A two-line patch: `.sawtracker/version` becomes `v0.21.0`, and the driver's `driver_version()` becomes `"0.21.0"`. run.py's `version` step holds the two equal. The merge makes the server create the annotated tag.

**Since v0.20.0** (from the merged patches):
- **Init requirements in traits** (SL-966): `T(args)` and `Self(args)` through a bound; enum and primitive `init`s; strict `T()`; the `Allocator` unit rule.
- **Slices and range views** (SL-988): `&[T]`/`&var [T]`, `a[i..j]`, open ranges; `Vector.append(other:)` and bulk copy (SL-971).
- **Channels between threads** without an executor (SL-967).
- **A bare `borrows -> T`** is one error with a fixit, across modules too (SL-916).
- **A `match` on a lent place** closes its window at an arm that binds nothing (SL-956); `if let`/`while let` likewise.
- **A `--target-features` name** the target's clang doesn't recognize is a usage error (SL-995).
- **Also:** `var _` refused everywhere (SL-980), JSON keys in byte order (SL-976), EDF sleepers (SL-977), effect paths in sync refusals (SL-982), and the SplitMix64 hasher, among others (SL-970, 973, 983, 985, 987).
- **Seed** bumped to 6c79301d0 (SL-993).

**The seed bump (approved by the user):** after the tag, a second patch on this issue (SL-998.p2) pins the seed to the release merge commit, per SL-991's cadence. Further dispatches then wait for sawos's feedback.
