## Description

**sawc2's backend lowers no conditional borrow, so `SpinLock.try_lock()` (and `Vector.find`) cannot be built** (found porting SL-672).

`call_term` (`compiler/llvm/src/calls.saw`) refuses a `WindowOpen` call with an absent target: `backend.not-yet`, "a conditional borrow is not in the backend slice yet". Typecheck, MIR, borrowck and drops all accept the program; only the backend stops.

```
$ .build/sawc2 build --std-root std compiler/tests/run/spinlock_try_lock.saw
ERROR backend.not-yet compiler/tests/run/spinlock_try_lock.saw:11:33 a conditional borrow is not in the backend slice yet
```

**What it blocks:** every use of a `borrows -> &T?` / `-> &var T?` accessor: `SpinLock.try_lock()` (the spec's never-spinning acquire), `Vector.find`, `Map.find`, and `if borrow let` / `if borrow var` over any of them. corpusdiff already keys one program on it (`place_cross_module_same_name_type`).

**Pin:** the due run-lane program `compiler/tests/run/spinlock_try_lock.saw`, which becomes a stated probe once it builds.

**Air: the new acceptance row needs MIR work too, and the description says only the backend stops.**

The description says "Typecheck, MIR, borrowck and drops all accept the program; only the backend stops". That holds for `if borrow`, but not for the `borrow` block that `optional_generic_concurrency` writes. Probed on main's sawc2 (`air-review/sl686/` on the Air):
- `if borrow var p = arc.unique() { … } else { … }` stops in the backend: `backend.not-yet`, "a conditional borrow is not in the backend slice yet".
- `let r = borrow var p = arc.unique() { if borrow var p = p { p ?? -1 } else { -1 } }` (the corpus program's line 65) stops in MIR: `slice.not-yet`, "a `borrow` block binding a conditional lend is not lowered to MIR in the bootstrap slice yet" (`lower.saw`'s `not_yet` in the borrow-block lowering).

So a backend-only patch leaves this row refused. Either SL-686's scope grows to that MIR lowering, or the row moves to its own issue.

On main the program first stops at `import.unknown-module` (`std.channel`), so this row can't be checked until A13a lands.

**On the patch I'll check:**
- the absent path opens no window and runs no epilogue;
- the present path's epilogue runs on every exit;
- `try_lock` on a held lock returns `None` without spinning;
- both the `if borrow` and the `borrow`-block forms, at -O0 and -O2, with an owning payload dropped once.
