## Description

**sawc2's backend lowers no conditional borrow, so `SpinLock.try_lock()` (and `Vector.find`) cannot be built** (found porting SL-672).

`call_term` (`compiler/llvm/src/calls.saw`) refuses a `WindowOpen` call with an absent target: `backend.not-yet`, "a conditional borrow is not in the backend slice yet". Typecheck, MIR, borrowck and drops all accept the program; only the backend stops.

```
$ .build/sawc2 build --std-root std compiler/tests/run/spinlock_try_lock.saw
ERROR backend.not-yet compiler/tests/run/spinlock_try_lock.saw:11:33 a conditional borrow is not in the backend slice yet
```

**What it blocks:** every use of a `borrows -> &T?` / `-> &var T?` accessor: `SpinLock.try_lock()` (the spec's never-spinning acquire), `Vector.find`, `Map.find`, and `if borrow let` / `if borrow var` over any of them. corpusdiff already keys one program on it (`place_cross_module_same_name_type`).

**Pin:** the due run-lane program `compiler/tests/run/spinlock_try_lock.saw`, which becomes a stated probe once it builds.
