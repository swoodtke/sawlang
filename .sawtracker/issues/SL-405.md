## Description

## Follow-ups to the bootstrap subset checker

From the Air's approval of SL-399.p1 r6 (SL-399 c26; probes in chat file f5). None blocks, and each is small.

1. **An overloaded method's result goes untraced, even when the call picks one overload.** `Doc.cursor()` returns `Cursor` and `cursor(offset:)` returns `Int`, so `let c = d.cursor()` leaves `c` untraced. Cursor's own `peek`, `next` and `insert` are then refused as std calls (probe o1; Stage 0 prints `3 4 5 3`). Pick the overload by argument count and labels, and trace its result. `peek` and `next` are lexer and parser vocabulary.
2. **L18 (`generic-extension-params`) misses `extension Result {`,** which crashes Stage 0 with `internal compiler error: 'Result'` (probe g3). `sawc/std` does not declare `Optional` or `Result` as generic, so `is_generic_type` misses them. Stage 0 refuses `extension Optional {` cleanly.
3. **Cosmetic:** under the (line, rule, message) key, one `UnsafePointer` token draws two `raw-pointer` messages plus the `unsafe` one (probe d10, and the `raw-pointer.saw` fixture).
