## Description

**Forwarding a conditional lend with a direct `lend` is `slice.not-yet`** (found by p861, SL-861 step 1, Oct 23: 60 cells of its matrix, `scratchpad/p861/matrix_exp.tsv`).

`func fwd(&var self, i: Int) borrows -> &var Int? { lend self.inner.find(i) }`, forwarding an inner `-> &var T?` accessor straight through, is refused as `slice.not-yet` in every cell (any inner local, depth, epilogue or caller). The spelled-out form, `if borrow var x = self.inner.find(i) { lend x } else { return None }`, works (SL-861's matrix, once its fix lands). So the direct form is a lowering gap, not a rule: the forwarded window is conditional, and its presence must be carried through the outer lend.

**Scope:** lower a direct `lend` of a conditional accessor's result in a conditional accessor, with the absent path opening no outer window (the presence funnel `lend_subject` / `bind_optional_place`, SL-864). Pin SL-861's 60 cells, at -O0/-O2 with `// leaks: none`.
