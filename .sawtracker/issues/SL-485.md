## Description

**sawc2 has no declaration-side checks for `NoMove`.** Found by batch B1 (tcb1), which added the use-side `transfer.no-move` rule for SL-467's V53/V58/V59.

sawc2 accepts three shapes that Stage 0 refuses:
- a type that holds a `NoMove` value inline without declaring `NoMove` itself;
- `NoMove` used as a generic bound;
- `NoMove` declared without `NoCopy`.

Each is an `errors/nomove_*` program with no conformance row: in `examples/errors/` and its `tests/corpus/errors/` twin.

**Owed:**
1. Read the spec's `NoMove` rules and state the three refusals and their exact conditions.
2. Name the mechanism, which is the conformance-declaration check in typecheck.
3. Add conformance rows for all three shapes to `compiler/tests/borrowck/CONFORMANCE.md`, or wherever the `NoMove` rows live.
4. Pin one refusal fixture per shape, plus the accepted forms: a declared `NoMove` container, and `NoMove` with `NoCopy`.

Typecheck, batch B2.
