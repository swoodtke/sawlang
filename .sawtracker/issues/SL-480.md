## Description

**sawc2 and Stage 0 disagree in both directions on storing a function value into a struct field of function type.** Found by the SL-475 mir unit while writing the `drops/captures` golden, which avoids both shapes.

- **Over-accept:** sawc2 accepts storing a non-escaping `() -> Int` parameter into a field of type `() -> Int`. Stage 0 refuses it. A non-escaping closure may then outlive the frame it borrows from.
- **Over-refuse:** sawc2 refuses an `escaping` parameter `f: escaping () -> Int` stored into a `() -> Int` field. Stage 0 requires that spelling.

**Owed:**
1. Read the spec's rule on `escaping` and on function-typed fields, and decide which compiler matches it in each direction.
2. Name the mechanism: where sawc2 compares the escaping-ness of a function value against a storage position.
3. Sweep every storage position: a struct field, an enum payload, a `Vector`/`Optional` element, a static, a capture into an escaping closure, and a return.
4. Pin one fixture per row, accepted and refused.

Typecheck. Batch B2 or later.
