## Description

**A refusal quotes a const argument that begins with a parenthesis without its opening parenthesis.** Found by the reviewer of SL-1129.p1 (Nov 15, cell `paren_argument_misfit`, chat f161); v0.24.2 does it too. A misfit argument `v<(K + 1) / 2>` is refused with "the constant argument `K + 1) / 2` is 128": the quoted source text starts one token late, after the `(`.

**Likely mechanism (UNVERIFIED):** the text is taken from the argument node's first child's span rather than the node's own, or the span of a parenthesized expression starts at its inner expression. A sweep owes every diagnostic that quotes an expression's source text (`self.text(m, node)` on a node that can be parenthesized): a const argument, a length, a static's initialiser, a format argument; each probed with a leading `(`.

**Fix:** the quote spans the whole written argument. A refusal fixture per position the sweep finds wrong.

Related: SL-1129.
