## Description

**sawc2's typecheck reads a scrutinee that is a name bound THROUGH a reference as an owned scrutinee, so a by-value payload binding moves out of borrowed storage.** Found by the SL-475 mir unit (chat m407).

**The mechanism:** `scrutinee_origin` (`compiler/typecheck/src/bodies.saw`) reads any non-receiver local NAME of non-reference type as `TcOrigin.Owned`, with use `move`. That includes names that read through a reference:
- a `borrow let`/`borrow var` binding;
- an `if borrow let` unwrap binding;
- a `borrow let k` payload binding used as a nested scrutinee;
- a `[&x]` capture.

So the scrutinee and each by-value binding get `move`. `case Occupied(k) -> sink(move k)` over a `borrow let` scrutinee is ACCEPTED, while the same match over a `&Slot` parameter is refused with `transfer.move-from-borrow`. `tests/corpus/place_match_arm_move_in_literal.saw` (EXPECT error) is the same miss through a place scrutinee, `match v[0]`.

**The fix:** each of those names is a borrowed origin, classified as a reference parameter is (use `test`, by-value bindings borrow), so a consuming use of a payload binding is refused with `transfer.move-from-borrow`. Sweep every binding form that reads through a reference: the four above, a `for` head's lent element, a closure's reference parameter, and a place scrutinee (`v[0]`, `self.f` under `&self`).

**Pins:** one refusal fixture per form, the corpus file refused, and the accepted forms (a Copy payload read, a `borrow let` payload binding).

**After the SL-475 mir fix** such a `move` lowers to `move (*_K)`, which the new verifier invariant reports, so this typecheck rule is what keeps typecheck-clean programs invariant-free. Typecheck; it goes into batch B1 beside SL-474.
