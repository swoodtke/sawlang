## Description

Found by design 275 U4's disagreement sweep (obligation 4), probed on main at
46d6db9c and unchanged by U4, which is behaviour-preserving.

THE CAUSE NOBODY CLASSIFIED. The effect graph has FIVE kinds of suspension
source, not four: beside the cooperative primitives, the blocking extern, the
test-only `__saw_suspend` and the conservative closure call, design 223 unit 3
records ``a call through `any Trait` dispatch`` (typechecker/expressions.py, the
one site that produces that label). It is CONSERVATIVE — a vtable word carries
no effect, and `_report_existential_suspend_dispatch` refuses the dispatch
outright when some conformance body really suspends — so no frame is ever owed
for it. Design 223's own comment in `_effect_init` says exactly that.

The two predicates U4 replaced disagreed about it and always had:
`really_suspending` (design 206) struck it, `suspends_ignoring_closure_calls`
(SL-306) did not. The transform frames on the second, so a body whose ONLY
suspension source is an existential dispatch is treated as owning a park.

REPRO (main, 46d6db9c — `.build/scratch/probe_existential_frame.saw` in the
sl318u4 worktree):

    trait Greeter { func greet(&self) -> Int }
    struct A { n: Int }
    extension A: Greeter { func greet(&self) -> Int { self.n } }

    func via_existential(g: &any Greeter) -> Int { g.greet() }

    func root() -> Int {
        let a = A(n: 5)
        let x = via_existential(&a)
        __saw_suspend()
        x + 1
    }
    func main() { print(__saw_drive(root())) }

    error: coroutine transform: `g: &any Greeter` cannot be a parameter of the
    suspending function `via_existential`. A reference that spans a suspension is
    held in the frame as a handle to its referent (design 88), and an erased
    referent has no size for the frame to name. ...

`via_existential` suspends NOWHERE — every conformance of `Greeter` here is
sync, so design 223's refusal correctly does not fire — and the program is
refused anyway, by a fence about frames, for a frame it never needed. The
refusal is clean and located, so nothing is silently wrong; what is wrong is
that an ordinary erased-parameter helper cannot be called from a driven body.

MECHANISM (obligation 4): one cause classified by two predicates that were never
reconciled. U4 gives it its own bit (`SuspendCause.EXISTENTIAL_DISPATCH`) and
keeps it inside `frame_boundary`, because U4 is behaviour-preserving — the
membership is recorded in that derivation's docstring rather than settled.

FIX DIRECTION: move `existential_dispatch` into the conservative half —
`frame_boundary = cooperative | blocking | test_suspend` — so a body whose only
cause is a dispatch is not framed and not pulled into the driven closure. That
is a behaviour flip (a program refused today starts compiling) and it changes
which callees the closure walk visits, so it belongs with the discovery ledger
(SL-318 U1) or the totality unit (U2), not to the source unit. Design 223's
refusal at the dispatch is what keeps it sound: a conformance body that really
suspends is refused before any of this is reached.

PIN: `examples/coro_existential_only_body_is_not_framed.saw`, XFAIL citing this
issue, with the intended behaviour as its EXPECT directives, so the flip
validates the fix.
