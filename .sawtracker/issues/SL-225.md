## Description

The runner's own decoration (Colors class: progress symbols, section headers, verdict line) renders unconditional ANSI, so piped/captured output — the server's patch-test capture, redirected local runs, CI logs — is full of escape sequences. Fix: detect with sys.stdout.isatty() at startup and define the Colors constants as empty strings when stdout is not a terminal; honor NO_COLOR (force off) and FORCE_COLOR (force on) as overrides. SCOPE CARVE-OUT: compile_saw_in_process's documented invariant stays — captured COMPILER diagnostics (the reporter's spans, the ICE line at test_runner.py:626) remain byte-identical to the CLI subprocess so examples/errors assertion fidelity is untouched; only the runner's own decoration is gated. No consumer parses the colored strings (battery.sh and build.sh read exit codes).
