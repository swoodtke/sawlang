Stage 0 (the frozen Python compiler): widening an integer into an Optional argument or memberwise field ends in an internal compiler error. A let and a return of the same widening build.

Repro:
    func take(x: Int?) -> Int { x ?? 0 }
    let small: UInt8 = 7
    let a = take(small)

Error: internal compiler error (FunctionCall): Can only insert i64 at [1] in {i1, i64}: got i8. A memberwise field Box8(v: small) with v: Int? fails with 'cannot store {i1, i8}'.

Loud, and frozen per the Sep 24 freeze. Ledgered as SL:hazards L22. Found by the Air's SL-447.p2 probes. sawc2 types it as (widen Int) (some Int?).
