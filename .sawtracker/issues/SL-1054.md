**Design (user ruling, Nov 10; from SL-1049 F12).** `@caller_location` is an attribute any function or closure may declare. It tells the compiler that, inside that body, `#file`, `#line` and `#function` expand at the CALL SITE instead of the definition site.

**Why:** a std accessor's panic reports std's own line. `v[5]` panics with `panic at vector.saw:89: Vector.[]: index out of range: 5 (len 3)`, where the spec promises the caller's `v.saw:9`. The same holds for every checked accessor (Data, `String.byte_at`, `Duration.secs` …). Arrays and slices already report the caller, because the compiler emits their check inline. The spec's source-location literals (design 98) say "there is no caller-site capture … in v1"; this is that capture.

**The ruled shape:**
- **Implementation, not interface.** The attribute is not part of the function's type or signature, a trait requirement never mentions it, and a conformer may declare it on its own.
- **For any code:** user functions, methods and closures alike, not only std.
- **It recurses:** inside a `@caller_location` body the call site is itself the caller's location, so a chain of such functions reports the first frame up the chain that does not declare it.
- `panic`/`assert` take their location from those expansions, so they follow automatically. The compiler-inserted checks in the body (bounds, overflow, shift, the unwraps) should follow too. CONFIRM at brief time.

**For the brief to settle** (lead recommendations, UNVERIFIED):
1. **Indirect calls:** a function value, a `FuncPointer` or an `any Trait` dispatch gives the callee no caller. Recommendation: the literals fall back to the definition site there, and the spec says so.
2. **Compiler-synthesized calls** (subscripts, operators, `for` desugaring, `==` and the comparison operators): each passes its source expression's location. This is a position-quantified rule, so it needs a funnel with named entry points, or a position matrix (obligation 1).
3. **Lowering:** a hidden location argument, a pointer to a constant record, passed at a direct call to a declaring function. An undeclared caller passes its own site and a declaring caller forwards its own. Generics are per instantiation. Coroutines carry it as an ordinary argument across suspension. Freestanding-safe, no allocation.
4. **Grammar:** an attribute position on a closure (GRAMMAR.md has none today), and `@caller_location` joins the attribute set and `syntax.rule.attribute-position`'s message.
5. **std adoption:** every checked accessor that panics declares it (`Vector.[]`/`set`/`swap`/`swap_out`, `Data`, `String.byte_at`/`substring`, `Duration`'s constructors …).
6. **Spec:** "Source-location literals" gains the rule; the bounds-panic example `panic at v.saw:9` (§10, "The accessor rule") is pending on this issue.
