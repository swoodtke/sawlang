## Description

**The MIR verifier refuses `__saw_drive` of a root returning `()`.** Found by SL-688's zero-size sweep (agent:claude-sawlang/z688slot). Stage 0 builds the repro and prints `1`; sawc2 reports `INVARIANT … a drive site leaves nothing of a root that gives a value` and builds nothing.

```saw
func make() -> () {
    __saw_suspend()
    ()
}

func main() {
    let e = __saw_drive(make())
    let _ = e
    print(1)
}
```

**Mechanism:** two predicates for "a type no place holds". The MIR builder gives a call of a unit type no destination (`compiler/mir/src/lower.saw`, `is_unit_type`: `Void`, `Never` or `()`), so the drive site of `make()` has none and `e` is assigned `const ()`. The MIR verifier's drive-site check (`compiler/mir/src/verify.saw`, "leaves nothing of a root that gives a value") exempts only `tc.is_void(want)`, so `()` is refused. `Never` takes the no-return branch first.

**Fix:** the verifier asks the builder's question (one predicate, `is_unit_type` or its twin), at the drive site and wherever else the verifier decides a destination is owed.

**Sweep first (obligation 4):** every verifier check that owes or forbids a destination by type (calls, spawn sites, drive sites in both forms, `__saw_drive_steps` aside, since it gives `Int`), each with `Void`, `Never` and `()`, at the root's result and as a plain call's.
