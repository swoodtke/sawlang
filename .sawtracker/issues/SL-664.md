## Description

**Unit 3 of SL-661: move the runtime sources out of `sawc/`.**

sawc2 links its runtime from `sawc/rt/`:
- `build.py` runs `sawc2 runtime --rt-root sawc/rt`;
- `compiler/driver/src/main.saw` names it;
- the rt sources are `rt/ABI.md`, `common/`, `host_macos/`, `host_linux/` and `shim.c`.

So deleting `sawc/` would delete sawc2's runtime.

**Owed:**
- Move the runtime to a top-level home, with its history (`git mv`). A natural home is `rt/` or `runtime/`; say which and why.
- Repoint every reader: `build.py`, the driver, the run lane, `tools/linux.py`, the battery lanes (`abidoc` and anything else reading `rt/ABI.md`), CLAUDE.md, TESTING.md and `compiler/README.md`.
- Sweep every path that names `sawc/rt`, with grep plus a build of each consumer.

**The Python compiler's copy:** Stage 0 builds the same `sawc/rt/` with `--runtime-build`. Until `sawc/` is deleted, that compiler must still find its runtime. The unit either keeps Stage 0 pointed at the new home, or leaves Stage 0's copy in place and gives sawc2 its own. Say which. The tag's environment must stay buildable either way: Stage 0 at v0.13.0 is untouched by anything that lands after the tag.

**Depends on:** nothing.
