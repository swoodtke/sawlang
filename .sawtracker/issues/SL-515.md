Found by U5b3 (SL-456) while bringing up the new std's system modules. Under `--std-root std`, typecheck refuses every struct that holds a plain `String` field and declares no copy policy, with `copy.undeclared-policy` ("holds `T.f` of type `String`, which declares Copy, so it declares its own policy"). Under `sawc/std` the same structs are accepted.

**Mechanism.** `holds_declared_copy` in `compiler/typecheck/src/tier.saw` treats a field of any declared-Copy nominal type as a retain hook that an undeclared struct may not absorb (the `copy.undeclared-policy.retain-hook` fixture's rule). Under the new std, `String` is an ordinary std struct with a written `extension String: Copy` (U5b2), so it now counts as a declared Copy type. The spec's automatic Copy tier names a `String` field (and a `[T; N]` of one) as a member the compiler retains for you with no declaration owed, so the String lang item has to be excepted there. Under `sawc/std` String is the synthesized builtin, never declared, which is why no lane over `compiler/` saw it.

**Sweep (the mechanism's other positions).**
- An enum payload and a tuple or optional field never reach `holds_declared_copy` (only struct fields and fixed-array elements do), so they are unaffected.
- A `[String; N]` field goes through the same function's Array arm, so the same fix covers it.
- `Data` and `Arc` are declared Copy types in both stds, and the spec makes a field of either the containment error, so they keep the refusal.
- Escaping-closure fields are not nominal and never reach it.

**Evidence.** Against `--std-root std` with U5b3's std modules, `sawc2 typecheck --check` over the driver build (`compiler/driver/src/main.saw` with the stage packages) gives 20 refusals, all this rule: 18 compiler structs (`Token`, `LexError`, `Diagnostic`, each stage's `*Options`, `ResDiag`, `TcDiag`, `MirDiag`, ...) and the new std's `Path` and `SystemError`. With a three-line local fix, typecheck, mir, borrowck and drops all report zero refusals over the whole driver build:

```saw
        if info.kind == TcKind.Nominal {
            if info.decl == self.known.string {
                return false
            }
            let rule = self.tier_of_decl(info.decl)
```

**Wanted.** That fix (or the same exception where the tier table answers "declared"), a typecheck refusal/golden pair pinning a `struct { s: String }` with no policy as accepted under `--std-root std`, and the retain-hook fixture still refused.

U5b3 is blocked on it: `std.path`'s `Path` and the driver self-check lane cannot be clean until it lands. U5b3 does not edit `compiler/typecheck/`.
