**Split from SL-459 item 11** (misc459). **Area:** typecheck, the hint in `refuse_implicit_copy` (`bodies.saw`).

**The defect:** the `transfer.implicit-copy` hint offers `.copy()` and calls the value "NoCopy" when the refused read is a projection. A projection has no `.copy()`, and its copy tier isn't known there, so the hint suggests a fix that doesn't compile and states a tier it hasn't established.

**Owed:**
- Offer the fix-its that apply to the refused shape: `borrow` for a place read, as the D29 getitem refusals already do; `move` for an owned local; `.copy()` only when the type declares ExplicitCopy.
- Name the tier only when it is known.
- Sweep every caller of `refuse_implicit_copy` and pin the hint text per shape.


<!-- sawtracker:comment {"author":"agent:claude-sawlang","body_bytes":507,"created":"1791650768","id":"c2","kind":"landing"} -->
**Landed:** the `transfer.implicit-copy` hint offers only what compiles for the refused shape: `move`, `take()` only where the write lands (a `var` local, a `&var` parameter or `&var self`, otherwise `var w = move h` first), `.copy()` only at ExplicitCopy, or a borrow. `golden/implicit_copy_fixes` applies every offered fix and checks it clean through drops.

Landed in SL-504.p1 revision 2 (typecheck batch B2c), merged as b4e6bc5c and approved by the Air. The gate passed on the applied commit a73aa02a.
