**Drop the `keep-main` merge driver on `corpus_diff.tsv`: it silently discards a branch's recorded corpus moves on every rebase.** USER RULING (Nov 2): remove it; git's text merge, and a manual rebase when it conflicts, is fine.

SL-709 added `corpus_diff.tsv merge=keep-main` so a rebase takes main's measurement whole. The cost showed up repeatedly: a rebase drops every row the branch recorded, even when main moved different programs, and nothing says so until the server's corpusdiff gate reports "N programs moved" a full test cycle later. It hit SL-831.p2 r3 and SL-940.p1 r2 (20 FuncPointer rows dropped), and the Air's review clone (SL-720 c12).

**Why plain text merge is safe:** each program is one line. Independent moves merge cleanly and correctly; moves to the same or neighbouring lines conflict and stop the rebase, which is resolved by taking either side and re-running `run --baseline`. A wrong merge can't land: the gate re-measures every program. The server's clone was never configured with the driver (SL-709 c7), so it already merges as text.

**The patch:** remove the attribute and its comment from `.gitattributes`, delete `tools/git_setup.sh` (its only purpose), and rewrite the rebase paragraph in `compiler/tests/corpusdiff/README.md`. Each clone that ran the script removes its config with `git config --local --remove-section merge.keep-main`.

**Text merge does what the new README says.** I rehearsed on a copy of the real 2,676-row `corpus_diff.tsv` with the patched `.gitattributes`, in a scratch repo:
- **Different rows:** a branch moving row 500 rebased over main moving row 2000 exits 0, and **both** rows are kept. That's the case keep-main used to lose.
- **Adjacent rows:** a branch moving 1001 against main moving 1002 stops: `rebase` exits 1, `UU corpus_diff.tsv`.
- **The same row:** a branch moving 1500 against main moving 1500 stops the same way.

So a lost row is now a conflict, and never silent.

**Gates:** `battery.sh citations patchgate`: `exit=0`. The gate's own decision (`patch_gate.py --dry-run --diff`) runs compiler tests, fixpoint and corpusdiff for the README, which the server does.
