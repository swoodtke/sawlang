**Optional statics: the spec and sawc disagree, and `None` isn't a constant initializer.** Found by SL-940's census (`.build/scratch/p940/census.md`).

- **The "Never optional" rule:** sawc exempts an `unsafe static var` from it (its typecheck README says so), so `unsafe static var HOOK: FuncPointer<F>? ` is legal there; the spec states the rule with no exemption. One of them is wrong.
- **`None` in a static initializer** is refused as `static.not-constant`, though `None` is as constant as a value gets. A bare (zero-initialized) `unsafe static var` of an Optional field reads back `None`, so the only spelling that works today is the implicit zero.

sawos's boot hook is the motivating shape: a hook that starts empty and is filled at boot. SL-940 pins the working form, a `FuncPointer<F>?` field inside a bare `unsafe static var`.

**What a fix owes:** a ruling on whether an Optional static (or only an `unsafe static var` one) is legal, the spec text to match, and `None` accepted by the constant evaluator wherever a constant initializer is, with fixtures for each static kind.
