Found by SL-913's sawos sweep (p913, D1; reproduced by the lead on main 5393392b0).

A static named as a constant argument is classified as `slice.not-yet` (SL-884's feature) in an annotation and in a repeat count. In a constructor call's type arguments, `Slab<T, MAX>(…)`, it is refused as `type.not-a-type: `SLOTS` does not name a type`. That position skips the classification the other positions use.

Repro: `.build/scratch/p913/probes/const_arg_expr_position.saw`. One line holds three uses: the annotation and the third use get `slice.not-yet`, and the constructor's type arguments (col 41) get `type.not-a-type`.

Mechanism (obligation 4): constant-argument resolution has more than one entry, and the constructor-call position bypasses the shared one. SL-884's unit should route every position a constant argument can take through ONE funnel, with a position matrix, and close this with it. sawos has 13 sites in this position.
