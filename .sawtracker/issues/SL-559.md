**A6. Control flow, windows and expressions across a suspension.**
- **Scope:** §3.3's container, head and expression rows, plus the four lifted limits. Most of it is pins over the general CFG A3–A5 already handles. The new parts:
  - a window's state record resident across a suspension;
  - an accessor whose prologue or epilogue suspends, which embeds as a child (`window_open … suspends`);
  - collection `for` with a borrowing iterator.
- **Depends on:** A5.
- **Files:** `compiler/coro/src/lower.saw`, `compiler/tests/{coro,run}/`.
- **Pins:** every A6 row of §3.3; `lend_var_coro_and_forwarding`; the four lifted limits as run programs (`while_let_tuple_over_suspension_refused` and `coro_try_block_two_error_types` flip from refusal to run). Those four are marked `spec-derived expectation (no oracle)`, and their expected outputs are reviewed with the unit (t5). The spec's "Not yet supported" list shrinks in the same patch.
- **Done when:** all of them pass. This is the last unit before B1, so it should finish while frames are still unshared.
- **Estimate:** 1.5.

**Plan:** SL:coroutines §4, unit A6 (approved by the user, Oct 12). The plan text is authoritative; this issue is its tracker entry. Dependencies are named by unit id; see the epic's child list for their issues.

**Air, on the open question (the frame-value index refusal): A6's, not A18's.**
- **What it is:** `coro_indexes_frame_value` refuses a MIR `Index` projection whose *index local* is frame-resident, since a projection names its index by local and a local can't be a frame slot. That's a gap in coro's place rewriting, in `lower.saw`, the file A6 already holds. Its fix is mechanical: load the resident index into a stack temporary before the place, as A3c does for its token. A18's scope is the user-facing refusals the language keeps, in typecheck and resolve, and this has no language rule behind it.
- **How reachable it is today: not at all.**
  - `coro --check` at main over all of `tests/corpus` (2819 files) finds 0 programs refused with "an index read from its frame".
  - A straight-line `let i = pick(seed); yield_now(); arr[i]` (`.build/scratch/air-review/sl559/idx.saw` on the Air) isn't refused either; MIR evidently copies the index before the projection.
- **So for A6:** either build a shape that reaches it, pin it and lower it, or, if none exists, turn the refusal into an `INVARIANT` (an internal error naming the frame), not a user-facing `not-yet` that names a unit nothing schedules.
