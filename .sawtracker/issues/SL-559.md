**A6. Control flow, windows and expressions across a suspension.**
- **Scope:** §3.3's container, head and expression rows, plus the four lifted limits. Most of it is pins over the general CFG A3–A5 already handles. The new parts:
  - a window's state record resident across a suspension;
  - an accessor whose prologue or epilogue suspends, which embeds as a child (`window_open … suspends`);
  - collection `for` with a borrowing iterator.
- **Depends on:** A5.
- **Files:** `compiler/coro/src/lower.saw`, `compiler/tests/{coro,run}/`.
- **Pins:** every A6 row of §3.3; `lend_var_coro_and_forwarding`; the four lifted limits as run programs (`while_let_tuple_over_suspension_refused` and `coro_try_block_two_error_types` flip from refusal to run). Those four are marked `spec-derived expectation (no oracle)`, and their expected outputs are reviewed with the unit (t5). The spec's "Not yet supported" list shrinks in the same patch.
- **Done when:** all of them pass. This is the last unit before B1, so it should finish while frames are still unshared.
- **Estimate:** 1.5.

**Plan:** SL:coroutines §4, unit A6 (approved by the user, Oct 12). The plan text is authoritative; this issue is its tracker entry. Dependencies are named by unit id; see the epic's child list for their issues.

One caveat on the pin note (Air), for the lead's call: the substitutes don't all keep the shape. For A12b, an `Atomic` or a channel in place of `Mutex` does. For A6's collection-`for` row, an index loop over a `Vector` is a `while` loop, which §3.3's `while` row already pins. What that row adds is a lending `next()` window opened per iteration, its record resident across a suspension in the loop body, and an index loop has no window, so the row would go unpinned without saying so. Two ways to keep it honest:
- **(a)** add the `LendingIterator` trait to `std/prelude.saw` (a declaration; the new prelude has only `Iterator`) and pin the row with a user-defined collection plus borrowing iterator, as the spec's own `grid.cells()` example does. No `Vector.iter` port needed;
- **(b)** mark the row gated in §3.3 next to K149, so the census, not the run lane, tracks it until the port lands.

When A6 lowers a suspending accessor half, P08 should get a 'language changed' annotation in the census and run lane (it disagrees with Stage 0 by design), and its row in `examples/conformance/INDEX.md` should name the new covering test (obligation 3).
