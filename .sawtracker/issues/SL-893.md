## Description

**Found porting sawtracker to v0.18.0 (ST-97), at 4ab60f12c.** An unmarked `borrows` accessor call in a `for` head, whose result is a plain value (`len()`, an Int), keeps its window open over the whole loop body. So a `&var` of the root in the body is refused with `loan.window-root`.

**Expected:** compiles and prints 2. LANGUAGE_SPEC, "The `borrow` construct", says a borrow whose result is only a value closes as soon as the value is read.

**Actual:** `loan.window-root` at `touch(&var st)`: "`st` is borrowed exclusively here while the window of `as_array` opened at 25:17 holds `st.projects` shared until the window closes".

**Workaround in sawtracker:** none was needed. The marked head `0..borrow st.projects.as_array()!.len()` compiles, and so does a hoisted `let n = …`. sawtracker uses the marked form anyway, for SL-849. Once SL-849 makes the unmarked form a compile error, this may be moot: close it if so, but it would be worth a pin either way.

**Reproducer:**
```saw
// sawc 0.18.0 (4ab60f12c): an unmarked `borrows` call inside a `for` head
// whose result is a plain value keeps its window open over the whole loop body.
//
// Expected: compiles and prints 2. The head's `as_array()!` borrow yields only
// `len()`, an Int, so per LANGUAGE_SPEC "The `borrow` construct" ("A borrow
// whose result is only a value ... closes as soon as the value is read") the
// window closes before the body runs.
// Actual: loan.window-root at `touch(&var st)`: "`st` is borrowed exclusively
// here while the window of `as_array` opened at 25:17 holds `st.projects`
// shared until the window closes".
// The same head written `0..borrow st.projects.as_array()!.len()`, or hoisted
// to `let n = st.projects.as_array()!.len()`, compiles and prints 2.
import std.json.{JsonValue}

struct Store { projects: JsonValue, n: Int }
extension Store: NoCopy {}

func touch(st: &var Store) { st.n = st.n + 1 }

func main() {
    var items = Vector<JsonValue>()
    try! items.push(JsonValue.Number(value: 1))
    try! items.push(JsonValue.Number(value: 2))
    var st = Store(projects: JsonValue.Array(items: move items), n: 0)
    for i in 0..st.projects.as_array()!.len() {
        touch(&var st)
    }
    print("{st.n}")
}
```
