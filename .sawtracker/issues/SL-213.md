## Description

Unit D of SL-209 (ownership uniformity). Plan step 6. Depends on Unit A (explicit decisions must exist to migrate onto).

## Remove codegen's independent ownership guesses
`_transfer_needs_copy` (`sawc/codegen/resources.py:1564`) currently derives ownership behavior from expression SHAPES, place markers, and frame markers in addition to checker annotations — a second, independent opinion that diverges from the front end. Migrate each such case INDIVIDUALLY to the explicit checker decision (Unit A):
- During development, compute both the old shape-derived answer and the new decision, compare, and investigate every difference.
- Once a category is fully covered by explicit decisions, remove its shape/marker fallback.

Codegen still chooses HOW to implement a copy — bitwise copy, retain, or memberwise operation — but it must NOT decide WHETHER the program owes one.

## Acceptance
An unclassified transfer reaching codegen becomes an INTERNAL COMPILER ERROR before LLVM emission, never an implicit permission to copy. No `_transfer_needs_copy` shape/marker fallback remains for a migrated category.
