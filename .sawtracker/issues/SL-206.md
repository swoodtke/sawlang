## Description

Gating moved to sawtracker (Sep 2026): patches are tested and approved there before they merge to GitHub, so the GitHub Actions workflow should no longer trigger on push/PR — it duplicates the gate and burns runner minutes on already-approved merges.

Change: replace ci.yml's `on: push/pull_request` triggers with `workflow_dispatch` only. Manual runs stay available from the Actions tab while sawtracker's runner ramps up; the job definitions (test matrix, lexdiff, astdiff, irdet, freestanding QEMU suite) are kept intact so nothing needs reconstructing if a manual run is wanted or the decision is reverted.

This is the process change the Sep-8 session agreed: sawtracker is the merge gate; GitHub CI becomes manual-only.
