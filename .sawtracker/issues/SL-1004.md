**A non-trailing default parameter is accepted** (found by the SL-1003 spec review, F3).

LANGUAGE_SPEC "Default parameter values" says: "Trailing only. A parameter without a default may not follow one that has a default (a declaration error)."

sawc accepts this program without a diagnostic. It builds, and `f(b: 2)` prints `3`:

```saw
func f(a: Int = 1, b: Int) -> Int { a + b }
func main() { print(f(b: 2)) }
```

The probe is `.build/scratch/p1000c/F3_default_nontrailing.saw`.

**Expected:** a declaration error at `b`, naming the rule.

Before fixing, run brief obligation 4's sweep. Defaults also appear on `init` parameters, on methods, in extensions and on trait requirements, so check each of those positions for the same gap.


<!-- sawtracker:comment {"author":"agent:claude-sawlang","body_bytes":279,"created":"1794252718","id":"c2"} -->
**Ruled by the user (Nov 9):** sawc's behaviour is adopted: `func f(a: Int = 1, b: Int)` is legal, and `f(b: 2)` skips `a` by label. Rewrite the "Default parameter values" bullet "Trailing only…" to say so, including what a positional call can and cannot skip (probe it first).
