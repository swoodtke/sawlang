## Description

Found by the SL-345 implementer (Sep 24); present before SL-345. _check_static_method_call checks a closure argument as a non-call-argument, so a closure passed to a static method is treated as escaping even when the parameter type is non-escaping, and a reference capture is refused. Free functions and instance methods get the call-argument treatment. Sweep: static vs instance vs free; a generic static; an extension static on a primitive. It's the same funnel question as SL-345's call-exclusivity entry list, so the fix should route static calls through the same closure-argument path (and the SL-345 funnel then covers them).
