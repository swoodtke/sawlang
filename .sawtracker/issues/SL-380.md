## Description

Measured on main (e62b3164) with `.build/scratch/probe_flat_chain.py` in the lead checkout. The program is `let x = 1 + 1 + … + 1`, then `print("{}", x)`:

| terms | result |
|---|---|
| 100, 200, 300 | compiles; prints the right sum |
| 400 | `internal compiler error at …:2:291 (BinaryOp): maximum recursion depth exceeded` |
| 500, 2000, 5000, 12000 | the same ICE |

A left-associative chain parses iteratively and has constant source nesting, but its AST is a left spine as deep as the chain is long. Every pass that recurses over expressions pays at least one Python frame per term, and some pay several. The interpreter's default limit of about 1000 frames runs out somewhere between 300 and 400 terms. This is an ICE on an accepted program, not a clean diagnostic, so it violates "never hide errors" and the fuzz oracle's contract.

Context:
- SL-2.p2 (U0′) raises the interpreter limit to 10,192 the first time the parser's depth funnel charges a level. That moves this threshold for most real files, but not for a file whose parse never enters `nested()`. codex's c24 on SL-2 also measured a 12,000-term chain overflowing U0′'s own parser tree walks, which U0′ r3 makes iterative.
- The same shape: an `else if` chain (the If → else Block → If nesting) and long method or optional chains. The user flagged the 256-arm `else if` limit on Sep 24 as undesirable, and the lead proposed a flat representation for that chain.

Mechanism (obligation 4): a left-deep representation of a flat source construct, walked recursively by passes that assume tree depth tracks source nesting. Sweep:
- binary chains in every operator tier (`+`, `&&`, `??`, comparison chains where they are legal);
- postfix method, member and optional chains (`a.f().g()…`);
- `else if` chains.
Each is measured end to end for the length at which the compiler fails, and the pass that fails is named.

Fix shape, needs a design decision:
- (a) Walk chains iteratively in each pass. That is many passes, and each new pass reintroduces the risk.
- (b) Represent associative chains flat: an n-ary operand list and a flat else-if arm list, so that tree depth equals source nesting. Passes then iterate lists. This is the larger change, and the durable one.
- (c) A pass-agnostic guard: a structural chain-length limit with a clean diagnostic. Honest, but a real program can hit it.

The lead's recommendation is (b), sequenced after U0′ and SL-73, together with the flat else-if chain. The user rules on the shape.
