Found by SL-548 step 1 (probe c14g). A const parameter of type UInt/UInt64 cannot take a value at or above 2^63: a static argument is refused as type.mismatch ("the static TOP is 18446744073709551615, which does not fit Int, as a constant argument must") and a literal argument as slice.not-yet syntax.expr.int (also 9223372036854775807 for an Int parameter, the magnitude of Int.min). The constant-argument type (TcKind.ConstInt) stores its value in an Int. Both refusals are clean, nothing silent. Stage 0 builds the literal form for UInt (prints 18446744073709551615) and ICEs on the static form. Ruled out of SL-548 scope (lead, SL-548 Q5); SL-548 const_argument funnel renders the value at the parameter width, so admitting the bits later needs only the representation.
