**SL-716.p1: Data's public API in the new std, summary for review.**

- **Surface:** the surface matches Stage 0's signatures: `init()`, `init(capacity:) -> Result`, `len`, `is_empty`, `capacity`, both `[]` lends (shared read; exclusive write that separates first), `get -> Byte?`, `set`/`push`/`append`/`append_bytes`/`reserve -> Result<Void, AllocError>` (all-or-nothing), `pop -> Byte?`, `clear`, `byte_ptr`, and `slice`, an O(1) retained window via the new `offset` field. A write to a shared block separates it first, and `d.append(d)` is well defined, because the argument's retain forces the separation before the copy. `iter` is left out (SL-703).
- **Pins:** nine run programs match Stage 0 at -O0 and -O2: `data_simple`, `data_cow_slice`, `data_cow_value_semantics`, `data_cow_self_append`, `data_place_shared_read`, `alloc_data_reports_oom`, `data_set_oob_panic`, `data_index_oob_panic` and the new `data_pop_clear_raw`. The two oob-panic programs carry `// differs:` for the panic location.
- **The std MIR pin `data_spare.mir`:** one line changed, `copy length` → `Add(offset, length)`, because `spare()` indexes `offset + length` (std/data.saw:99). The relaxed load and acquire fence it pins are unchanged. This was a lead ruling.
- **Lint fixes:** five std-profile lints fired on the new code: four `root-reuse` sites (the length is now bound to a `let` first) and one `borrowed-match-payload` site (now a `relocated` helper plus `self = fresh`).
- **Corpusdiff (SL-666):** the baseline was re-measured over main with Arc. About 20 programs move to pass, among them the data_* programs, T25, W03, M41 and the import150 forms. The other rows now stop at later refusals: `iter`, `Path`, `fromBytes`, `threads:`, and five on unsigned `format`, which SL-711 lowers. One row moves to `wrong`: `alloc_data_push_forced_panics_named`, which is SL-729 (`try!` prints no error rendering).
- **Gate (Sonnet, under the lock):** `run.py --only resolver,typechecker,std,programs,coro` ok, `corpusdiff gate` ok (all 2661), citations green. The diff also applies on main after SL-717.p1, whose tsv rows don't overlap.
