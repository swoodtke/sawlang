## Description

**Finding (a9budget, while implementing SL-566):** sawc2 builds no value loop. A `break` that carries a value is `slice.not-yet` in typecheck, so `let r = while { … break v }` and a conditional value `while` (`T?`) are refused before MIR, suspending or not.

- **Mechanism:** `check_break` in `compiler/typecheck/src/bodies.saw` refuses any `break` with an operand (`self.not_in_slice(s, Alt.Stmt_Break)`, "a value is outside the slice"). Nothing downstream lowers a loop's value: MIR, the borrow check and drops never see one.
- **Reach:** every value loop. `compiler/tests/corpusdiff/corpus_diff.tsv` lists the corpus programs refused this way, among them `while_expr_infinite`, `while_expr_conditional_found`, `while_expr_conditional_not_found`, `for_loop_expr`, `range_inclusive_basics`, `conformance/V90_forwarding_fence_is_narrow` and `errors/coro_value_while_suspending_condition`.
- **What it blocks:** SL:coroutines §3.3's lifted limit "a value-producing `break` out of a spanning loop", which the A6 amendment moved to A9 (SL-566). In MIR it is ordinary blocks, so once the slice takes value loops the row should need no coroutine work; the run-lane probe is written and waits here. The spec's "Not yet supported" entry for it stays until then.
- **Repro:** `func f() -> Int { var i = 0; let r = while { i += 1; if i == 3 { break i } }; r }` gives `slice.not-yet ... syntax.stmt.break is not in the bootstrap slice yet`.

import std.task.*

func gate(n: Int) -> Int {
    yield_now()
    n
}

func first_square_over(limit: Int) -> Int {
    var i = 0
    let found = while i < 10 {
        i += 1
        yield_now()
        if i * i > limit {
            break i
        }
    }
    found ?? -1
}

func gated(stop: Int) -> Int {
    var i = 0
    let out = while gate(i) < 3 {
        i += 1
        if i > stop {
            break 7
        }
    }
    out ?? 0
}

func summed(rounds: Int) -> Int {
    var i = 0
    var total = 0
    let result = while {
        total += gate(i * 3)
        if i == rounds {

        }
        i += 1
    }

}

**Implementation detail (lead, Nov 12): a design pass (Opus) first; a loop's value crosses typecheck, MIR, the borrow check and drops.**

**The gap.** `sawc` builds no value loop: `check_break` (`compiler/typecheck/src/bodies.saw`) refuses any `break` with an operand as `slice.not-yet` (`syntax.stmt.break`). Fourteen corpus programs are refused on it (`while_expr_infinite`, `while_expr_conditional_found`, `while_expr_conditional_not_found`, `for_loop_expr`, `range_inclusive_basics`, `conformance/V90_forwarding_fence_is_narrow`, `errors/coro_value_while_suspending_condition`, …), and two spec sentences are marked pending on it.

**The language rule is written; the design is about the compiler.** LANGUAGE_SPEC (the loop-expression section; find it by `break` with a value and "value loop"): a conditionless `while { }` is its `break`'s value; a conditional `while` is `Some` of a `break`'s value and `None` when its condition ends it; a `for` likewise. "Value-branch arms are transfers" covers the `break <value>` arm. Read the whole section and quote the rules the design relies on.

**The design must settle, stage by stage:**
1. **Typecheck:** the loop's type from its `break`s (one type across every `break`, the expected-type path when the loop is an initializer or an argument, the literal-adoption rule across breaks, `Never` for a conditionless loop with no `break`); a valued `break` in a loop used as a statement; a valued `break` crossing a nested loop, a `match` arm, a closure boundary (refused), a `try` block; a labeled break if the grammar has one; the transfer at each `break` (move, copy tier, the checkpoint).
2. **MIR:** the value's slot, written on each `break` edge and wrapped (`Some`/`None`) for the conditional forms; scope exits on the `break` edge (locals of the body dropped before the jump, in order); a `break` out of a `borrow` block or a window (windows close first); the `for` forms, including a lending `for`.
3. **Borrow check and drops:** what a `break` carrying a borrow-derived value may be; drop elaboration of the body's locals on the valued edge; the verifier's "owned local not dropped at a scope exit" on that edge.
4. **Coroutines:** SL:coroutines §3.3's lifted limit "a value-producing `break` out of a spanning loop" (A9, SL-566): confirm that in MIR it is ordinary blocks and needs no transform work, with the probe in c1 (expected output 4, -1, 7, 0, 30, 4).
5. **The backend:** nothing expected; say so or say what.
