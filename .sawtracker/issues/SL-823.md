## Description

**Type aliases: two checks the closed Stage 0 issues DF-270b/c settled are missing in sawc2** (SL:hazards S9; the SL-425 sweep, c7; main and seed alike).

1. **Invariance (DF-270b, SL-49, closed for Stage 0):** `Vector<TokenKind>`, where `TokenKind` is an alias for `UInt8`, is accepted at a `Vector<UInt8>` parameter and when bound to a `Vector<UInt8>` `let`, and runs. A distinct alias is a distinct type, and generics are invariant, so the spec says refuse.
2. **Conformance signatures (DF-270c, SL-50, closed for Stage 0):** a conformance method spelling `Int` where the trait's requirement names the alias `Handle` is accepted; it should be validated as a mismatch.

The third S9 face, `Tag(Noisy(...))` over `type Tag = Noisy` being refused, is SL-744 (open).

**Obligation 4:** every position that compares two types structurally where an alias must stay distinct:
- generic arguments (in parameters, `let` annotations, returns and fields);
- conformance signatures (parameters, the return, receiver mode);
- overload resolution;
- `as` casts.

**Retires:** part of the subset checker's `type-alias` rule (with SL-744).
