**A standard wire encoding for enums, and through it a lossless nested Optional.** Deferred by the user (Nov 1): "Can we just do the simple Some / None case for now and revisit later when we have a use case?"

**Today:**
- A raw-backed enum serializes as its raw value.
- `@synthesize` refuses an enum with no raw backing or with a payload case.
- `Optional` is untagged (`None` → null, `Some(x)` → `x`), so an `Optional` whose payload is itself Optional loses `Some(None)`. The spec states that as a limit (SL-833 patch 3).

**The lead's proposal, when a use case arrives,** is serde's externally tagged shape over the seam's `begin_map`:
- a case with no payload is its name as text, `"red"`;
- a case with a payload is a one-entry map from its name to the payload, `{"circle": 2}`, with several payload values positional, `{"rect": [3, 4]}`, as structs are;
- a raw-backed enum keeps its raw value.

Optional keeps its null shortcut and falls back to the standard form only when its payload can itself be null: `Some(None)` → `{"some": null}`. That fallback needs a static "can be null" member on `Serialize`, false by default.

**Open for the user when this is scheduled:** case names or indexes, and the tagging style (external, or internal like `{"case": …, "value": …}`).
