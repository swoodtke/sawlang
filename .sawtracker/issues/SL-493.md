## Description

Found by SL-459's misc459 agent while checking item 3, which is closed as stale: aliases are transparent in sawc2 and fold at their underlying type.

**Defect.** sawc2's typecheck accepts a static initializer that is not a constant expression. Only the constant evaluator refuses it, and it uses `slice.not-yet` ("a conversion in `static m.A` is not evaluated as a constant in the bootstrap slice yet"), which reads as a slice gap. Under the language, the program is wrong: LANGUAGE_SPEC "The constant grammar" lists what a static initializer may be, and Stage 0 refuses each such static with "static `A` must be initialized by a compile-time constant". A user error belongs in typecheck, which is SL-459 item 12's class.

**Mechanism.** No typecheck check holds a static's initializer to the constant grammar. The fold (`compiler/typecheck/src/fold.saw`) answers `NotConstant` for anything outside it and never reports that. The evaluator then meets the construct in MIR and refuses it with its own `slice.not-yet` (interp.saw `rvalue`: `Conversion`, a call, an aggregate, `Interpolate`).

**Shapes seen.** The evaluator refuses each with `slice.not-yet`, and typecheck says nothing:
- an alias back-conversion, `static A: Byte = Byte(65)`, including in a `static_assert` (`static_assert(Byte(65) == 65, ...)`);
- a call (`T.from(truncating: x)` and any function call; "a call");
- an interpolation, as a String static's initializer.

Some aggregates over constants are legal by the spec ("memberwise aggregation"), so an aggregate refusal is a genuine slice gap and not this defect. The check has to tell the two apart.

**Fix site.** Wherever typecheck checks a static initializer: `check_static_value` and its callers in `compiler/typecheck/src/bodies.saw` / `checks.saw`, which are tcb2b's typecheck files. A refusal such as `static.not-constant` names the sub-expression that fails, as the spec asks ("the diagnostic names the sub-expression that failed rather than the whole condition"), at every position the constant grammar governs: a static initializer, a `static_assert` condition, a raw case value and an `@align` argument. Every position is one funnel or one matrix (brief obligation 1). The evaluator's `slice.not-yet` then stays only for the true slice gaps.

Probe: misc459 worktree `.build/scratch/alias3c.saw`.
