## Description

**`match v[0] { case _ -> … }` over a NoCopy element copies the element in MIR, which trips the verifier** (found by p852, SL-852 step 1, Oct 23; cell `scratchpad/p852/cells/getitem_wild_unused_nocopy.saw`, dump `wild_nocopy.mir`).

Typecheck accepts a `match` whose scrutinee is a getitem place `v[0]` of a NoCopy element and whose arms bind nothing (`case _`). MIR then copies the element out (`_9 = copy (*_10)`), and the verifier reports the INVARIANT "copies a `Tok`, which does not copy silently". Since SL-844 the command exits 1.

**Lean (the lead):** typecheck is right. A `match` on a place that binds nothing (or binds by reference) needs no copy, so MIR should match on the place, the way a `match` on a lent place stays by reference (SL-838's ruling). Confirm or overturn in step 1.

**Obligation 4:** scrutinee places {getitem, a field of a local, a `borrow` lend, a deref} × arms {`_` only, literals, a by-reference binding, an enum case with no payload binding, guards} × element type {NoCopy, NoCopy with `deinit`, String}. Each cell: compiles and runs with no copy and no leak, or the clean refusal where a consuming binding asks to move out of a place.
