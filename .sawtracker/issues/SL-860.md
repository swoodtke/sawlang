## Description

**A conditional lend whose prologue suspends is refused as `if borrow` or a copy-read, but works as `match`** (found by p859, the SL-859 sweep, Oct 23; repros in `.build/scratch/p859_evidence/a/a02r_cond_pro_refused.saw` and `iso/cond_forms2.saw`).

```saw
func find(&var self, i: Int) borrows -> &var Int? {
    yield_now()
    if i >= self.cells.len() { return None }
    lend self.cells[i]
}
```
- **Refused:** `if borrow var c = h.find(0) { c += 1 }` and `let c = borrow h.find(0)` give `coro.not-yet`: "a conditional borrow whose accessor suspends is not lowered yet (SL-545)". The refusal is raised by `coro_decide_frame` → `coro_refuse_item` in `compiler/coro/src/lower.saw`, pinned by `compiler/tests/coro/refuse/coro.not-yet.conditional-window.saw`.
- **Accepted, and correct under leaks and ASan** (sweep cell a08): `match h.find(0) { case Some(borrow var c) -> … }` and `borrow var h.find(1)! += 5`.

It's an implementation gap: the same window is already lowered through `match`. Under the user's principle (suspension is allowed unless it can't be done safely), the fix lowers every conditional-lend spelling through the path `match` uses, and retires the `coro.not-yet.conditional-window` refusal.

**Obligation 4:** every conditional-lend spelling {`if borrow let/var`, `guard borrow`, `let c = borrow …` copy-read, the block form, `match`, `!` force, `??`} × the accessor's suspension {prologue only, epilogue only, both}, at -O0/-O2 with `// leaks: none`.
