## Description

LIVE MISCOMPILES of safe code. Found by the SL-213 (unit D) census, NOT fixed
there: they are outside the four findings that unit batched, and SL-213's
dispatch rule is to stop and file a divergence rather than widen its own scope.

## The mechanism (obligation 4)

Four transfer boundaries decide "does this value owe a retain?" with an
**inline `isinstance(value, Identifier)` test of their own**, never consulting
the checker. They do not route through `_transfer_needs_copy`, so the
`needs_copy` annotation `_stamp_retain` wrote is simply never read at any of
them.

The shape test AGREES with the checker on a bare binding and DISAGREES on every
PROJECTION — a field, a tuple element, an indexed element — because a
projection reads storage its container keeps and therefore owes a retain, while
a bare identifier may be a move. So each site duplicates without retaining: the
copy aliases the source's buffers, and the first release frees storage the
other still holds.

This is exactly the DF-139a / DF-151h defect re-instantiated at the four
boundaries those two fixes did not visit. Both of those were the same test at
the `let` initializer and the assignment RHS, and both were fixed by routing
the site through the shared oracle. These four were never routed.

    _needs_copy_for_struct_init  TupleIndex@16:25  -> False   needs_copy=True

The checker decided `copy`, recorded it, and stamped the node. Codegen answered
False from a node-type list and duplicated without retaining.

## Fix shape

Each site reads the checker's answer instead of re-deriving one:
`_transfer_needs_copy` is the existing oracle and already begins with the
`needs_copy` arm. Sites 1, 2 and 3 can delegate to it wholesale; site 4's tier
gate is its own (a field type that owes a retain) and what it needs is for the
SOURCE test to stop being a node list.

NOT a one-line change to trust blindly: SL-213 measured that
`_transfer_needs_copy`'s isinstance tail is the ONLY answer inside monomorphized
generic bodies (design 219 wave C discharges the tier requirement at the CALL
SITES, so no `needs_copy` is ever stamped on an instance body's nodes), so
delegation must keep that arm reachable rather than replacing it with a bare
annotation read.

## Obligations the fix owes

- **Driven twins.** None of the four was probed in a suspending body. Design
  269's own lesson is that a sync matrix can look clean where its driven half is
  not, and the coroutine transform rewrites exactly these reads into frame
  reads.
- **Conformance rows**, one per boundary, with the heap-string oracle these
  probes use (a string LITERAL is immortal and passes vacuously — design 271's
  recorded gotcha).
- The tier axis: each row at the silent `Copy` tier (where the symptom is a
  refcount underflow) and at trivial (where nothing is owed).
