Landed as SL-475.p1 r2 (merge 92a91407), approved by the Air with the gate green.

**MIR no longer moves an owning value out through a reference:**
- a scrutinee read through a reference is matched in place;
- an escaping closure reads its captures in place;
- `[copy x]` runs the type's `copy()`, through the bound for a type parameter.

The four copy-instead-of-move rules go through `mir_copies_silently`. A type parameter copies only where a bound grants `Copy`.

**The verifier:** `verify_moves` refuses a move through a reference. The exemptions are an epilogue's record load and SL-477's take-once.

**SL-471:**

- the payload leak limit is stated and pinned;
- the flag-cleared verifier gap is closed, with a fixture.

`run.py` runs unit programs from the repository root.
