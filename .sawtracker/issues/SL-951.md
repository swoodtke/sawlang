**Blade idiom pass: the errors it still hides, and v0 shapes the current language replaces.** The SL-936 port kept v0's behaviour at every site; this is its optional U3 (survey `.build/scratch/p936/report.md`).

**Never hide errors:**
- `try! Env.get(...)` panics on a `SystemError`: `builder.saw` `compiler()`, `tester.saw` `compiler()` and its has-sawc check, `sosimg.saw` `sos_clang()`/`sos_ld()`, `tests/dep_build.saw`.
- `manifest.saw` falls back to `Path(s: ".")` when `Env.cwd()` fails, which hides the failure; `tests/git_local_repo.saw` and `tests/git_resolve.saw` use `try! Env.cwd()`.
- `git.saw`'s ls-remote turns `Command.output()`'s `Err` into `None` with `try?`, so a spawn failure reads as "no remote".

**v0 shapes:** `main -> Int` in place of `extern exit`; `Command` in place of `extern system`; `-c` for library builds (a library's `blade build` hits `entry.missing`); quieter git output.

Each change keeps the blade lane green (`tools/blade_lane.py`) and the error-path behaviour the Air checked on SL-936.p1 (a one-line `error:` and exit 1, never a panic).
