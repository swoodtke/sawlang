Child of SL-884: the first piece scheduled. **A constant argument named by a `static`** (`Slab<T, MAX>`, `[T; SLOTS]`, `FixedBuf<FRAME_VALUES>`) is typecheck `slice.not-yet` in sawc, and in a constructor call's type arguments it is mis-refused as `type.not-a-type` (SL-915, folded in here).

**Why now:** it blocks the sawos restart (SL-913's sweep: ~383 sites in 70 sawos files, 198 of 201 entries) and SL-865 U9 (the freestanding suite's shared `fsrt` module sizes its arena with a static). Corpus: K21, K22, K25, `coro_frame_over_65535_nonconstant_values`, `resolve_seam_offloads`.

**Obligation 1 (a funnel or a matrix):** route every position a constant argument can take through ONE funnel that resolves a static's value, with its entry points named. Position matrix, with a fixture per row: a type annotation, a constructor's type arguments (SL-915), a repeat count `[v; N]`, a generic function's explicit argument, an inferred `[T; N]` parameter, a field's type, a return type, an alias, a nested argument (`Ring<Slab<T, MAX>>`), and a static defined in another module (qualified and imported). The spec (const generics, design 148; statics) decides which statics qualify (a constant initializer only?) and what happens to a non-constant one.

Closes SL-915.
