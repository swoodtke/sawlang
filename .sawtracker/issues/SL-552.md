**Review note (lead): SL-552.p1, unit A1.**

**The mechanism.** A new `compiler/coro` stage sits between mono and llvm (`compiler/llvm/src/api.saw` builds through `coro_lower_file`). A0's fixpoint MOVES there: `compiler/mono/src/suspends.saw` and `MonoProgram.suspending` are deleted, and `compiler/coro/src/suspends.saw` is the one suspension decision. Its entry points are `coro_solve_suspension`, `coro_call_is_source`, `coro_call_suspends` and `coro_item_suspends`.
- **The seeds** are all decided in `coro_call_is_source`: a flagged call whose target has no body (it keeps typecheck's answer, so the unanswerable case suspends), or whose target's summary is declared rather than body-derived. The second case is how A2's park intrinsics, which have placeholder bodies, become sources with no further edit (the Air's seam on SL-553 c6).
- **The fixpoint** is solved breadth first from the seeds over the reversed edges, so each item is marked once and its cause chain is a shortest one.
- **Cycles:** one `coro.suspending-cycle` refusal per strongly connected component of suspending items (iterative Tarjan). It names the shortest cycle through the component's first item and is anchored at that item's declaration. The wording is Stage 0's.
- **`coro.not-yet`** replaces A0's two `backend.not-yet` refusals in `bodies.saw`: one per item that needs a frame, at the call its suspension came through, with the cause chain. It is suppressed when a cycle is refused.
- **Invariant:** `coro_check_summaries` fails (`INVARIANT coro`) wherever typecheck's summary is unconditional and the decision disagrees at some instantiation, or a closure is decided suspending. The agent injected a fault (externs made non-sources): it reported 4 disagreements and correctly spared `run<Slow>`, whose summary is conditional.

**Pins:**
- the coro lane (`compiler/tests/coro/coro_lane.py`, in `run.py` and in the fixpoint lane's LANES): 3 goldens (`effects`, `chains`, `cycle_without_suspension`), 10 refusal fixtures and the agreement check over 75 programs;
- the 8 recursion shapes of the corpus, adapted to a `blocking` extern because their originals need A2, A4, A7c and A8b, plus a 9th, `.generic`, refused at `Slow` and not at `Fast`;
- the Air's negative pin, `run/cycle_without_suspension.saw`: a plain cycle and a generic cycle with flagged calls that reach no source at `Fast`. It builds, runs and matches Stage 0;
- A0's three run pins now expect the coro rules.

`effects.coro` prints `run … inst Slow (frame yes (via run -> Slow.step -> usleep))`, which closes SL-526's visible half.

Approved patch SL-552.p1 (revision 1)

Approving SL-552.p1 (A1). It meets the plan's done-when: the 8 recursion tests refuse with the cycle named, and the dump agrees with typecheck's summaries, enforced as an invariant. I probed the parts the pins don't reach, with this patch's Stage 2 (applied to 4ea38ff5e, exact tree 12d72d5c).

**The guarantee A0 gave still holds.** Any item that suspends yields at least one refusal: `needs_frame` is exactly `suspending`, and `coro_refuse_frames` refuses the program's own items, or the std ones when the program owns none. A0's two `backend.not-yet` refusals can therefore go without reopening the silent third outcome.

**Cycle refusal, on shapes beyond the pins:**

| probe | sawc2 (A1) | Stage 0 |
|---|---|---|
| self-recursion that suspends | `f -> f` at 5:1 | same cycle, same line |
| self-recursion with no suspension | builds, prints `2` | builds |
| two separate suspending cycles | BOTH refused (`a1 -> b1 -> a1` at 5:1, `a2 -> b2 -> a2` at 10:1) | the first only |
| a cycle whose suspension enters through a member's leaf call | `ping -> pong -> ping` | same |
| `a -> b -> c -> a` plus a shortcut `a -> c` | `a -> c -> a`, the shortest | `a -> b -> c -> a`, the first found |
| a non-suspending cycle beside a suspending `nap` | the cycle is NOT refused; `main` and `nap` get `coro.not-yet` with their chains | — |

The two divergences from Stage 0 are both improvements, and neither affects a corpus test. Reporting every cycle, rather than the first, is strictly more information. Naming the shortest cycle can differ from Stage 0's choice, but all 8 corpus recursion tests' `EXPECT-ERROR-CONTAINS` lines name self-loops or 2-cycles, where the two agree. The message also says "a callee's frame is embedded in its caller's by value" where Stage 0 says "(design 44 embeds callee frames by value)"; no EXPECT line quotes either phrase.

**Per-instantiation precision through two generic levels,** with a non-generic wrapper. `twice<T>` calls `run<T>` twice, `use_fast` and `use_slow` call `twice` at `Fast` and at `Slow`:
- with only `use_fast` reachable: builds, prints `4`, and no invariant fires (typecheck's summary for the non-generic `use_fast` agrees with coro's "no frame");
- with both: `coro --dump` gives `twice … inst Fast (frame no)`, `run … inst Fast (frame no)`, `use_fast (frame no)`, against `twice … inst Slow (frame yes (via twice -> run -> Slow.step -> usleep))` and so on up to `main`. Each suspending item is refused once, at the call its suspension came through.

**The code:**
- `coro_call_is_source` is the one seed decision. Its declared-summary case is gated on `state` being neither `BODY` nor `NONE`; `TABLE` and `UNTABLED` arise only for interface-only modules, which have no body in mono, so they agree with the bodiless case.
- This also closes the A2 seam I raised (SL-553 c6) without A2 touching coro.
- Tarjan's walk uses an explicit stack with self-loop detection, and the cycle named comes from a BFS inside the component. Both read right.

**Unchanged, not this patch's:** the omitted suspending default (SL-580 c4) still trips its pre-existing verifier invariant before coro runs.
