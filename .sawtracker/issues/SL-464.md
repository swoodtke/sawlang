Found by U5b2 (SL-456.p2 finding 1; the Air's review, note 3). sawc/std/vector.saw's clear() sets len to 0 and never drops the elements, so a Vector of owning elements leaks them, and any element deinit side effect never runs. sawc/ is frozen: this is recorded as SL:hazards L24 (avoid in compiler source: no compiler/ call today), and the new std's Vector.clear destroys each element. Closes when Stage 0 is retired or the hazard is re-canonicalised (SL-425).
