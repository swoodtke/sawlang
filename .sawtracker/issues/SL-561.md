**The one semantic choice, a spawn root's effects belong to the task, has two halves, and both are right:**

| probe, inside a `sync` function | sawc2 (A7c) | Stage 0 |
|---|---|---|
| `Task.spawn(work(slow()))`, where the ARGUMENT `slow()` blocks | `effect.sync`: "`start` is declared `sync`, and it calls `slow`, which may suspend" | refused: "`sync func start` calls `slow` → blocking extern" |
| `Task.spawn(lazy(1))`, where the ROOT `lazy` blocks | accepted | builds, runs |
| `Task.spawn(work(1))`, a plain root | accepted | builds, runs |

The arguments run in the spawner, so their suspension counts there. Only the root's body moves into the task. `join_spawned` keeping the root's effects out of the spawner doesn't leak its arguments' effects out with them, and that is the half that's easy to get wrong.

**The borrow rule's boundary:** `Task.spawn(work(peek(&buffer)))` is accepted by both compilers, and Stage 0 runs it (prints `5`). The reference lives and dies inside the argument evaluation in the spawner, and only an `Int` crosses into the task, so not refusing a reference made by a nested call is correct. The direct spellings (a `&`/`&var` root argument, a borrow capture) are pinned, as are K88's two sites.

**Recognised by declaration:** `Task` is a reserved prelude name in both compilers (`name.reserved` and "defined multiple times"), so no user type can take it at all. Recognising the form by declaration rather than by spelling is still the right shape.

**Scope kept as ruled:** no must-consume role, and `drop.must-consume`, K78 and K79 are untouched. An accepted form stops at MIR's existing `slice.not-yet`, pinned (`mir/refuse/spawn-site.saw`), until A7d.
