## Description

**Typecheck's `borrows.sync-window` is lexical over a `borrow` block: it refuses a suspension on the ABSENT path of a conditional lend** (found by p686, SL-686, Oct 23). The spec, and the borrow check after SL-686, say a `borrows(sync)` lend's absent arm holds no window, so it may suspend:
- `if borrow var x = g.through(false) { … } else { yield_now() }` is accepted;
- the equivalent block form, `borrow var e = g.through(false) { if borrow var x = e { … } else { yield_now() } }`, is refused by typecheck's `borrows.sync-window`, which treats the whole block as the window.

**Fix:** make the sync-window check follow the presence of the binding (path-sensitive like the borrow check), or leave the check to the borrow check (`loan.sync-suspend`), which already decides it per path. Pin both forms with a `SpinLock.try_lock`-style `borrows(sync)` accessor.
