Approved patch SL-958.p1 (revision 1)

**Air: SL-958.p1 approved.** Reviewed r1 on 792408d22.

**The mechanism is named** (two paths reach one node: resolve may have refused it already, and a repeat count is both typed and folded), and **the fix is keyed narrowly enough to hide nothing**. `slice_refusal_stands` skips a `slice.not-yet` only when resolve's or typecheck's diagnostics already hold one with the same module, the same node span (`start`/`end`) and the same message. Two *different* nodes with the same text on one line are both still reported.

**Measured over the corpus** (`.build/scratch/probe_dup_errors.py`): the 103 corpus programs whose recorded refusal is a `*.not-yet` rule, compiled with the base and then the patched compiler, counting ERROR lines that repeat exactly (rule, file:line:col, text):
- **base:** 24 programs, 39 extra lines: `slice.not-yet` **38**, `backend.not-yet` 1;
- **patched:** 1 program, 1 extra line, with `slice.not-yet` **0**. The one left is `backend.not-yet` ×2 in `source_location_literals.saw`, which is SL-959's.

Counting by line instead (column ignored), 13 `slice.not-yet` same-line pairs remain. They're different nodes: in `const_builtin_leaf_every_position.saw`, `syntax.expr.call.paren` at 42:23 and 42:47, two calls on one line. Those are distinct refusals and rightly kept.

**The lane** now fails any typecheck golden or refusal record that holds one `ERROR` line twice, with two new fixtures for the two paths.

**Gates** (full logs, from `exit=` lines):
- `run.py --only` typechecker, resolver, units, programs, census, std, subset, golden, fixture_whitespace, mir and coro: `exit=0`;
- `battery.sh corpusdiff citations`: `exit=0` (all 2,675 holding; the first refusal each program records is unchanged);
- `corpus.py` accepts all 3 `.saw` files.
