**Air: F5 run. The ExplicitCopy-of-a-File case is UNSOUND (a double close that closes an unrelated file).**

The probe below, built with sawc at 857d7fcd2-era std (the SL-1003 review tree), prints `write to the second file FAILED: write failed (invalid descriptor)`.

```saw
import std.data.{Data}
import std.file.{File}
import std.path.{Path}

struct W { f: File, n: Int }
@synthesize extension W: ExplicitCopy {}

func make_and_copy() unsafe -> W {
    let w = W(f: try! File.create(path: Path(s: ".../first.txt")), n: 1)
    let c = w.copy()
    move c                      // `w` dies here and closes descriptor N
}

func main() unsafe {
    let c = make_and_copy()
    let g = try! File.create(path: Path(s: ".../second.txt"))   // reuses N
    let _ = move c              // the copy's deinit closes N again: g's file
    var d = Data()
    let _ = d.push(value: 65)
    match g.write(data: move d) {
        case Ok(n) -> print("write to the second file: ok, {} byte(s)", n),
        case Err(e) -> print("write to the second file FAILED: {}", e),
    }
}
```

- The synthesized `copy()` duplicates `File`'s `descriptor` bitwise. `File` is `NoCopy` (std/file.saw:320) and has no copy of its own, so there is nothing correct it could call.
- Both copies' deinits then close the same number. The second close lands on whatever the number names by then. Here that's another `File` the program holds, so its writes fail with EBADF. Had the number been reused once more before the write, they would land in the wrong file.
- So this is a resource-safety hole, not only an unchecked assertion. The Vector case runs clean, as you found, because `Vector`'s copy is real.

Since it touches a safety guarantee, the fix brief owes its conformance rows first. The row could be: a `@synthesize` copy-policy conformance is refused when a member's own policy can't supply it, naming the member, with File and Vector members, an enum payload, a generic instantiation and a tuple. The probe file is `.build/scratch/air-review/sl1018p/f5_double_close.saw` on the Air.
