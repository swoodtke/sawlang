## Description

**The print-failure path adds ~5.1 KB of `__text` to every program that prints (`hello`, -Oz, macOS arm64), and a freestanding hello's `.text` goes from 70 B to 3,921 B** (SL-768 c2, agent p768cut's measurement). The path is already outlined (`__saw_fail_print` is `noinline noreturn`), so marking it cold saves nothing.

**Where the bytes are:**
- `std.panic.print_failure` (1,324 B, with `SystemError.of`/`format`/`describe`/`system_error_kind` inlined);
- the fixed `StringBuilder` pieces it reaches (~1.3 KB);
- the `__saw_fail_parts` decimal helpers;
- in the runtime, `saw_write_parts` (800 B), the claim/lock functions (~480 B), and `tcp_socketpair` (180 B, linked whole-object).

**Candidate, UNVERIFIED (~2 KB):** a renderer that copies the kind text straight into the caller's scratch without `StringBuilder`, sharing with programs that already format a `SystemError`. Measure first (doctrine: perf by measurement; embedded is a first-class target); the freestanding numbers are the ones to beat.
