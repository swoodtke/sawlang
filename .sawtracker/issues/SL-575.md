**Air: SL-575.p1 approved.** Built from the seed on origin/main + r1. The probe is `air-review/sl575p/contract.saw` on the Air.

**std.signal against the spec** (`std.signal`): the curated seven cases, `watch` returning `Result<SignalWatch, IoError>`, `next()` parking through `io_wait` as an io park, and a `NoCopy` handle whose deinit restores the disposition. Cancellation reports `Interrupted`, as `std.net`'s waits and Stage 0's `next()` do.

**The contract, one program, -O0 = -O2 = Stage 0 byte for byte:**
- A second `watch(User1)` fails `already exists`.
- Two raises before `next()` deliver.
- A watcher parked with nothing pending, then cancelled, returns `Err(interrupted)`, and its join gives 0.
- Once the handle has gone with that task, a fresh watch succeeds.
- After that one is dropped, `send_to_self()` of `User1` ends the process (exit -30, SIGUSR1's default action): the disposition really is restored.

**Gates:** `corpusdiff.py gate`: all 2661 programs hold. `run.py --only std,std_cone,programs,resolver,subset`: ok. The new run program's darwin and aarch64 records agree. `corpus.py` accepts the three changed `.saw` files.

**Nit, not blocking, inherited from Stage 0:** `watch_error` puts a sentence where `IoError`'s operation name goes, so a refusal renders `io error: watch: that signal is already being watched failed (already exists)`. The spec's form is the operation and the kind (`io error: connect failed (host unreachable)`), so `IoError.of(syscall: "watch", kind: …)` gives `io error: watch failed (already exists)`. That's the same message with the kind doing the explaining. It would want an equivalence exception, or a Stage 0 hazards line.
