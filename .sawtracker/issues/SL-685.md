## Description

**sawc2's backend lowers a static of an integer or a Bool only, so no bare static of a lock or a `Once` builds** (found porting SL-672).

`LlEmitter.static_global` (`compiler/llvm/src/places.saw`) writes an `Atomic(<int>)` and a scalar static, and refuses everything else: `backend.not-yet`, "a static whose value is not an integer or a Bool is not in the backend slice yet".

```
$ .build/sawc2 build --std-root std compiler/tests/run/lock_statics.saw
ERROR backend.not-yet compiler/tests/run/lock_statics.saw:14:11 a static whose value is not an integer or a Bool is not in the backend slice yet
```

**What it blocks:** the freestanding idiom the spec's statics tier 1 exists for. With SL-672, `static STATS: SpinLock<Counters>`, `static REGISTRY: Mutex<Int>` and `static LIMITS: Once<Limits>` type, lower and drop-elaborate clean (`compiler/tests/std/calls/lock_statics.saw`), and stop here. All eleven of SL-672's corpus programs declare one, and the nine that must build stop here.

**The slice it needs, smallest first:** a bare static of any type is zerofill (`zeroinitializer`, internal, writable, aligned as its layout says), since tier 1's checks (`static.zero-hidden`, `static.zero-invalid`) already hold every part valid at zero; then tier 2's memberwise aggregates. A cell-carrying static is never rodata.

**Pin:** the due run-lane program `compiler/tests/run/lock_statics.saw`, which flips when a bare aggregate static builds.
