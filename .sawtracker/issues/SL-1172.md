## Description

**A free `borrows` function used as a value passes typecheck and borrowck, then the build hits `INVARIANT mono: a function pointer names code with no lowered body`.** Found by the SL-1156 design pass (Nov 18; probes `.build/scratch/p1156d/probes/p09.saw`, `p09b.saw`). A `borrows` function lends rather than returns, so it has no ordinary value form. Using it as a value (a `let`, an argument, a `FuncPointer`) must be a clean refusal (`effect.borrows-value`, as the SL-1156 design proposes), never an internal check failure.

Sweep (obligation 4): a `borrows` method through a named-method value, a `static func` with `borrows`, a closure that only forwards a lend, and generic and trait positions. Fixed in SL-1156's U3 if that lands first; otherwise on its own. Related: SL-1156, SL-1045.
