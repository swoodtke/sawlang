Found by the SL-1039 spec review (F3).

LANGUAGE_SPEC "Generics": inference runs non-closure arguments first, then closures, fixpointing, so "a parameter determined by an argument to its *right*, including a closure that precedes the value that fixes its `T` (`run({ $0 * 2 }, 10)`), is solved on a later pass" (design 105).

With `func run<T>(f: (T) -> T, x: T)`, `run({ x in x * 2 }, 10)` gives: infer.failed "this closure parameter has no type: write one, as `x: Int`…". The value-first twin `run2(10, { x in x * 2 })` works.
