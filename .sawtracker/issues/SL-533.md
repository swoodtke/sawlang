@claude-air-reviewer **SL-533.p1 is up for review: U7b, sawc2 builds itself** (u7b2, 9 commits squashed and rebased onto main after SL-519: 41 files, +2036/−177).

**Census** (`compiler/tests/run/README.md`, "The self-build census"). Each class between `sawc2 build` of its own driver and a working Stage 1:
- **`Int.to_string()` (9):** one requirement funnel, a trait default body plus "member glue", for a builtin conformance with nothing written.
- **`print` of a `Printable` (2):** renders through `format` into a fixed 512-byte stack builder.
- **Raw-backed enum layout (167 functions, and 475 more holding one):** laid out as its backing integer.
- **Payload-free enum `==` (590):** compares tags.
- **One each:** `T.min`/`T.max`; interpolation, through the growable builder; `Vector` literals; part-by-part equality of trivially copyable values (including `Alt?`); and the entry point defining std's argc/argv externs.
- **SL-529:** `StringBuilder.append(b: Byte)` was missing, so Stage 1 lexed every token as decimal bytes. The differential caught it.

Every class has a run-lane pin. The run lane is now 52 programs matching Stage 0 at -O0 and -O2; interpolation is no longer due, and 2 programs remain due.

**The `stage1` lane** (`compiler/tests/stage1/stage1_lane.py`, plus `twin.py`, a battery stage). It checks three things:
- **Determinism:** the driver's `.ll` is the same bytes across two builds and from a copied tree.
- **The fixpoint:** Stage 1's `.ll` equals Stage 0-built sawc2's, and Stage 2 links into Stage 1's bytes.
- **Agreement:** every sawc2 invocation that `run.py`'s lanes make runs under both binaries, and stdout, stderr and exit status must be byte-identical. `mismatches.tsv` is empty, and a listed mismatch that stops occurring fails as stale.

**Lead check, independent of the lane:**
- **Rebase:** onto main after SL-519. On the rebased tip, `run.py` is ok and the `stage1` lane is ok: **884/884 invocations agree** (two more than before the rebase, from SL-519's fixtures), and the fixpoint holds. Times: 793s for the lane, of which 653s is the lanes under both binaries.
- **By hand:** Stage 0 → sawc2 → Stage 1 → Stage 2. The driver's `.ll` (28,769,774 bytes) is byte-identical from Stage 0-built sawc2, Stage 1 and Stage 2. Stage 1 and Stage 2 linked under different file names differ only in the ad-hoc code signature's identifier (their output names). Linked under one name, Stage 2's and Stage 3's binaries are identical (`3f4cabbb…`).

**Not in this unit:**
- **SL-523:** the double lowering. It's a 0.8s fix, but there's no clean pin, because the subset allows no mutable counter.
- **SL-522:** clang is still run by the script, against Stage 0's runtime objects.
- `run.py` still defaults to Stage 0-built sawc2. Switching it to Stage 1 takes Stage 0 out of the loop, which is the precondition for SL-425.
- **Still refused, cleanly:** unsigned/Bool/Float rendering, Map and Set literals, `@synthesize`d member glue, and `==` on enums with payloads.
- CLAUDE.md's battery prose doesn't list `stage1` yet; I'll add it in a docs pass.
