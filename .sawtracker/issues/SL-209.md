## Description

EPIC / initiative — USER-DESIGNATED PRIORITY (2026-09-09).

## Objective
Make ownership an explicit property of every value transfer: checked centrally, recorded per transfer occurrence, and preserved through every lowering. The compiler has a central checker (`_check_value_transfer`, `sawc/typechecker/types.py`), but individual syntax handlers must remember to call it and codegen sometimes compensates when they do not (`_transfer_needs_copy`, `sawc/codegen/resources.py`). That lets expression positions bypass enforcement. Implement incrementally, preserving Saw's current language rules. Does NOT resolve the separate design questions of reusable-vs-consuming closures or fallible duplication.

- All referenced anchors confirmed present at current main: `_check_value_transfer` (types.py:4372), `_value_branch_arm_results` (types.py:4327), `_transfer_needs_copy` (resources.py:1564), `admit_declarations` (sawc.py:1183, design 266).

## Units and landing sequence (each is its own issue)
The remaining plan steps 2-7, grouped into five units, land in this order — each retains existing acceptance controls and adds tests for the boundary it changes:
1. Unit A — Ownership boundary inventory + structured transfer decision (plan steps 2-3). The foundation: `_check_value_transfer` returns an explicit decision, not error+needs_copy.
2. Unit B — Forwarding and control-flow taxonomy (plan step 4). Folds in SL-79 (DF-305a): the Optional/Result return auto-wrap is a forwarding position that must check ownership BEFORE wrapping. Closes SL-79.
3. Unit C — Preserve the decision through lowering, specialization, closure & coroutine conversion (plan step 5). Most likely to interact with in-flight coroutine-transform work (SL-208); sequence after that lands.
4. Unit D — Remove codegen's independent ownership guesses (plan step 6). Depends on Unit A's decisions existing.
5. Unit E — Mandatory pre-codegen transfer-decision verifier + the full interaction matrix (plan step 7). Last: makes completeness mechanically enforced.

Deliver the foundation first (A), then make every subsequent omission detectable (B-E). The completion criterion for the whole initiative: a new expression form cannot silently bypass ownership checking — it must declare how it produces or forwards a value before codegen accepts it.
