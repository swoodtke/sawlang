SL-887 (p887) keeps `sawc runtime` at `-g0`. Runtime objects with DWARF would put the runtime cache's absolute paths (`.build/rt2/…`) into every program's debug map, and would move `runtime_dirent.ll`. So a crash inside a runtime seam symbolizes to an address, not a line. Fix: emit the runtime's compile units path-free (the same rule SL-887 uses: dotted module paths, `directory: "."`), keep the objects' DWARF through the two-step link, and check that the fixpoint stays byte-identical.
