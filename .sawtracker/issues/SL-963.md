## Description

**A lane check that every direct call in emitted IR matches its callee's definition.** Suggested by the Air on SL-961, a miscompile where a hand-written `call void @g(ptr, ptr)` met a glue defined as `i8 (ptr)`. LLVM accepted it without complaint, because opaque pointers make a direct call to a mistyped definition well-formed IR.

**The check:** for each `.ll` the run lane, the corpus and sawc's own build emit, every `call` to a named function defined or declared in the same module must agree with that definition on return type and parameter count and types. A mismatch fails the lane and names both lines.

**Where:** a small IR scanner, run from the run lane over its programs' `.ll` and from the fixpoint lane over sawc's own IR. Per the Air's comment on SL-961, the corpus has 0 mismatches today after the fix, so it should pass from the first run.
