## Description

**A forwarding accessor is refused (`move.use-after`) when the inner accessor keeps an owning local across its `lend`** (found by p859, the SL-859 sweep, Oct 23; repro `.build/scratch/p859_evidence/iso/fwd_min.saw`; sync, not about suspension).

```saw
func at(&var self, i: Int) borrows -> &var Int { let note = "held".to_string(); lend self.cells[i] }
func fwd(&var self, i: Int) borrows -> &var Int { lend self.inner.at(i) }
// ERROR move.use-after fwd_min.saw:16:9 `_2` is used after it may have been moved
```
It reproduces with a NoCopy local (`fwd_min_nocopy`) and with the `borrow x = … { lend x }` form (`fwd_min_block`). With an `Int` local it builds and prints 11 (`fwd_min_trivial`). It's raised in borrowck.

**Mechanism (UNVERIFIED):** the inner accessor's state record (holding the owning local across the lend) is carried through the outer accessor's record, and the hand-off reads as a use after a move.

**Obligation 4:** forwarding depth {1, 2} × the inner local {trivial, String, NoCopy, NoCopy with `deinit`} × the form {direct `lend inner.at(i)`, a block `borrow x = … { lend x }`, conditional lends on either side} × the epilogue {none, prints}. Each cell runs correctly, with the inner local dropped once at the inner epilogue (`// leaks: none`).
