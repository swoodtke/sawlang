## Description

**sawc2 accepts `&var x` passed to a `&T` parameter, but the spec says call-site sigils mirror the parameter in both directions.** Found by batch B1 (tcb1) while fixing SL-474's sigil rule.

- **The spec:** "The call-site sigils still mirror the parameter".
- **Stage 0:** `_check_call_reference_sigils` in `sawc/typechecker/types.py` refuses a mismatch in either direction. For this one the message is "parameter `p` is `&T`; write `&x`", with the hint "call sites mirror the parameter's reference spelling".
- **sawc2:** refuses a bare reference binding (SL-474) and `&x` passed to a `&var T` parameter, but accepts `&var x` passed to a `&T` parameter as a shared conversion.

**Owed:**
- Refuse `&var x` passed to `&T` with `type.mismatch`, with a fix-it naming `&x`.
- Sweep every position a written sigil meets a reference parameter:
  - a free call, a method argument and a static call;
  - an initializer argument;
  - an operator's reference operand;
  - a closure call;
  - a labeled argument.
- Pin one fixture per position.
- The implicit receiver stays implicit.

Typecheck, batch B2.

Added from the Air's SL-463.p1 approval: **the overload filter scores a bare reference binding by its own type.** Take it in the same unit.

**The repro:** with `f(x: Int)` and `f(x: &Int)`, and `p: &Int`:
- **Stage 0** accepts `f(p)` and calls `f(Int)`, the value read (prints 101).
- **sawc2** scores `p` as `&Int`, picks `f(&Int)`, then refuses it with the `&p` fix-it. Following the fix-it changes which overload runs (201).

**Owed:** score a bare reference binding by its referent's type, the same value read that `read_value` gives every other position, so `f(p)` picks `f(Int)`. With only `g(x: &Int)` and `g(x: String)`, `g(p)` stays refused. Pin both. Probe: `.build/scratch/air-review/b1/probe_overload_ref.saw` (on the Air's machine; recreate it locally).
