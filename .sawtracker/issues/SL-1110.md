## Description

**Follow-ups to SL-1107 from the Air's review of its patch (Nov 14): the fold over raw cases and cycles.** Evidence: the review comment on SL-1107 (c5) and its generator, chat file f73 (`gen_probes.py`: group `c` is raw cases, group `l` lengths and repeat counts on a cycle with no raw case; l18, l19, c16, c48, c49 are finding 1).

**1. A length and a repeat count disagree when they reach a cycle THROUGH a static.** `static M: Int = K`, `static K: Int = M`, `static T: Int = M + 1`: `let b = [0; T]` is quiet since SL-1107 (the cycle is reported at `M`), and `struct S { a: [UInt8; T] }` still adds "the static `T`'s initializer does not fold". The same split for a static that names a cyclic case (`static S: Int = E.A as Int`, then `[UInt8; S]` and `[0; S]`). The two positions must give one answer. Lead's decision (reversible): quiet in both, the statics' own rule ("one already evaluated is on a cycle, which its own declaration refuses"): a `Cycle` fault reached through any number of statics and cases adds no error at a use. Do it after SL-457's U3 lands, where a length and a count share one conversion.

**2. A long chain of cases folds in cubic time.** `case K0 = 0`, `case Ki = E.K(i-1) + 1`, `typecheck --check`: 1,000 cases 0.5 s before SL-1107 and 2.8 s after; 2,000 cases 1.8 s and 19.1 s. By the reviewer's reading: `fold_case` scans the chain and rebuilds it at each level (as `fold_static` does), and `reaches_case` walks every earlier case for every case, rebuilding `path` on each return. A case's folded value is not kept: each use folds the whole chain again. Keeping each case's value once folded (the ahead pass already evaluates every raw case) removes both.

**3. The same chain at 4,000 cases is a segfault, before and after SL-1107** (the fold's recursion depth, by its shape; UNVERIFIED). Probably the same for a chain of statics; probe it. Keeping folded values (2) bounds the depth when cases are evaluated in declaration order, but a chain declared in reverse still recurses: the fix wants a depth-independent order or a clean refusal.

**4. Wording:** `case A = sizeof<[UInt8; E.B]>()`, `case B = E.A` prints "the array length `E.B` depends on itself, through a static whose type holds it", and there is no static.
