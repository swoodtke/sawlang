## Description

**Borrowck's nested-call rule (K139) misses a `borrow`-marked accessor call: `borrow r.at(reset(&var r))` is accepted** (found by p849, SL-849 step 2, Oct 23; pre-existing on main; repros `scratchpad/p849/nested_more.saw`, `nested_bare.saw`).

- **Refused (`loan.nested-call`):** the bare `r.at(reset(&var r))`, correctly: the receiver is borrowed for the whole call, and an argument writes it.
- **Accepted, on main and on SL-849's build:** the marked `borrow r.at(reset(&var r))`, `borrow var r.slot(reset(&var r)) += 1` and `borrow let x = r.at(reset(&var r)) { x }`.

SL-849 (every `borrows` call is written with `borrow`) makes the marked spelling the only one, so the rule would protect nothing. It's an exclusivity soundness hole: an argument writes through `&var r` while the accessor's window over `r` is open.

**Mechanism (UNVERIFIED):** the rule reads the receiver of a plain call node; the `borrow` place wrapper hides it.

**Obligation 4:** every borrowck rule that reads a call's receiver or arguments (`loan.nested-call`, `assign.rhs-borrow`, `loan.window-root`, `lends.*`, the sync-window rules) × {bare, `borrow`, `borrow var`, the block form, a conditional lend `!`/`??`, inside a `match` scrutinee}. Each marked cell has the bare cell's verdict.
