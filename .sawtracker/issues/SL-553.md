**2. Files A2 must touch beyond its list.** No other agent holds any of them today (A0 is in `compiler/mono` and `compiler/llvm`).
- `compiler/typecheck/src/lang.saw`: `tc_lang_expected` matches every `ResLang` with no default arm, so each new role needs a row there for its expected shape.
- `compiler/tools/subset_check.py`: the std profile refuses `yield_now`, `sleep` and `cancelled` in `std/` as `sync-only`. They are in `SYNC_ONLY_NAMES`, and `STD_PROFILE_FEATURES` does not drop that rule. The std lane requires the profile to accept `std/`. Probe: a two-function `std/task.saw` declaring `yield_now` and `cancelled` got `sync-only` on both lines. The fix is a profile feature entry for the task vocabulary.
- `compiler/tests/std/`: a `subset/` fixture for that profile change.

**3. The design I would implement, for the lead to confirm.** Each point is reversible.
- **The park intrinsics are std declarations.** Under the new std a lang role binds a std module's declaration, and `func-decl` requires a body (only an extern function has none). So `std/task.saw` declares `public(package) func __saw_park_ready()`, `__saw_park_timer(...)` and so on, with roles `ParkReadyFunction`, `ParkTimerFunction`, and so on.
  - Each summary comes from its role in `summarize_declared`: it suspends and is nonsync, and no unit is built for its body.
  - Each body panics, naming the missing lowering, so a call that reaches the backend unlowered fails loudly.
- **A2 declares every reason:** ready, timer, fd, channel and offload, with the signal watch going through fd. A3c lowers them all but touches only `compiler/coro/`. Operands follow Stage 0's types, and A3c can settle them.
- **`cancelled()` does not park.** Stage 0 says it is not a suspension source and can be called in any context; outside a frame it reads `false` (design 52b item 3, `sawc/typechecker/expressions.py`). So `cancelled` calls `__saw_cancel_requested() -> Bool`, a lang role with no suspension. Its body is `false`, which is its meaning in an unframed item, and A9 lowers it in a framed one. The plan calls both `sleep`'s and `cancelled`'s intrinsics park intrinsics, but this one does not park.
- **Where the names live:**
  - `sleep` and `cancelled` are declared in `std/task.saw`. Under the new std, `resolve/src/prelude.saw` names them in the prelude from `std.task`.
  - `yield_now` is public but stays out of the prelude.
  - `Duration` lives in `std/duration.saw`, which the existing prelude row already names.

I am waiting for the lead's ruling on points 1 and 2 before implementing.
