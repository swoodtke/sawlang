Stage 0 (the frozen Python compiler): two extensions of one type in different modules, each declaring a method of the same name (private methods, which the spec allows: extensions are import-scoped), make the build fail with an internal compiler error. The method mangling drops the extension's module, so the two collide.

Repro (a program of four modules): shape.saw declares 'public struct Shape { public side: Int }'. area.saw declares 'extension Shape { func fold(&self) -> Int {...}; public func area(&self) -> Int { self.fold() } }'. perimeter.saw has the same shape with its own fold. main imports both.

Error: internal compiler error at area.saw:9:13 (MethodCall): Undefined method: Shape$m$shape.fold

Loud, and frozen per the Sep 24 freeze. Ledgered as SL:hazards L23. Found by SL-447 U6b3, whose own fold_chain collided with signatures.saw's, and which it renamed.
