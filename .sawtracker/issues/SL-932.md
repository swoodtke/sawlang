**MIR has no scope end for drop-free locals, so a local's coroutine-frame residency runs to the end of the body, not to the end of its scope.** Frames come out larger than they need to be, and the spec's "an aligned local in a suspending function is fine as long as its own scope does not span the suspension" (LANGUAGE_SPEC "Alignment") doesn't hold.

Found by pplace (SL-865 U7, `@align`), at base origin/main 09feb7f08 plus the U7 WIP.

**Evidence.** In `tests/corpus/align_nonresident_local_in_suspending_function.saw`, `worker` declares `@align(64) var scratch: [UInt8; 32]` inside an `if` that closes before the `yield_now()`. Its scope never spans the suspension, but coro keeps it in the frame:

```
$ sawc coro --layouts align_nonresident_local_in_suspending_function.saw   (twin: .build/scratch/p878place/sweep/a07_nonresident_suspending.saw)
frame #6: a07_nonresident_suspending.worker() task root  (size 64 align 8, lower bound 64)
    suspend 1: bb1 call yield_now
    (*frame).[48: Int]  size 8 align 8  _1 seen  (across 1)
    (*frame).[8: [UInt8; 32]]  size 32 align 1  _3 scratch  (across 1)
```

**Mechanism.** compiler/tests/coro/README.md, "Storage lifetimes", says a local's lifetime is where the initialisation analysis says it may be initialised, and "A local only ever copied never stops being initialised, so its lifetime runs to the end." Only a `Drop` ends a lifetime, and MIR writes no statement at the scope end of a value with no drop: `MirStmtKind` is `Assign`, `Drop` and `Budget` (`compiler/mir/src/model.saw`). So every drop-free local of a framed body that is initialised before a suspension is resident from there to the end of the body.

**Consequences.**
- `@align` (SL-801, landing with SL-865 U7): the frame-residency refusal `coro.align-frame-resident` is keyed on sawc's real residency, which is sound (an alignment is never dropped), but it refuses the spec's accepted control. The corpus row `align_nonresident_local_in_suspending_function` stays refused by `coro.align-frame-resident` until this lands. Its message says sawc keeps the local in the frame to the end of the function and cites this issue.
- Frames hold drop-free locals past their scopes, so they are larger than they need to be, and the packing can't reuse those bytes.

**Fix shape.** A scope-end marker in MIR for every local, drop-free ones included (or a scope-end point the lifetimes funnel reads), so a lifetime ends at the scope's end. This changes frame layouts broadly: the coro goldens (layouts, `pack_*`, lifetimes), the coro census and the frame sizes in the corpus snapshots all move, so it wants a unit of its own with a position matrix: a block, an `if`/`match` arm, a loop body, a `borrow` block and an `if let` body, each with an early exit.
