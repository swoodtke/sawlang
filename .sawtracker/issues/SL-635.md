**`comparable_bits` gives up at a nesting depth of 16, so `==` on a deeper trivially comparable type is refused** (SL-606 bucket B, sibling of SL-627's cap family; found in SL-627's sweep).

- **Mechanism:** `compiler/llvm/src/ops.saw` `comparable_bits(t, depth)` returns false once `depth > 16`. `memory_comparison` reads that false as "this type is outside the backend slice" and refuses with `backend.not-yet`. The walk is over a concrete type's parts: an Optional's payload, and a record's tuple elements or fields. Those are subterms of an interned type, so it terminates without the cap. A memo keyed by TypeId keeps it linear on a type that shares parts.
- **Repro:** `type B0 = Int`, then `type Bk = (B{k-1},)`. `let a: B18 = …; let b: B18 = …; print("{}", a == b)` fails `sawc2 build` with `backend.not-yet … the operator == on ((((…Int,),)…) is not in the backend slice yet`. B16 builds and prints `true`. The generator is `.build/scratch/b1/gen_eq.py` in b1caps's worktree.
- **Fix:** drop the depth parameter, with identity memoization if sharing makes the walk exponential (principle 6). Pin: B18 (cap plus two) builds and prints `true`.
- **Owner note:** `llvm/src/` is d1attr's track (SL-628) at the time of filing, so this was not folded into SL-627.
