## Description

**Two gaps beside SL-580's extern-agreement funnel** (found by A18, agent p580refuse):
1. **An `@export` that DEFINES a C symbol an `extern` declares at another signature builds silently:** `@export func f(x: Int32) -> Int32` against `extern "C" { func f(x: Int) -> Int }` runs and prints `42`, with the width mismatch undetected. A18's funnel (`check_extern_declarations`) compares extern declarations with each other, not with `@export` definitions. It wasn't widened, because `sawc2 runtime`'s seam definitions sit against std's externs, so the widening must handle the runtime build (each seam's `@export` checked against `runtime/ABI.md`'s signature, as design 149's `[package] runtime` already does) and user exports alike.
2. **No hosted-module gate under `--freestanding`:** Stage 0 refuses importing a hosted-only std module (`std.net`, `std.file`, `std.process`, …) in the freestanding profile; sawc2 has the profile bit now (SL-580's `TcProgram.freestanding`) but no gate. Kernels and freestanding are first class.

Both are small typecheck additions; obligation 4 for (1): every position a C symbol is declared or defined (extern, `@export`, the runtime build's seams, `@section` statics?).
