## Description

**sawc2 checks a generic instance only when mono emits it; design 218c A5(a) says every DEMANDED instance is checked** ("checking aligns with existence, `-c` and `-o` report identically"). Found by SL-702: `errors/never_emitted_instance_reports` (an `Anchor: NoMove` element in `Vector<Anchor>.swap_out`, inside a function nothing calls) is accepted by sawc2 and refused by Stage 0. Once the instance is emitted (the scratch variant calls `wire()`), sawc2 refuses it correctly: `transfer.no-move … in the instantiation std.vector.Vector.swap_out(...) args Anchor … a generic that relocates its values cannot hold one`. So this is not a soundness hole, since nothing unchecked ever runs. It is a diagnostic-completeness gap: an error in an unreachable instantiation goes unreported, and `build` and `check` can differ.

**Scope:** wherever sawc2 decides which instances to check (mono's worklist from the roots), check every instance the program DEMANDS (named in a reachable or unreachable body), not just the ones it emits, or record why sawc2's rule differs and get a ruling on 218c A5(a). Pin: the corpus row (now `wrong`) moves to pass.
