## Description

**A window left by SL-768 c2's raw-code rule** (agent p768cut, decision 7): `Thread.spawn`'s lowering drops the brace's captures BEFORE it calls `Thread.__saw_started`, so on a refused spawn a capture's `deinit` can run between the `__saw_rt_thread_spawn` seam call and `SystemError.of`. If that `deinit` calls a classifying seam, the error renders the wrong raw code. Moving `of` to the top of `__saw_started` can't close it; the fix is in the spawn lowering: build the error (or read the stamp) before the env drop. Pin: a refused spawn whose capture's `deinit` calls a failing fs seam reports the spawn's own errno.
