## Unit A: bare `borrow` (SL:borrowing r21 §2.1 and §2.2)
**Ruling:**
- The word order stays `borrow let` / `borrow var`: the construct first.
- Where no name is bound, bare `borrow` is shared and `borrow var` is exclusive, mirroring `&`/`&var`.
- `let` or `var` follows `borrow` only where a name follows it: the block form, `if borrow let x`, `case Some(borrow var x)` and `for borrow let x in`.
- A bare `borrow` is always shared, never inferred from use. A write through it is a type error, not a grammar refusal.

**GRAMMAR.md:**
1. In every position where a borrow binds no name, accept `borrow <place>` as shared and `borrow var <place>` as exclusive:
   - the statement form;
   - a borrow in expression position;
   - the argument position;
   - a place in an interpolation segment;
   - any other such position §12 lists.

   Update the productions, §12's context rows and §13's text.
2. **`borrow let <place>` with no name bound is removed.** Add a removed production, such as `syntax.expr.refused-borrow-let-unbound`, with a hint naming bare `borrow`. There is one spelling per meaning. Reading `borrow let` as a declaration in expression position is exactly what §2.1 rules out.
3. **Contextual-word rule, the lead's decision.** `borrow` stays contextual. It is the borrow prefix when the next token, on the same line, is an IDENT, `self` or `var`, and in binding forms `let`. Otherwise it is an ordinary identifier: `borrow(x)` is a call, `borrow.count` a member, `borrow[0]` a subscript and `borrow = 1` an assignment.
   - State this in `syntax.rule.contextual-words` with the lookahead set.
   - Every place GRAMMAR.md allows under the prefix starts with a name or `self`. If you find a legal place shape that starts otherwise, such as a parenthesized head, stop and report it. Do not widen the set.
4. **Recognizer, lint and corpus:**
   - regenerate the corpus;
   - golden cases for each unbound position (shared and `var`);
   - a negative for `borrow let <place>` unbound, named by the removed production;
   - the contextual-word cases in both directions, `borrow` as the prefix and `borrow` as an identifier;
   - update the dump pins and README examples that use unbound `borrow let`;
   - record, and justify, every grammar corpus verdict change.

Three points for the implementing agent, to relay if it's already running. One more is a check, and it came back clean.
