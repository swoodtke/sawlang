## Description

**An accessor's epilogue loads every record field at entry, on every lend site's path: an owning local live across one site is refused (INVARIANT / `move.use-after`)** (found by p868, SL-868 r2, Oct 24; repro `scratchpad/p868/m6_plain_local.saw`; it predates SL-868, on main too).

In an accessor with several `lend` sites, an ordinary owning local that lives across one site and is never assigned on another site's path is refused: the MIR INVARIANT "owned local _2 may still be live at a `return`", and borrowck's `move.use-after`.

**Mechanism (UNVERIFIED, p868):** the epilogue's entry loads EVERY record field before the resume dispatch, on every site's path, including fields the taken site never wrote. SL-868 r2 stopped the prologue from WRITING an unopened window's record at a site, but left the entry load. Nothing faults today (record locals are never dropped, and the unwritten field is unused on that path), but the load reads an unwritten field, and it makes an owning local look live on paths where it never existed.

**Fix:** load record fields per site, after the resume dispatch, using SL-868's per-site facts on `MirAccessor` (`site_resume_first`, `site_open_first`), and teach the epilogue verifier the per-site load. Obligation 4: sites {2, 3} × the local's site {one, several, all} × its type {trivial, String, NoCopy, NoCopy with `deinit`} × the caller {sync, suspending}, with `// leaks: none` and ASan.

**Step 1 (p873): this is a LIVE MEMORY FAULT, not only a refusal.** The issue text's "nothing faults today" is wrong. In a SUSPENDING caller, a multi-site accessor's prologue (`write_record`) moves another site's local, unassigned on the taken path, into the record. - **Ruled design:** ONE `record_site_kinds` in MIR `split.saw` gives per-(site, field) kinds {absent, whole, flagged}. The prologue writes, and each site's path loads, only its own fields after the dispatch. The verifier checks it per site. Drops' `verify_record_flags` requires flags only for the fields a return writes. `MirInit` gets per-site plain loads.
