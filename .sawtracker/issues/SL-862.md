## Description

**A `constexpr` function that suspends is accepted** (found by p859, the SL-859 sweep, Oct 23; repro `.build/scratch/p859_evidence/inv/i30_constexpr.saw`).

`func f() constexpr -> Int { yield_now(); 1 }` builds and prints 1. SL:architecture and GRAMMAR's effect slot say `constexpr` implies `sync`: a compile-time-evaluable function can't suspend. Callers still treat `f` as may-suspend (i31 is refused twice), so nothing unsound was observed, but the declaration's contract isn't checked.

**Fix:** `constexpr` folds into the `sync` effect at the declaration, so the body's suspension gives `effect.sync` (or a `constexpr`-named variant) at the suspending call, and callers then see `f` as `sync`. Pins: the refusal at the suspending call, and a `constexpr` called from a `sync` function, now accepted.
