## Description

**Found by:** batch B2b (tcb2b), while settling SL-492. Filed on the lead's ruling (option (a)): SL-492 closes on its optional-place half, and this rule goes to a later batch, after a census. **Area:** typecheck, every call of a named `borrows` method.

**The rule:** the spec says "A `borrows` method is called only through the `borrow` construct, as the head of a `for`, or as the operand of a `lend` that forwards its place". SL:borrowing §1 says it too: "A `borrows` function can be called only through the `borrow` construct". A plain subscript is exempt, because it is the getitem (D29, §5.1), but a named accessor has no plain role.

**The defect:** sawc2 doesn't enforce the rule for named accessors at any position. All of these type-check, borrow-check and lower:

```saw
struct P { n: Int }
struct Bag { items: [P; 2] }
extension Bag {
    func peek(&self, i: Int) borrows -> &P? {
        if i < 0 || i > 1 {
            return None
        }
        lend self.items[i]
    }
    func first(&self) borrows -> &P { lend self.items[0] }
}
func a(b: &Bag) { let o = b.peek(0) }           // an optional copy, no `borrow`
func c(b: &Bag) -> Int { b.peek(0)!.n }         // a window through `!`
func d(b: &Bag) -> Int { b.first().n }          // an unconditional lend
func e(b: &Bag) { if var x = b.peek(0) { x.n = 5 } }   // a write to a copy
```

**Mechanism:** a `borrows` call is checked like any method call (`method_call`). Its receiver's borrow waits for `settle_places`, which settles the mode but never asks whether the call is in a position that may open a window. The only positions that ask are the `borrow` forms, `lend` and the `for` head. They decide how the window is spelled, not whether one may be opened. So no funnel names "the positions a `borrows` call may stand in". The rule needs one, with the `borrow` forms, the `for` head and the `lend` operand as its entry points. Every other position refuses, with a fix-it to the `borrow` spelling.

**Position matrix** (each row needs a refusal fixture, except the allowed ones):

| position | today | owed |
|---|---|---|
| `let o = b.peek(0)` (a whole optional copy) | accepted, copies | refused; fix-it `borrow b.peek(0)` (§2.2: the optional copy) |
| `b.peek(0)!.n`, `b.peek(0)?.n` | accepted | refused; fix-it `borrow b.peek(0)!.n` |
| `b.first().n`, `b.first().m()` | accepted | refused; fix-it `borrow b.first().n` |
| an argument, `f(b.first())` | to probe | refused; fix-it `borrow b.first()` / `borrow var` |
| `if let x = b.peek(0)` / `if var` | accepted, copies (SL-492 kept this) | refused; fix-it `if borrow let|var x = b.peek(0)`, or `if let x = borrow b.peek(0)` for a copy |
| `guard let|var x = b.peek(0)` | accepted, copies | refused; fix-it `if let x = borrow …` (a guard takes no borrow binding) |
| `while let|var x = b.find(0)` | accepted, copies | refused; fix-it `while borrow let|var` |
| `match b.peek(0) { case Some(x) … }` | to probe | refused; fix-it `match borrow b.peek(0)` or a `borrow` block |

| `borrow …`, `borrow let|var x = …`, `if|while borrow …`, the `for` head, the `lend` operand | allowed | allowed |
| a plain subscript `v[i]` | getitem | unchanged (D29) |

**Census and the Stage 0 hazard question** (grep-level; the batch should redo it precisely with sawc2, for example by refusing behind a flag and counting):
- Stage 0's std (`sawc/std/`) declares these named `borrows` methods: `Vector.get`, `Map.get` (`get` twice), `Box.value`, `Map._key_ref` / `_value_ref`, `JsonValue.as_array` / `as_object`, and the borrowing-struct `iter` / `enumerated`, which are `for` heads.
- The new std (`std/`) declares `Vector.get` as `(&var self, index: Int) unsafe borrows -> &var T?` and `Box.value` as a lend. The new std itself makes 0 `.get(` calls and 3 `.value()` calls.
- `compiler/` has 134 lines with `.get(` in 68 files, and 6 with `.value()`. Most are Stage 0 `Vector.get` / `Map.get`, written plainly, e.g. `names.get(k) ?? ""`. Stage 0 doesn't parse `borrow`, so it can't compile the ruled spelling. Enforcing the rule over sawc2's own source is therefore an SL:hazards question: exempt Stage 0 std's declarations as `accessor_exclusive_only` already does (`ResModuleKind.Std && not std_new`), or re-spell after self-hosting (SL-425).
- `tests/corpus/` has 372 lines with `.get(`. The programs that expect success would be newly refused under the rule, unless the Stage 0 std exemption covers them.
- Related: SL:borrowing §5 K14 says `get` should return a copy and `find` should be the conditional lend. The new std's `Vector.get` still lends. Renaming it to `find`, with a value `get`, would remove most of the census.
