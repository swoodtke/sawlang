## Description

**Found by SL-662's sweep (d662inplace).** A `match` on an owned local whose type is `NoMove` moves the payload out into the arm's binding, so the payload's `deinit` runs at a stack copy, away from its home. Nothing refuses it.

**Mechanism.** Typecheck's scrutinee-origin reading (`compiler/typecheck/src/bodies.saw`, the origin a `match` scrutinee gets) marks an owned local whose type does not copy silently `TcUse.Move` directly (`self.set_use(scrutinee, TcUse.Move)`, origin `Owned`). Every other move of a place passes through `check_no_move` in `move_expr`, the funnel that refuses a `NoMove` relocation, and, since SL-662, records a generic one for mono's per-instantiation check (`note_relocation`). This position sets the use without either, so it is a bypassed entry point of the NoMove funnel.

**Repro** (`sawc2 build --std-root std`; Stage 0 behaves the same):

```saw
struct Pinned { id: Int }
extension Pinned: NoCopy {
    func deinit(&var self) unsafe {
        print("deinit {} at {}", self.id, (&self) as UnsafePointer<Pinned> as Int)
    }
}
extension Pinned: NoMove {}

enum Holder {
    case Has(p: Pinned),
    case Empty
}
extension Holder: NoCopy {}
extension Holder: NoMove {}

func main() unsafe {
    let h = Holder.Has(p: Pinned(id: 1))
    print("home at {}", (&h) as UnsafePointer<Holder> as Int)
    match h {
        case Has(p) -> print("arm sees {}", p.id),
        case Empty -> print("empty")
    }
}
```

prints `home at 6094219344`, then `deinit 1 at 6094219272`: the payload left the binding it was built in (its home would be the enum's address plus the payload offset).

**Positions to sweep:** a bare `match` on an owned `NoMove` local, its value-producing form, a `match` on an owned local inside a generic body whose type only an instantiation makes `NoMove` (which `note_relocation` does not see either), and whether `if let`/`guard let` reach the same origin (on an owned NoCopy optional, sawc2 refuses them as `transfer.implicit-copy` today). The fix is either refusing the move at a `NoMove` scrutinee (the author writes `match &h` to borrow it) or routing the origin's move through `check_no_move`/`note_relocation`; which one is a reading of the spec's "every other transfer position".

SL-681.p1 submitted. **Reproduced** in sawc2 and Stage 0: the `deinit` ran at a stack copy, away from the value's home.

**The fix:** one relocation funnel, `check_relocation` (`compiler/typecheck/src/bodies.saw`), whose docstring names its entry points: `check_no_move` (a spelled `move`, keeping the fresh-placement exception), `scrutinee_origin` (the bypassed site), `add_capture` (`[move x]`), `check_take` (replacing the two `take()` sites) and `settle_body_paths` (a generic last-use read). A concrete `NoMove` relocation is refused where it is written. One that only an instantiation decides is recorded with how it was written, and mono refuses it per instantiation (SL-662's path). The match message points to a `&`/`&var` parameter as the way out.

**The sweep (obligation 4):** the `match` scrutinee was the only bypass. Statement and value `match`, a by-value-parameter scrutinee, a discarding arm, and tuple, optional, guarded, nested and struct scrutinees were all run before and are refused now, concretely and per instantiation. Every other consuming position (`if let`/`guard let`/`while let`, destructuring `let`, captures, return, by-value argument, `??`, `!`, `try`, a `for` head, a value branch arm, a `consumes` receiver) was already refused as an implicit copy or needed a spelled `move` that the funnel refuses. A temporary scrutinee relocates no bound value and stays accepted. The full matrix is in the agent's report.

**Pins:** conformance row **K170** (written first; K167–K169 are reserved for SL-564 r2), 10 typecheck refusal fixtures and 5 mono refusal fixtures (`transfer.no-move.*`), and the run probe `nomove_match_borrows_in_place` (a borrowing match whose arm and `deinit` see the same address, concrete and generic, at -O0 and -O2). One fixture header shifts: mono now reports a spelled `move` at the keyword, as typecheck does (`transfer.no-move.placement-after-borrow`, 20:19 → 20:14).
