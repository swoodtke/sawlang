Ruled (user, Sep 25; SL-400 c6, Q7): a boolean `guard cond else { … }` is added. Its `else` block must leave the scope, as with `guard let`. It enters the grammar as a lockdown production and is implemented in the new compiler. The spec text is carried on SL-393. The frozen compiler does not get it.
