Found by the SL-1190 sweep.

`sawc build -O0 --codegen-units=module --lto=thin` builds a sawc that runs in 8.0 s (with `full`, 7.2 s), against 52.9 s unoptimized. The link line carries `-O0`, but the ThinLTO backend optimizes anyway (mechanism UNVERIFIED).

A flag must do what it says: either `--lto` at `-O0` is refused (as `--lto` with `--codegen-units=1` is), or the link runs the LTO backend at the build's level. The default at `-O0` is `none`, so only an explicit `--lto` reaches this.
