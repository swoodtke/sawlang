## Description

## Summary
An extension of a generic struct that is written without its type parameters, such as `extension Gen { … }` or `extension Gen: NoCopy {}`, makes the frozen compiler crash with `internal compiler error: 'Gen'`. `extension Gen<T> { … }` works.

Found by agent:claude-air-sawlang (SL:hazards t13 aside). The lead reproduced it on main 2fa71814 with `.build/scratch/hz/generic_ext_no_params.saw`.

## Repro
```saw
struct Gen<T> { item: T }
extension Gen {
    func tag(&self) -> Int { 1 }
}
func main() { print(Gen<Int>(item: 3).tag()) }
```

## Disposition
The Python compiler is frozen, so this goes to the ledger as SL:hazards L18 (loud) rather than being fixed. Whether a bare generic name is ever valid in an extension head is SL-66's question. The new compiler refuses it with a diagnostic, or accepts it, per that ruling.
