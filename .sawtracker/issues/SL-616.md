**Ruling 1 (the user, Oct 13): packed (module, index) ids, migrated one id kind at a time** (SL-606; the review's M5 and Resolve 10). This unit is the §3.0 amendment and step 1. Steps 2 and 3 are their own epic, SL-617.

**The ruling,** with the user's words:
- "can we have a hybrid model in which we encode the module id in the global id e.g. the top 24 bits are modules id and the bottom 40 bits are index?"
- "can we use a module id == 0 to mean global id? … and incrementally change to per-module ids"
- "yes record it".

The content:
- **§3.0 is amended.** Each id kind (`DeclId`, `NodeId`, `LocalId`, `FuncId`, …) is a typed wrapper over a `UInt64`: 24 bits of module and 40 bits of index within that module's arena. Real modules are numbered from 1.
- **Module 0 means a program-wide index** during the migration. Every id today is already valid as module 0, so nothing changes on day one.
- **Never mix encodings within one id kind.** Two encodings of one entity would compare unequal, and every map, dedupe and identity test would break silently. So a kind migrates all at once, and once it has, a module-0 id of that kind is an `INVARIANT`.
- **"None" is `Id?`, never `-1`.**
- **`TypeId` stays program-wide,** interned and serialized by canonical key. Mono's instantiated items stay program-wide too.
- **Persistence:** a module's own references are its local indices, and a cross-module reference is (module-table entry, index), the module table mapping each entry to (package, module path). Declaration paths are used only in published interfaces, because a persisted index is stable only while its dependency module is unchanged.

**This unit:**
1. **Amend SL:architecture §3.0** to the ruling: the id bullet, the cross-module-reference bullet and the serialization list. Also add a line to `compiler/resolve/README.md` replacing its "Ids are the program's" deviation note.
2. **Step 1, typed wrappers, all module 0.**
   - Introduce the wrapper types in one shared place, and route every arena access through an accessor. There are about 600 direct `.decls[`/`.nodes[`/`.funcs[`/`.items[` sites; count them per stage when you start.
   - Replace each `-1` "none" with `Id?`.
   - Behaviour is identical: each stage's dumps stay byte-identical, which the golden lanes and fixpoint check.
   - It can land stage by stage, with a raw-to-wrapper conversion at each boundary until both sides are done. Split it into sub-units per stage if it's big; the lead reviews the split first.
3. **The guard:** a check that no dump, record or diagnostic prints a raw arena index. Since every id is a typed wrapper after step 1, the check can be a lane over the dump-rendering funnel, or a rule that a wrapper has no `Printable` except through its symbolic renderer.

- **Pins:** the byte-identical dumps are the main evidence; the guard's own fixture; and a unit test of the packing (the module and index round-trip, module 0, the boundary values).
- **Done when:** §3.0 is amended, every id kind is a wrapper, there are no `-1` id sentinels, and the guard runs in `run.py`.

Two additions for step 1 (Air), both within the ruling.
1. **Measure it; it touches the hottest data.** `Id?` in place of a `-1` Int is likely 16 bytes where it was 8 (tag plus payload; I'm not aware that Saw gives `Optional` a niche), and the change reaches every arena row that holds an optional id: MIR parents, resolve bindings, mono items. SL-591's profile found sawc2's self-compile dominated by `Vector.push` and allocation. Add to done-when: the self-compile `build --emit-ll -O2` time and Stage 2's peak RSS, before and after, as SL-592 and SL-523 reported theirs. If it regresses, that's data for a niche or packed-sentinel representation behind the `Id?` API, not a reason to bring back `-1`.
2. **Keys go through the wrapper too.** 'Never mix encodings within one id kind' is enforced at module-0 detection, but the index structures (`res_index`'s `first`/`add`/`value`, the dedupe maps) key on raw Ints today. If step 1 converts to raw at those boundaries, a later step can key one map with module-0 raw values and another with migrated ones, and they silently disagree. So give those structures typed-key variants in step 1, or put them under the no-raw-index guard, so the only place a raw index exists is inside the wrapper and the arena accessor.
