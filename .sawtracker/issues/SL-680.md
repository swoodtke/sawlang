## Description

**A `try` block whose `try`s raise two error types needs the closed error union** (left by SL-670, t670try).

The spec and Stage 0 build a closed union of the error types a `try` block's `try`s raise. Stage 0 does this even when one of them is `Box<any Error>`. sawc2 refuses it as `slice.not-yet.error-union` (fixture `typecheck/refuse/slice.not-yet.error-union.saw`). Implementing it needs a type for the union across typecheck, mono, the target layout and the LLVM backend: its representation, its `match` arms in the catch, and how `error` is typed there. See SL-670's stop comment.

**Owed:**
- the representation, decided with the Air before dispatch, or with the user if the spec leaves a visible choice;
- the catch's typing of `error`;
- the lowering;
- pins against Stage 0, including A6's moved row `coro_try_block_two_error_types` once suspending.

**Unblocks:** A6's `coro_try_block_two_error_types` lifted limit (SL:coroutines §4, A6's amendment).
