**Owning values through task roots** (`.build/scratch/air-review/sl560/owning_tasks.saw`, a `NoCopy` type with a printing deinit; the run pins use `Int` and `String`). Built by the patch at -O0 and -O2, and by Stage 0:

`drop 1|keep -> 1|made 2|drop 3|quick -> 13|drop 4|cancelled keep -> 4|drop 5|after discarded join|main returns|drop 2|drop 6|drop 7|`

All three are identical. Every value drops exactly once and where it should:
- an argument a suspending root owns (1) drops at the task's end;
- an owning result joined into a local (2) drops at `main`'s end;
- a never-suspending root, framed anyway, drops its argument (3);
- a cancelled-then-joined task still runs its code and drops its argument (4);
- a joined result discarded as a statement drops at once (5);
- a detached task's owning result (6) and argument (7) drop at the background close, after `main` returns.

**The framed-`main` path, through the std change** (`framed_main.saw`: `main` yields, spawns, joins one task and detaches another): `drop 1|joined 1|main returns|detached ran with 2|drop 2|` at -O0, -O2 and on Stage 0.
