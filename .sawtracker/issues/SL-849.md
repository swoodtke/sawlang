## Description

**A `borrows` method called without `borrow` is accepted in some positions** (found by the sawtracker port measure, Oct 23; probes `st_measure/probes/p1*.saw` and `p4b.saw`).

The spec says a `borrows` method "is called only through the `borrow` construct". But `doc.as_array()!.len()` (`as_array` is `borrows`), with no `borrow`, passes every stage, and p1 builds and runs. In a `for` range head, the unmarked call holds its window for the WHOLE loop (`loan.window-root` on a later use, p4b); the same head written with `borrow` closes at the statement (p4 builds, prints 2). About 272 lines of sawtracker still make unmarked calls (UNVERIFIED, grep).

Two things to settle, then fix:
1. **Rule:** is the `borrow` prefix required at every call of a `borrows` method (as the spec reads), or only where the lend outlives the expression? The construct's section is marked "Status: planned" though sawc2 implements it; reconcile the status line too.
2. **If required:** the checker refuses an unmarked call, with a fixit, at every position (obligation 1: one funnel or a position matrix). If not required: an unmarked call's window must end where the `borrow` form's would, since a whole-loop window from an unmarked head is a silent semantic difference.

**Air, on the rule (question 1):** the standing doctrine settles it toward **required at every call**. The user's rulings make reader-visibility trump inference: "infer when accurate, be explicit where inference would guess; READER-VISIBILITY TRUMPS both (the call-site `&var` precedent)".

A `borrows` call opens a window: storage is lent, the place is charged, and a later use can be refused. That's the same reader-relevant fact `&var` marks at a call site. If the prefix is optional "where the lend doesn't outlive the expression", a reader must work out the window's extent to know whether a mark was owed. That inference is exactly what p4b shows going silently wrong: an unmarked `for` head holds its window for the whole loop, while the `borrow` head closes at the statement.

So the second half of option 2 (an unmarked window must end where `borrow`'s would) would make the two spellings mean the same thing while only one says so. Requiring the prefix leaves one spelling, one meaning, and the window visible where it opens. The ~272 unmarked sawtracker lines are a mechanical migration that a fixit makes cheap. That also settles the section's "Status: planned" line as the spec's own reading.
