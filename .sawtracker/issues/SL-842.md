## Description

**A type parameter named the same as a visible type is an error** (user ruling, Oct 23, SL-425 c26; SL:hazards L9).

`extension Holder<Cmd>` beside `enum Cmd`: Stage 0 reads `Cmd` as a type parameter and sawc2 as the concrete type. The ruling makes the ambiguity an error, consistent with "shadowing is an error" (design 100). Extending one concrete instance stays a planned feature ("generic specialized extensions").

**Positions:** a generic function's, method's, struct's, enum's, trait's and extension's type parameters; a const generic. Each × a name that collides with a type visible there (a local type, an imported bare name, a prelude type, a qualifier). The diagnostic names both the parameter and the type it shadows, with a hint to rename the parameter.

**Pins:** each cell. Retire the remaining `name-collision` (type-parameter) check in `compiler/tools/subset_check.py` and the L9 entry in SL:hazards.
