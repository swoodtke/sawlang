## Description

**A `borrow` argument that is the lent place itself keeps its window to the end of the statement; the spec says the call** (found by p844, SL-844, Oct 23; pre-existing).

`look(borrow h.get().name)`, where the argument is a reference into the lent place (no fresh value crossed), holds the accessor's window until the end of the enclosing statement, so the epilogue runs after the rest of the statement. The spec says a borrowed argument's window is the call. SL-838 closes a value-only read at the read, and SL-844 closes at a crossed fresh value; this by-reference argument case is the remaining one.

**Scope:**
- the argument's window closes when the call returns, so the epilogue runs before the next operand or statement part (pin the print order);
- obligation 4: a `borrow` argument in each call position (a plain call, a method receiver's argument, a nested call's argument, an interpolation segment, an operator operand that takes a reference), × the lend {unconditional, conditional `!`};
- borrowck goldens may move only by earlier closes.
