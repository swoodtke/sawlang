## Description

**An unsuffixed integer literal above `Int.max` with no expected type is accepted, and wraps silently** (SL:hazards S7; found by the SL-425 sweep, c7, on sawc2 at main and on the seed alike, at -O0 and -O2).

- `print(18446744073709551615)` prints `-1`.
- `let x = 9223372036854775808` binds `-9223372036854775808`.
- The same literal is refused at `let x: Int =` and beside an `Int` operand (`type.mismatch ... does not fit in Int`), and keeps its value at a `UInt64` slot.

"Never hide errors": a literal whose value its default type can't hold must be refused.

**Mechanism (UNVERIFIED, from the sweep):** the range check runs against an expected type, and the default-to-`Int` path skips it.

**Obligation 4:** every position where a literal takes its DEFAULT type rather than an expected one:
- `let` without an annotation;
- a generic argument inferred from the literal;
- an interpolation segment;
- a format argument;
- a `print` argument;
- a tuple element;
- a collection literal element with no annotation;
- an operand beside another default literal.

Pin each.

**Retires:** the subset checker's `int-literal-range` rule (it stays until this lands).
