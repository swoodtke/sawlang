**Found by SL-505 (u7skel) while pinning mono's depth backstop.** Typecheck's body verifier reports an INVARIANT for every recursive call of a generic function, so no stage after typecheck sees one, and `sawc2 build` cannot build a recursive generic.

**Repro** (`sawc2 typecheck --check --std-root std`):

```saw
func count<T>(x: T, n: Int) -> Int {
    if n == 0 {
        return 0
    }
    1 + count(x, n - 1)
}

func main() {
    print("{}", count(true, 3))
}
```

gives `INVARIANT rec_generic 5:9 a call's instantiation names its own target's parameter`.

**Mechanism.** `compiler/typecheck/src/bodyverify.saw` (the call check, around the `mentions_decl_param(arg, c.target)` test) treats an instantiation that names the target's own parameter as a broken invariant. That is exactly what a recursive call inside the generic body records, `count<T>` at `T`: the parameter is the caller's own, and the caller is the target. The check means to catch an instantiation leaked from the callee's signature, but it cannot tell that from a call made inside the target's own body. Polymorphic recursion (`f<T>` calling `f<Wrap<T>>`) trips it the same way. That case is what SL:architecture §3.8 rules should be refused, with a located diagnostic (SL-507), not reported as an invariant.

**Siblings to sweep:** a recursive generic method, where the instantiation names the method's own parameter; a method of a generic type calling itself, where the owner names the type's parameter, a path the check may or may not share; mutual recursion between two generics, which does not trip this check because the targets differ, so it is worth a pin.

**Owner:** typecheck (tcb2c's lane). SL-505 makes no change there. Its run lane has no recursive generic program until this is fixed.

**Landed:** the body verifier judges an instantiation by its body's scope (`mentions_unseen_param`, `param_visible`), so recursive generic calls (direct, swapped, a generic method at its own parameter, from a closure) are accepted, and a genuinely wrong instantiation still raises the invariant (injection unit program). Polymorphic recursion passes typecheck and is refused by `mono.depth`; SL-507 still owes the real check. Pins: golden `generic_recursion`, run program `generic_recursion`, `mono.depth.recursive`.
