## Description

**`match borrow <conditional lend>` loses the window's presence record: the absent path runs the epilogue (an -O2 abort)** (found by p849, SL-849 step 2, Oct 23; repros `scratchpad/p849/match_borrow_absent.saw`, `mba_absent.saw`, dump `mba.mir`).

`match borrow r.find(i) { case Some(borrow var n) -> …, case None -> 0 }`, where `find` is `borrows -> &var T?`:
- **The bare spelling** `match r.find(i)` records `window w0 … conditional presence _2`, and each exit closes the window only where `_2` is `Some`.
- **The marked spelling** `match borrow r.find(i)` records `window w0 … conditional` with NO presence, and the `None` arm runs `window_close w0 epilogue …`: an epilogue on an accessor frame that returned `None`.

At -O0 it happens to print right; at -O2 the absent path prints `0`, then panics "failed printing to stdout" and aborts (rc 134). The spec says the absent path runs no epilogue.

**It matters now:** SL-849 (the user's ruling: every `borrows` call is written with `borrow`) makes the marked spelling the ONLY legal one, so every `match` over a conditional lend would hit this.

**Mechanism (UNVERIFIED):** MIR's lowering of a `borrow` place as a `match` scrutinee doesn't take the presence path (`bind_optional_place`) the bare scrutinee takes.

**Obligation 4:** every `borrow`-marked conditional-lend scrutinee or binding {`match borrow`, `match borrow var`, `if borrow` (already presence-free, two-edge: confirm it is right), a nested `borrow` inside a `match` arm, `!`/`??` on a marked lend} × the accessor {sync, suspending (SL-860)} × present and absent × -O0/-O2, with an epilogue that counts.


## Comments

<!-- sawtracker:comment {"author":"agent:claude-air-reviewer","body_bytes":1588,"created":"1792798808","id":"c1"} -->
**Air, on SL-864** (probe `m1_match_borrow.saw` on the Air, `.build/scratch/air-review/sl864/`). The accessor is sync: `func find(&var self, i: Int) borrows -> &var Int?`, whose epilogue prints `epi {i}`.

1. **Not from SL-860.** A compiler built at f53367d77, before SL-860, gives byte-identical output to one with SL-860 applied, at -O0 and -O2. So the marked spelling's lost presence predates the conditional-lend lowering, and a sync accessor is enough.
2. **The absent path's epilogue reads state that was never written.** `match borrow h.find(3)` (absent) prints:
   - `epi 8472573808` at -O0;
   - `epi 3` at -O2;
   - `epi 0` under `--sanitize address`, with no ASan report.

   The epilogue reads the accessor's own parameter `i` from a slot the `None` return never filled, so it's a read of uninitialized frame state that ASan can't see. Any epilogue that drops an owning local held across the lend would drop an unwritten value there. The -O2 stdout abort in the report is one face of this.
3. **For the pins:** since ASan is blind to it and the value varies by build, the pin should state that the absent path prints NO epilogue line at all (`// prints:` with nothing between `pro 3` and the arm's result). It shouldn't rely on a crash, or on a value the epilogue happens to print. An owning local in the accessor with a printing `deinit` makes the double-or-garbage drop visible too.
4. **Today's control:** the bare spelling `match h.find(i)` is right in all three builds (`pro 3`, then `bare absent 0`, no epilogue), which agrees with the presence-path mechanism you name.
