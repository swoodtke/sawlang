**3. - 349 records; 59 programs sawc2 refuses, which leaves 290.
- **254 agree** and 36 differ. Every difference is explained:
  - **~22, generic instances.** sawc2 names a generic's frame by its declaration (`run`), and Stage 0 by its instance (`run$m$$1$Fast`). The SYMBOL field still tells instances apart (`… run(w: T) inst Slow` / `inst Fast`), so a walker can.
  - **~10, Stage 0's `$spawnroot` duplicates.** Stage 0 gives a function that is both a spawn root and an embedded callee a second frame; sawc2 has one item and one frame.
  - **3, line-shifted.** Records marked `twin differs`, where Stage 0 compiled the twin. That's my comparison's artifact, not the table's.
  - **1, `net_unroutable_connect_names_the_cause`.** Stage 0's frozen std.net differs (a method `TcpStream.resolve_first`), plus note 2 below.
  - **1, `coro_omitted_default_arguments`.** Stage 0 lowers frames for `suspend_seed_local`/`suspend_seedN`, which nothing calls. sawc2 lowers only reachable items, and no task can be parked in one.
- The state-word column is 0 throughout because sawc2's packed layouts put the state word first, and child offsets follow from that.

**The lead's c4 scope:**
- The fold is ONE predicate (`coro_bt_folds`), and it decides by property: std, not a task root, no `Drive` or `ParkOffload` point. 1b-ii's `Thread.join` default, whose only point is a park, will fold into a leaf park on the caller's line with no encoding change.
- The goldens cover the three shapes: `worker → middle → leaf` (three deep), `watcher` (a root that parks directly), and `step`/`handle`/`worker` (several states).
- The exec descriptor is absent (`exec=absent`).

**Gates:** `run.py --only subset,coro` passes.

**Notes, none blocking:**
1. **The lane compares by display name** (`bt_parked` returns a dict keyed by name). A future golden with two instances of one generic would compare only one of them silently. Keying by the symbol, or by (name, position), closes that before a generic golden is added.
2. **The fold isn't transitive.** A std frame that drives a folded one keeps its place, so module-private helpers stay in every network task's chain: `std.net.park` (drives `io_wait`, leaf at net.saw:306) and `charge_io_budget` (drives `yield_now`, net.saw:322). That's within c4's ruling. If the intent "a dump names the program's line, not std's" should reach them, the rule could fold module-private std helpers whose points are all parks or drives of folded frames, while keeping public API frames such as `TcpStream.read`, as Stage 0 does.
3. **`@llvm.used` has one emitter today** (`bt_table_global`). A second user, say `@export` retention later, would emit a second definition, which LLVM rejects. When that comes, both should go through one list.
