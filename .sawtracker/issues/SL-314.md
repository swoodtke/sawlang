## Description

Found by SL-303 (M20) and reconciled by design 274 §2a as a NEW Class-1 finding. Reproduced Sep 17: tools/dump_ast.py accepts 'func f() { x = 1 y }' and 'func f() { x += 1 y }' as an assignment followed by a separate expression; the same for 'let x = 1 y' and 'g() h()'. LANGUAGE_SPEC.md:56: 'A statement ends at the end of its line. There are no semicolons.' — so this is a silent misparse, not a grammar choice; it predates assignments and SL-73 records the adjacent-expression face. The prototype parser refuses at the second statement ('expected statement boundary'). RULING OWED (design 274 §4 item 1): lead recommends REFUSE at the second statement's first token, matching the prototype; the alternative is to document the permissiveness and make the prototype match. Unit: design 274 U0' once ruled. No current candidate example uses the shape; the strict comparison would fail if one did.
