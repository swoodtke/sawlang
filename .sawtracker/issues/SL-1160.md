## Description

**`blade test` hides why a test program failed to compile.** Found by SL-1154's implementer (Nov 17): sawc writes its diagnostics to stdout, and `Tester.shell_ok_loud` (`blade/src/tester.saw`) discards stdout (its comment says diagnostics go to stderr), so a test whose compile is refused shows only `test X ... FAILED`, with no `ERROR` line. Checked: `sawc ... 2>/dev/null` still prints the `ERROR` lines. Never hide errors: `blade test` shows a refused compile's diagnostics (and `blade build` likewise, if it has the same shape: check every site that runs sawc and discards its stdout), with a lane row holding a refused test's message.

Related: SL-1154, SL-1152 (a test's time limit).
