## Description

Unit B of SL-209 (ownership uniformity). Plan step 4. Folds in and CLOSES SL-79 (DF-305a). Depends on Unit A.

## Handle forwarding and control flow structurally
Build on `_value_branch_arm_results` (`sawc/typechecker/types.py:4327`), distinguishing three kinds of expression:
- FORWARDS an existing value: block tails, branches, appropriate casts and wrappers.
- CREATES a new value.
- EXPOSES borrowed storage.

Rules:
- Forwarding must preserve the source's ownership obligations. Adding parentheses, a block, or an Optional/Result wrapper must NOT turn an alias into a fresh temporary.
- Keep ownership state PATH-SENSITIVE. Both branch arms start from the same incoming state; their outgoing states merge according to reachable paths. Checking one arm must not make the other appear to move an already-moved value. Diverging paths contribute no fall-through state.

## Folds in SL-79 (DF-305a — "check ownership before Optional/Result return auto-wraps")
The Optional/Result return auto-wrap is exactly a FORWARDING position: today the wrap can happen without the ownership check the plain return receives. Route it through the same forwarding taxonomy so ownership is checked BEFORE wrapping, same-module and imported, at argument/return/field positions. Landing this unit closes SL-79.

## Acceptance
Equivalent expression spellings agree; moves remain legal on mutually exclusive paths; use after a possible move is rejected; the auto-wrap-before-check hole (SL-79) is closed with SL-79's own minimal repro promoted to a regression test.

## THE RULING (SL-79 carried it)

DECIDED: the wrap is TRANSPARENT. `func opt(r: Res) -> Res? { r }` is refused too, so one `?` no longer changes whether a `move` is written. Three reasons, weightiest first: (1) the alternative does not close the bug — an implicit-move reading leaves every ALIASING source double-freeing and would need the aliasing test anyway; (2) it deletes a spelling difference nobody could explain; (3) one rule at one chokepoint is auditable.

MEASURED MIGRATION COST: ONE LINE, across sawc/std, blade, libs, devtools and the whole corpus — `sawc/std/json.saw:1316`, `return v` -> `return move v`. The shape the ruling worried about is essentially unwritten in practice, which is the strongest argument for taking it.
