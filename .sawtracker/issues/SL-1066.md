## Description

**The patch gate builds its venv from a bare `python3`, which is Xcode's Python 3.9 on the gate machine since Homebrew relinked Python today; every SL patch now fails before a test runs.** Found by the lead on Nov 12, from SL-799.p2's gate log.

**Evidence.**
- SL-799.p2's run (`patch log SL-799.p2`): `compiler tests FAILED, exit 1 (0s)` with `TypeError: dataclass() got an unexpected keyword argument 'kw_only'` (`compiler/tools/ast_nodes.py`), and `fixpoint FAILED` with `TypeError: extractall() got an unexpected keyword argument 'filter'` (`compiler/tools/seed.py`); the traceback's frames are `/Applications/Xcode.app/…/Python3.framework/Versions/3.9/lib/python3.9/`.
- On the gate machine now: `which -a python3` gives only `/usr/bin/python3` (3.9.6). `/opt/homebrew/bin/` holds `python3.14` and no `python3`; its links are dated Nov 12 10:33 (python@3.14 3.14.10), so an upgrade this morning relinked the versioned names only. The last passing gate run was Nov 11.
- `build.sh`: with no `SAW_PYTHON` and no `.venv`, it runs `python3 -m venv .venv`. The server tests each patch in a fresh worktree, which has no `.venv`.
- The patch under test changes one run-lane probe; it is not the cause.

UNVERIFIED: that an unversioned `/opt/homebrew/bin/python3` existed before the upgrade. The passing run on Nov 11 and today's link dates are the evidence for it.

**Fix (this issue).** `build.sh` picks the interpreter it makes the venv from: the newest `python3.N` on PATH, then `python3`, taking the first that is Python 3.12 or later (the tools use `dataclass(kw_only=…)` and `tarfile`'s `filter`), and refuses with one clear line when none is, or when an existing `.venv` is older. `SAW_PYTHON` is used as given, as before. CLAUDE.md's "Python environment" says so.

**Machine-side remedy, the user's:** restoring an unversioned `python3` that is 3.14 on the server's PATH, or giving the server `SAW_PYTHON`, also clears it at once, without this patch.

**After it lands:** `patch retest SL-799.p2`, and every patch that failed in the window.
