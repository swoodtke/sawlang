**There is no runtime-provider package a freestanding image can depend on outside `tests/freestanding/`.**

Found by SL-1182's lz4 dogfood (surprise log item 9). `libs/lz4/image` depends on `tests/freestanding/core` for its runtime seams, boot stub and linker script, by a relative path into the test tree.

**The request** (packaging, unruled): a published minimal runtime-provider package, for example `libs/rt-qemu-virt` with per-arch tables, that examples and libraries can depend on, so test fixtures stay test fixtures. sawos has its own HALs; this one is for sawlang's examples and lanes.
