## Description

`match mk(n) { case x -> take(move x) }`, `match move s { case x -> … }` and `match mk(n) { case "zz" -> …, case z -> take(z) }` each give the drops verifier's INVARIANT: the match's temporary gets no drop, and no ownership hand-off, on the path of the arm that binds it whole. 45 cells of SL-844's matrix (every `match`-scrutinee use with an owning field) hit it. **Mechanism (UNVERIFIED, p844):** in `lower_match` / `hold_parts`, a whole-binding pattern over an owned scrutinee temporary neither moves the temporary into the binding nor schedules its drop.
