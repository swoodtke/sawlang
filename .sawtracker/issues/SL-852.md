## Description

**A `match` over an owned temporary whose arm binds all of it trips "owned local _N may still be live at a `return`"** (found by p844, SL-844 step 1, Oct 23; probes `scratchpad/p844/faces/s1_match_call.saw`, `s2_match_local.saw`).

`match mk(n) { case x -> take(move x) }`, `match move s { case x -> … }` and `match mk(n) { case "zz" -> …, case z -> take(z) }` each give the drops verifier's INVARIANT: the match's temporary gets no drop, and no ownership hand-off, on the path of the arm that binds it whole. 45 cells of SL-844's matrix (every `match`-scrutinee use with an owning field) hit it. It needs no field hop, so it's a separate mechanism from SL-844's `take_from_temporary`.

**Mechanism (UNVERIFIED, p844):** in `lower_match` / `hold_parts`, a whole-binding pattern over an owned scrutinee temporary neither moves the temporary into the binding nor schedules its drop.

**Obligation 4:** scrutinee {call result, `move` local, `??`, `!`, a getitem copy} × pattern {a bare binding, a literal-then-binding, a guarded binding, an enum payload binding, a tuple pattern binding all parts} × arm use {consumed, borrowed, unused}. Pin each cell with `// leaks: none`.
