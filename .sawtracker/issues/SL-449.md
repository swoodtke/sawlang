Stage 0 (the frozen Python compiler): comparing a fixed-width integer with an integer module static of a different width fails with an LLVM verifier error. The typechecker adopts the static to the peer's width, and codegen still emits it at its declared width.

Repro:
    static SHIFT: Int = 3
    func check(flag: UInt32) -> Bool { flag >= SHIFT }

Error: '%SHIFT' defined with type 'i64' but expected 'i32' (icmp uge i32).

Loud (the build fails), and frozen per the Sep 24 freeze. Ledgered as SL:hazards L21. Found by the SL-447 U6b2 widening golden. sawc2 types it correctly (a bare static adopts as an operator's peer).
