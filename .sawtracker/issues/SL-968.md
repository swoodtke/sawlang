## Description

**The std module list comes from the compiler, so every new std module costs a seed bump.** Found by SL-965's census.

`loader.saw:load_new_std_modules` loads a fixed list of std modules. A std file that imports an unlisted module fails every build with `import.unknown-module` (`.build/scratch/p965/probe_newmod.saw`). The seed builds Stage 1 against the checkout's `std/`, so a new std module first needs a compiler that lists it and then a seed bump.

**Direction:** the std root lists its own modules, with the list read from the root (a manifest file, or the directory with an order rule), and the compiler keeps no list of its own. This is a loader-contract change with its own consumers: Stage 0's records, the std cones, design 82/150's prelude rules, and freestanding profiles that load a subset. The design starts with a census of every reader of the list.
