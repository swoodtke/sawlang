## Description

Found by the SL-345 implementer (Sep 24). The bug predates SL-345 but matters more now: SL-345 refuses a read-only visitor that implicitly captures a &var parameter and tells the author to write [&v]. In a DRIVEN (suspending) body that spelling is itself refused: 'self.v.deref(…) lends a place … ExplicitCopy'.
