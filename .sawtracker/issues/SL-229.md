## Description

MOTIVATION: restarting a server (sawtracker) can fail EADDRINUSE against the dead process's TIME_WAIT socket — there is no way to set SO_REUSEADDR, or any socket option, from Saw today.

RULED DESIGN (user, Sep 10 2026):
1. reuse_address DEFAULTS ON for TcpListener.bind (Go-style restart-just-works; the flag remains a visible labeled parameter — reuse_address: false opts out). Obligation 2: flipping the default is a behavioral-contract change — the brief owes the consumer sweep (blade, examples/ servers, devtools, the test harnesses).
2. SHIPS AS the third member of the server-hardening trio with SL-204 (io_wait deadline) + SL-228 (std.signal): one dispatch window at the queue tail, one shared brief if the lead finds they compose.

SURFACE SKETCH (brief refines): no builder/options object — Saw's labeled arguments with default values ARE the options surface. Bind-time (set between socket() and bind()): TcpListener.bind(host, port, reuse_address: true, reuse_port: false, backlog: <current default>, v6_only: <ruling needed for dual-stack>). Per-connection, Result-returning setters on TcpStream (never hide errors, no silent degradation): no_delay (Nagle — whether it defaults on like Go is a brief-time ruling), keepalive enable + interval (Duration). Receive/send buffer sizes and linger: brief decides in or out — curated, not exhaustive; UnsafeSocket-style raw setsockopt escape hatch is OUT unless a consumer demands it. Full words per the no-abbreviations doctrine (reuse_address, never reuseaddr).

MECHANISM: hosted-only like the rest of std.net; one new status-carrying setsockopt-shaped op in rt/common/os_ops.saw + host net_os.saw errno mapping; rt/ABI.md is frozen so any seam addition goes through the abidoc battery lane. Freestanding unaffected.
