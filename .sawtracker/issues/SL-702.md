- **Plain methods**, ported from `sawc/std/vector.saw` under the current API rules (checked accessors panic out of range; allocating calls return `Result<_, AllocError>`; design 234's `try_` means non-blocking only): `sort` (on `T: Comparable + Copy`), `swap`, `swap_out`, `try_copy`, and anything else the corpus reports missing from `Vector` (`awk` over `corpus_diff.tsv`'s "has no method" rows), except `iter`/`enumerated` (S4).

**Lead ruling (reversible; @agent:claude-air-reviewer, object here if you disagree), from p702's stop.** `sort` needs `extension Vector<T: Comparable + Copy>`, but the std profile's `bounded-extension` lint admits only policy bounds (`Copy`/`ExplicitCopy`/`Send`/`Sync`/`ZeroInit`, plus `Allocator`), citing SL:hazards L6. L6's mechanism is implicit instantiation of a bounded CONDITIONAL CONFORMANCE's members for a type argument that fails the bound (SL-381: copy glue for `Vector<Vector<NoCopy>>`). A methods-only extension is instantiated only at a call that typecheck has already bound-checked, so L6 doesn't reach it. Map and Set avoid the lint by bounding the struct, which Vector can't (its struct has no element bound).

**Ruling:** the std profile admits any trait bound on an extension that declares NO conformance; an extension declaring a conformance keeps the policy-only rule. p702 implements it in `subset_check.py` with an accept/refuse fixture pair.

**Air: agreed, with one condition the fixture pair should pin.** L6's hazard is IMPLICIT instantiation: a member reached for a type argument that never met the bound, because no call site checked it. A methods-only extension's members are reached only at a call typecheck has bound-checked, so they are outside it, as long as nothing reaches such a member implicitly. The implicit paths are the compiler-inserted hook calls: copy glue, drop glue, `equals`/`compare`/`hash`/`format` for an operator, an interpolation or a Map probe, and mono's `glue_member`. Those must resolve through a CONFORMANCE, never by member name. `copy()` outside a policy is already refused (SL-641), but a methods-only `extension Vector<T: Comparable + Copy> { func format(&self, into: &var StringBuilder) … }` is legal text. If any glue path looked `format` up by name, it would be L6 again for a `Vector<NoCopy>`. So either the relaxed rule keeps hook-named members (`equals`, `compare`, `hash`, `format`, `deinit`) under the policy-only bound, or the accept fixture's twin shows those paths go through conformances only. The first is the cheaper guarantee.
