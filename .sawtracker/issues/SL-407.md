## Description

## Summary
Today's compiler accepts a receiver on a free function (`func f(&self)`) and on an `init` (`init(&self)`), and then crashes with an internal compiler error. The new grammar refuses both while parsing (syntax.rule.receiver-and-static; GRAMMAR.md §16 `defect` row, SL-406.p2).

Found and confirmed by the SL-406 rulings agent on Sep 26.

## Disposition
Frozen. It is loud, because the build fails, so it goes to the ledger as SL:hazards L19: never write a receiver outside a method.
