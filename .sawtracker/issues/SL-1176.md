## Description

**A seam export that agrees with ABI.md's width class but not with std's extern is not caught.** SL-1175's `export.signature-disagree` skips `__saw_rt_*` exports, because the export funnel judges those (`export.reserved`, or `export.seam-signature` inside a runtime compile). `export.seam-signature` compares only ABI.md's width classes, so a runtime exporting a seam as `Int` where std declares a pointer (both "word") passes. In a `--freestanding --runtime` compile, where std's extern and the runtime's export are in one compile, that is the SL-1175 hole for seams.

To do: in a runtime compile, judge a seam export against std's extern of it with SL-1175's agreement rule, after `export.seam-signature` (so the existing fixtures keep their first error). Pin a seam exported as `Int` against std's pointer. Related: SL-1175, SL-1159.
