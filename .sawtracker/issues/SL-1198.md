**Release v0.24.5.** The project owner ruled on Nov 25 that v0.24.5 is tagged once SL-1150 and SL-1161 land. sawos moves its pin to it for SO-141.

**The patch:** `.sawtracker/version` becomes `v0.24.5`, and `driver_version()` in `compiler/driver/src/main.saw` becomes `"0.24.5"`; run.py's `version` step holds the two equal. The server creates the annotated tag at the patch's merge commit. It is submitted after SL-1150.p1 merges, so the tag holds it.

**What v0.24.5 holds beyond v0.24.4:**
- **SL-1150, `Task.spawn` freestanding.**
  - A freestanding runtime that declares `__saw_background_drive` and `__saw_background_close` owns the thread's background group: it drives the group between its own waits and closes it at the thread's end.
  - Under such a runtime, the deadlock report stands down to the runtime's poll.
  - A runtime never drives from a seam's body.
- **SL-1161, complete: a join and a group's teardown in a task park.**
  - A `TaskGroup` local whose scope ends in a suspending frame parks until its tasks finish. The cases that keep the nested sweep are listed in the spec.
  - The window-drive fence (`coro.window-drives`): inside a static root's exclusive `borrows(sync)` window, nothing may reach the executor's sweep. That covers a teardown, a drive, a blocking join, an `extern` with no body, and a call through a function value of unseen origin.
  - runtime/ABI.md: no seam runs program code on the caller's thread.
- **SL-1156 U7c:** a closure, `FuncPointer`, erasure or hook that reaches a static root is refused where it is made.
- **SL-1190, split codegen by default:** a hosted `sawc build` compiles one LLVM module per Saw module, in parallel. That means ThinLTO above `-O0`, and no LTO at `-O0`. `-c` and `--freestanding` keep one unit. Leftovers from a killed build are reclaimed.
- **SL-1197, sosimg `rt_map`:** the header carries the realtime bands' levels, and `[sos] priorities` takes `rt0` to `rt3`. The header is version 4 only when the word is nonzero, and a loader opts into version 4 with `reads_rt_map: true`.

**For a project moving its pin from v0.24.4 (sawos):**
- **The runtime:**
  - sosrt's seams must not run program code on the caller's thread;
  - a runtime that owns the background group defines its drive and close loop (SL-1150's ABI section).
- **Possible new refusals:**
  - `coro.window-drives` inside a static root's exclusive window;
  - SL-1156 U7c's creation rules.
- **sosimg:** `reserved0` is `rt_map`, and `has_known_version()` stays at version 3 until the loader passes `reads_rt_map: true`.
- **Builds:** freestanding objects are unchanged (one unit). Every package rebuilds once (a new `--build-id`).
