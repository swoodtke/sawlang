**Found by:** sl543 (SL-543), building the ruling's accepted control, the Air's guarded const-generic shift.

**The defect:** `sawc2 build` refuses every instantiated body that reads a const generic parameter as a value, as `backend.not-yet`: "the constant `N` is not in the backend slice yet". Stage 0 builds and runs it.

```saw
func width<const N: Int>() -> Int {
    N
}

func main() {
    print("{}", width<3>())
}
```

Stage 0 prints `3`. sawc2 refuses at 2:5.

**Mechanism:** MIR lowers a const parameter read as a value to a `MirConstKind.Generic` operand ("folded per instantiation", `compiler/mir/src/model.saw`). Nothing downstream folds it: no stage reads `MirConstKind.Generic`, so mono hands the backend the instance with the operand unsubstituted, and `const_value` in `compiler/llvm/src/places.saw` has arms for `Int`, `Bool` and `Builtin` only, so it reaches its refusal. Every position that reads `N` is the same operand: a tail, an operand (`N - 1`), a comparison (`N > 0`), an argument.

**Pinned by:** run program `const_generic_shift_guard` (SL-543), as a `// due:` program refused by `backend.not-yet`. Once the backend folds the operand from the instance's const argument, the due lines come off and the program compares with Stage 0's `1 8`.

Not worked around: the area (`compiler/llvm`, `compiler/mono`) is outside SL-543's scope.
