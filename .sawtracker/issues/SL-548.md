**Found by:** sl543 (SL-543), building the ruling's accepted control, the Air's guarded const-generic shift.

**The defect:** `sawc2 build` refuses every instantiated body that reads a const generic parameter as a value, as `backend.not-yet`: "the constant `N` is not in the backend slice yet". Stage 0 builds and runs it.

```saw
func width<const N: Int>() -> Int {
    N
}

func main() {
    print("{}", width<3>())
}
```

Stage 0 prints `3`. sawc2 refuses at 2:5.

**Mechanism:** MIR lowers a const parameter read as a value to a `MirConstKind.Generic` operand ("folded per instantiation", `compiler/mir/src/model.saw`). Nothing downstream folds it: no stage reads `MirConstKind.Generic`, so mono hands the backend the instance with the operand unsubstituted, and `const_value` in `compiler/llvm/src/places.saw` has arms for `Int`, `Bool` and `Builtin` only, so it reaches its refusal. Every position that reads `N` is the same operand: a tail, an operand (`N - 1`), a comparison (`N > 0`), an argument.

**Pinned by:** run program `const_generic_shift_guard` (SL-543), as a `// due:` program refused by `backend.not-yet`. Once the backend folds the operand from the instance's const argument, the due lines come off and the program compares with Stage 0's `1 8`.

Not worked around: the area (`compiler/llvm`, `compiler/mono`) is outside SL-543's scope.

**RULED (the user, Oct 29): a const generic parameter may have ANY INTEGER WIDTH** (`<const N: UInt8>`, `Int16`, …, `Int`/`UInt`). The spec's 'Int or UInt' line changes to match, and SL-920's per-width fit checks stay meaningful. `Bool`, `String` and every other non-integer type stay refused at the declaration (sawc accepts them today, p548's F2). This unit enforces that refusal.

**SL-548.p1 submitted** (2 units squashed, tip 645915dc5 on 93443cbe9). Must land after: nothing.

- **Unit 1, the value funnel:** `MirOperand.param` is set by `name_val` (`op_generic`). `MonoProgram.const_argument(k, param, ty)` (ENTRY POINTS `copy_operand`, `mono_check_instance`) returns the instance's value at the parameter's DECLARED width, or an INVARIANT, never a silent zero. `copy_operand` writes the value and keeps the `Generic` kind (so `-N` at `Int.min` still panics, not wraps). One backend `Generic` arm.
- **Const parameter types (user ruling c2):** any PRIMITIVE integer width. `Bool`, `String` and every non-integer type are refused (`type.const-parameter`). A distinct alias (`Byte`, `type Small = UInt16`) is refused too, naming the type it stands for (lead call; matches Stage 0). A parameter default may name a const parameter (`by: Int = N`).
- **Unit 2, per-instance `static_assert` (F1):** a condition naming a const parameter is deferred (`defer_assert`) and folded per instance from tables `mono_check_instance` fills through the funnel. A false assert, or one that faults at an instance (a shift by N out of range), now fails; before, it silently passed.
- **Pins:** stated probes `const_param_value_{positions,arguments,closures,methods,default,widths,slab_shape}` (the last is sawos's `slab.saw` shape), `coro_const_param_value` (sanitize lane), `_narrow_overflow` / `_negate_min` (panics), `const_generic_shift_guard` (now stated), `const_param_assert_holds`; refusal fixtures `type.const-parameter{,.string,.alias}`, mono `static_assert.failed.{const-parameter,const-and-layout,const-fault}`.
