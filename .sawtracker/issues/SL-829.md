## Description

**An unrepresentable float literal is accepted** (SL:hazards S20; the SL-425 sweep, c7; main and seed alike). The user's ruling on SL-722 Q2 (Oct 16) decides it: an unrepresentable float literal (±inf, or a nonzero value that rounds to zero) is an ERROR, and a subnormal is accepted. sawc2 instead:
- accepts a 400-digit literal, which becomes `inf` and compares above 1.0;
- accepts a literal below the least subnormal, which equals 0.0.

Stage 0's DF-276a (SL-68) is closed, and sawc2 never got the check.

**Where the check goes:** typecheck's float literal funnel `tc_float_bits` (SL-722 U2) already computes the exact bits, so it knows when the result is ±inf or a nonzero literal rounded to 0. Refuse there, naming the literal and its nearest representable value.

**Pins:**
- the two sweep cases;
- the largest finite and the least subnormal accepted;
- just above the max finite refused;
- a nonzero literal half the least subnormal refused;
- `0.0` and `-0.0` accepted;
- a constant expression folding to inf (Q2 covers only literals; say what the spec rules for folding, or mark it OPEN).

**Retires:** the subset checker's `float-literal` rule (S20 part; the rule is also an SL:architecture §4 blanket).

**Air: SL-829.p1 approved.** Reviewed r1 on origin/main 1ba34876b.

**The boundaries are IEEE's, ties to even included.** Saw float literals have no exponent, so I generated exact decimals (`gen_boundaries.py`, Python `Decimal`).
- **Accepted, printed shortest, -O0 and -O2 identical:**
  - the largest finite double, and a literal one unit below the halfway point above it: `1.7976931348623157e+308`, negated too;
  - the least subnormal, and half of it plus 10^-1100: `5e-324`, negated too;
  - `0.` with 500 zeros: `0.0`.
- **Refused `float.unrepresentable`:**
  - the halfway point itself (ties to even, so infinity) and its negation;
  - 10^309;
  - exactly half the least subnormal (ties to even, so zero);
  - half the least subnormal minus 10^-1100.

**Every position funnels through the two entry points.** `g3` refuses once each at:
- a `static` initializer;
- a plain (non-generic) default;
- a function tail;
- a `let`;
- an array element and a repeat literal;
- a tuple element and a struct field;
- a format argument;
- a comparison operand and an arithmetic operand;
- a value-`if` arm;
- a closure tail.

**Gates:**
- `run.py --only typechecker,subset,std_cone,std,fixture_whitespace,migrate,programs` passes, `std` included, so no std literal is newly refused.
