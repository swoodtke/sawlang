A MODULE-QUALIFIED call to an imported suspending GENERIC free function, sitting inside a driven body, is never framed: the driven frame's resume plain-calls the instantiation and the post-transform `sync` check then refuses the program.

```saw
// modules/alpha/lib.saw
import std.task.{yield_now}
public func outer<T>(x: Int) -> Int {
    let r = inner<T>(x)
    r + 1
}
func inner<T>(x: Int) -> Int {
    let r = leaf(x)
    r + 10
}
func leaf(x: Int) -> Int { yield_now()  x + 100 }

// probe4.saw
import alpha
func chain(n: Int) -> Int {
    let r = alpha.outer<Int>(n)      // QUALIFIED + GENERIC + embedded
    r
}
func main() { print("chain {} {}", __saw_drive(chain(1)), __saw_drive_steps(chain(1))) }
```

```
error: cannot suspend in `sync func` method: method `__Frame_chain.resume` calls
`outer$1$Int` → `inner` → `leaf` → yield_now (`leaf` suspends at line 27)
```

THE MATRIX that isolates the cell (all compiled on both compilers, byte-identical):
- `import alpha.{outer}` + bare `outer<Int>(n)` — WORKS: `chain 112 1`, three frames.
- qualified NON-generic (`inner.worker(n)`, `s.t.hop(n)`, K116) — WORKS.
- qualified GENERIC, `let`-bound or tail, statement position — REFUSED as above.
So the cell is qualified × generic × embedded. Not silent (a refusal), and the refusal is the post-lowering totality check design 275 U2 makes mechanical — but it is the wrong diagnostic: the program is sound, and the message blames the author's `sync` context for a frame the transform declined to build.

MECHANISM (named per obligation 4, from the diagnostic + the K116 evidence, not yet stepped in the debugger): `alpha.outer<Int>(n)` parses as a `MethodCall` carrying the typechecker's `module_free_call` stamp (SL-208). The generic PROMOTION (`_promote_nested_generic_calls`, now `FrameLedger.instantiation_is_boundary` + `rename_call_to`) walks `FunctionCall` nodes for generic instantiations to key and frame; a qualified generic call is not a `FunctionCall`, so its instantiation is never promoted, no frame row exists for `outer$1$Int` in the embedded position, and the call is lowered plain. SL-217 is the ROOT sibling of the same parser shape (a qualified suspending call cannot be a drive/spawn root); this is the EMBEDDED face, and it is the generic case only because SL-208 taught the non-generic classifiers about the stamp and the promotion was not in that sweep. In U1's terms: no consumer ever ASKED the ledger about this site, so the miss-is-an-ICE invariant never fires — which is precisely U2's coverage check (a): every reachable suspension site has a `SiteDecision`. Once U2 lands, this site must get one, and the shape table's answer is EMBED.

Workaround today: the selective import (`import alpha.{outer}`) and the bare spelling.
