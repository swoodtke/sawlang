## Description

**`compiler/tests/run/net_read_eof_and_error.saw` (from SL-570) is flaky under load.** One gate run, by SL-769's agent on a loaded machine, failed it at -O2: sawc2 printed `end of stream` where Stage 0's record has the reset error (`ConnectionReset`). Three reruns passed. The program uses no tasks: a socket reset races a close.

UNVERIFIED: whether the peer's RST arrives before or after the reader sees the FIN depends on scheduling, so the expected kind is not deterministic. A pin must not race.

**Fix:** make the reset deterministic, e.g. `SO_LINGER {on, 0}` on the closing end so `close` sends an RST with no FIN first, or read only after the peer's close is known complete. Otherwise split the program into the EOF case and a reset case whose order is forced. Re-record darwin and aarch64.
