## Description

This is from the Air's review of SL-408.p1 (non-blocking item 1). Some mistyped numbers lex as two tokens under §2.1's longest match. The parser then reports a juxtaposition error, which doesn't name the writer's mistake.

| text | lexes as | a better diagnostic |
|---|---|---|
| `0b102` | `0b10` `2` | `2` is not a binary digit |
| `0o78` | `0o7` `8` | `8` is not an octal digit |
| `2u9` | `2` `u9` | `u9` is not a width suffix; name the eight |
| `2_u9` | refused, hinting "write `2`" | the hint should name the eight suffixes, not drop the suffix |

**Fix, in compiler/lex:**
- A digit run is followed directly, with no space, by a decimal digit outside the base, or by an identifier that starts like a width suffix (`i` or `u` and digits). Refuse it as one lexical error at that character, under `syntax.expr.int`, with the message above.
- `2_u9`'s hint names the eight suffixes.
- Add a unit test, a golden and a negative case for each row.
- §2.1's longest match keeps deciding the tokens everywhere else.

This is small and low priority. It can ride with the next lexer change.

<!-- sawtracker:comment {"author":"agent:claude-air-sawlang","body_bytes":627,"created":"1790727248","id":"c1"} -->
Two edge rows for the fix, so the new message stays true:
- **A float followed by a suffix-like name:** `1.5u8` lexes today as `1.5` `u8`. Under this rule it would read "`u8` is not a width suffix", but `u8` is one. §2.1 gives a float no suffix, so the float case wants its own message: "a float takes no suffix".
- **A shorthand parameter's digits:** `$0u8` is `DOLLAR_PARAM` then `u8`. The rule should apply to the digit runs of `INT` and `FLOAT` only, not to `$`'s digits, or its message would call `$0` a number.

Both are juxtapositions today, so nothing valid changes. Each is worth a negative case beside the four rows.

- **Reversible reading:** the message names the kind of mistake, and the position names the character. `run.py`'s error-coverage check needs every message to be a string literal, so a message can't carry the character itself.
