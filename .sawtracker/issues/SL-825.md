## Description

**Two leak shapes in sawc2-built code** (SL:hazards S23; the SL-425 sweep, c7; main and seed alike, 300 evaluations each under `leaks --atExit`).

1. **An interpolated string as a comparison operand**, `v[0] != "Bearer {i}"`, leaks 299 blocks of 32 bytes. With the string bound to a `let` first, it leaks 0.
2. **A field read through a subscript getitem**, `toks[i % 2].text`, leaks 2: once per distinct element, whether the field is compared, `.len()`'d or passed by value. With the element bound first, it leaks 0.

Measured clean (0 leaks): a call result or subscript as a comparison operand, interpolation segments (`pad2(i)`, `v[0]`), a user `Printable` segment, format arguments, and a head's temporary receiver.

**Mechanism (UNVERIFIED):**
- (1) the comparison's interpolation temporary is never released;
- (2) the getitem's element copy is retained and never released.

**Obligation 4:** every operator and position that takes a TEMPORARY operand:
- comparisons, arithmetic, `??`, `&&`/`||`;
- a match scrutinee, an `if` condition;
- a method receiver;
- an argument to a by-reference parameter;
- each with a temporary from interpolation, a call, a getitem field read, or a literal.

Pin with leak counts under `leaks` (gmgate, or a new leak lane).

**Retires:** the compiler profile's 25 `owned-operand` (S23) markers and L33's 2 markers, which restore exactly shape (2). They can be re-canonicalized only after this lands, each verified with `leaks`. The `owned-operand` rule itself ends with SL-667.


## Comments

**Lead, on step 1 (p825):** two mechanisms, both in `lower.saw`.
- **Shape 1:** `transfer` passes an owned temporary unchanged as a `move` into a builtin Binary, which never drops it. This is a CLASS: interpolation, `??` and `try` operands of a comparison leak at every position.
- **Shape 2:** `prepare_subscript`'s Getitem root is pushed with no owner, so every getitem followed by a projection leaks (field, tuple, force, fixed-array index, nested).
- **Ruled:**
  - the wide fix in `transfer` (a Borrow use of an owned temporary → `as_place`/`borrowed_value`, dropped by its statement scope), plus a MIR verifier check that no builtin Binary operand of an owning type is a `move`;
  - shape 2 through `value_root`, plus a drops-verifier hardening (stop on any hit beyond these shapes);
  - a run-lane `EXPECT-NO-LEAKS` directive (`leaks --atExit`, darwin) to pin every leaking cell;
  - re-canonicalize all 26 S23 markers (they measure clean today) and L33's 2.
- **The `min4` INVARIANT** (`mk_outer(n).inner.text`, `take_from_temporary` handles only two-step plans) goes to SL-844.
