## Description

TcpStream reads park the task on the reactor via io_wait with no way to bound the wait, so a connection that never sends data (e.g. a browser preconnect socket) occupies its handler until the peer closes. Sawtracker (ST-7) had 30+ second page stalls from worker-pool starvation and worked around it by raising its pool to 64 workers. SO_RCVTIMEO does not apply to reactor-parked nonblocking fds. Request: a deadline-carrying io_wait (or read-with-timeout on TcpStream) so servers can enforce idle-connection timeouts; the existing sleep-deadline wakeups in the reactor look like a natural attachment point.
