## Description

`./build.sh test --dry-run --diff FILE` on a copy-aware diff (`git diff -C --find-copies-harder`, as SL-418.p1 uses on the server's advice in chat m245) reports every `copy from` source as a changed path. SL-418.p1 showed 5,842 changed paths for 3,009 files, and predicted a Python-suite run because `examples/D21_substituted_never_is_a_value.saw` is 'one of its inputs', though no `examples/` file changes. The server gate diffs the applied commit (`--changed-since HEAD^`), so its real decision is unaffected; only the `--diff` preview is wrong. Fix: in `tools/patch_gate.py`'s diff parsing, a `copy from` path is not changed; only `copy to` (and a `rename from`/`rename to` pair's both sides) count. Add a fixture with a copy-aware diff to the gate's own tests.
