## Description

**The user's ruling (Oct 16): every runtime seam that can fail must return an error a caller can turn into a `Result`.** Doctrine: never hide errors. A `void` or a bare-handle return over a call the OS can refuse is a silent failure (SL-276: `__saw_rt_thread_spawn` discarded `pthread_create`'s failure and returned an uninitialized handle; SL-354: the reactor's register ignored `kevent`'s result, fixed in SL-569).

**This issue is the sweep (obligation 4: a class until a sweep says otherwise).** For every `__saw_rt_*` seam (`runtime/ABI.md`, `compiler/tools/runtime_table.py`'s 69, and every `@export` in `runtime/`), record:
- **its OS calls and their failure modes:** errno values, and a NULL or -1 return;
- **how the failure reaches the caller today:** a status return, `-1` plus `__saw_rt_last_syserror()`, a sentinel, a panic, or NOTHING;
- **its callers:** sawc2's `std/`, Stage 0's `sawc/std/` and `sawc/codegen/`, and what each does with the failure;
- **a verdict:** OK (already `Result`-translatable), or MUST CHANGE, with the proposed signature (prefer `-> word` 0/errno with out-params, the shape of SL-569's register) and the std-side `Result` it feeds.

A seam whose failure is a documented idempotent no-op (`__saw_rt_reactor_unregister`'s ENOENT/EBADF) or impossible by construction records WHY instead.

**Candidates from a first read of ABI.md, to confirm, not assume:**
- `thread_join` and `thread_detach` (void);
- `pthread_mutex_init_default` and `pthread_cond_init_default` (void);
- `reactor_create` (ptr), `reactor_poll` (a count; -1?), `reactor_wake` (void);
- `offload_start` (a job handle; thread creation can fail);
- `proc_release` (void), `sleep_ns` (EINTR), `write` (void);
- `blocking_sleep`, `executable_path` (ptr).

`__saw_rt_thread_spawn` is already ruled (SL-765 c6).

**Output:** a census table on this issue with compile/run evidence for each claimed failure path where one can be provoked. Then the lead proposes ONE ABI cut, which the user approves, and the fix units follow, landing with SL-765's T3 change under the same version if they're ready together. Both runtime trees change byte for byte, Stage 0 follows each changed signature (as SL-765 c6 rules for the thread seam), and `runtimeabi.saw` is regenerated.

### Verdict key
- **OK**: reports, and the std consumer translates the report.
- **OK-NOOP**: a failure that is a no-op or impossible, with the reason.
- **MUST CHANGE**: needs a new signature.
- **MUST CHANGE (body)**: the failure is hidden inside the body, but no signature needs to move.
- **CALLER GAP**: the seam reports, and a caller drops the report.

Caller abbreviations: "s2std" is `std/`, "s0std" is `sawc/std/`, "s0cg" is `sawc/codegen/`, and "rt-int" means the runtime calls the seam itself.
