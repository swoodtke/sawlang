**Implementation detail (lead, Nov 12): a constant index outside a fixed array joins the certain-fault funnel, as `constant.index-range`. This unit also closes what is left of SL-730.**

**Probed on main today** (`.build/scratch/qconst.saw`, `sawc typecheck --check`): on `let arr: [Int; 3]`, none of `arr[3]`, `w[5] = 1`, `w[4] += 1`, `arr[1 + 2]`, `arr[0 - 1]` is refused; each builds and panics at run time. SL-730's other half is already done: a negative array length and a negative repeat count are refused (`constant.negative-length`).

**The rule.** LANGUAGE_SPEC "Runtime Semantics and Traps": "Fixed-array indexing with an out-of-bounds compile-time constant is a compile error ("index out of range"), mirroring the tuple-index check." It is one of "the faults a run-time operation would panic with" (Compile-Time Evaluation): the index faults wherever it runs, so it is refused whatever else is known.

**Where.** `compiler/typecheck/src/bodies.saw`:
- **THE CERTAIN-FAULT FUNNEL** (`check_certain_fault`, ENTRY POINTS `shift_count`, `arithmetic_expr`, `check_compound`) refuses a constant shift count and a zero divisor, and hands a fold that waits on a later declaration to `defer_constant`.
- `memory_index` already has the shape of the check for an `UnsafeMemory` view of an array (`fold_constant(index)`, the array type's `ConstInt` length, `index.bits < 0 || index.bits >= length.a`, rule `memory.index-range`).
- A fixed array's subscript is typed where a subscript's base has `TcKind.Array`; `sequence_method` types the builtin `swap(i, j)` on an array.

**The change.**
1. Add the index case to the certain-fault funnel: given the index expression and the array type, fold the index; when it is a constant integer and the length is a `ConstInt` (not a const PARAMETER, whose value is known only per instantiation), refuse an index `< 0` or `>= length` as `constant.index-range`, at the index expression. A fold that `awaits_typing` goes through `defer_constant` exactly as a shift count's does. Message:
   > the constant index N is outside `[T; L]`, whose elements are 0 to L-1, so this access panics wherever it runs

   and for a zero-length array "which has no element". For `swap`, name which index.
2. Call it from every place a fixed array is indexed, and add them to the funnel's ENTRY POINTS list:
   - the fixed-array subscript's typing (one function should serve the read, the write, the compound assignment, `&`/`&var` of an element and a `borrow` head; if they are typed by separate functions, each calls the funnel);
   - `sequence_method`, for both of `swap`'s indices, on an array only (a slice's length is not constant).
3. A slice, a `Vector` and an `UnsafeMemory` view are untouched (`memory.index-range` stays the view's rule).

**Position matrix** (a refusal fixture each, `compiler/tests/typecheck/refuse/constant.index-range[.VARIANT].saw`):
