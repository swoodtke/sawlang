**User decision (Nov 11): delete `examples/`.** It is v0.18.0's frozen tree (2,835 files) and the KEY of the Stage 0 snapshots: each corpus program's oracle is Stage 0's recorded run of its `examples/` twin. The same tree is in the v0.18.0 checkout the toolchain resolver already reaches (`tools/toolchain.py v0-root`), byte for byte.

**What reads it today** (`git grep examples/`):
- `compiler/tests/oracle.py`: `twin_state` opens the twin to compute `same`/`differs`, and `twin_of`;
- `compiler/tests/corpusdiff/corpusdiff.py` and `compiler/tests/coro/stage0/snapshot.py`: the `twin_sha` check that the twin is unchanged, and re-snapshotting;
- `tools/patch_gate.py` (an input of the corpusdiff part) and `tools/test_patch_gate.py`;
- `tools/check_citations.py`, `tools/commentlint.py` and `tools/test_commentlint.py` (exclusions), `tools/sawfloat.py`, and `tools/signal_race_probe.c` (check each: a path or a comment);
- `tools/frozen_trees.tsv`'s row, and run.py's `frozen` step.

**The plan, one unit:**
1. **Record the relation.** For a program that isn't detached, both sides are frozen, so `same`/`differs` is fixed. Store it in the snapshot rows (corpusdiff's snapshot, and the coro Stage 0 index) and compute `twin_state` from the row, never by opening the twin. `native` becomes "no row and no recorded twin"; `detached` stays "the corpus file's sha ≠ its row's `frozen_sha`".
2. **Re-snapshotting reads twins from the v0 checkout** (`oracle.v0_root()`/`examples/…`) rather than this tree. The `twin_sha` check moves there as well, or is dropped where the tag guarantees it.
3. **Delete `examples/`**, its `frozen_trees.tsv` row, and every exclusion or path that names it. The README's project tree loses its line.
4. **Gate:** with the tree gone, the corpusdiff baseline is UNCHANGED (`run --baseline` shows no diff); the coro lane, `snapshot.py`, `run.py --only` (oracle, coro, census, programs, comments, docs, the patch-gate tests) and `battery.sh patchgate citations` all pass.

**Owed to the user:** CLAUDE.md describes `examples/` (the repo map, "Testing", "`examples/` is FROZEN") and is the user's file. List the lines to change in the landing note.
