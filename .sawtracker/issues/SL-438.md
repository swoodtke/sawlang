These are small follow-ups from SL-420.p1 (SL-420 c7). None of them changes a decision the patch made.

1. **`compiler/tests/migrate/test_migrate.py` needs cases for three tool features SL-420 added:**
   - a pairing case for the `retired` status: no twin, and a note required;
   - an anchor-row fixture (rule `reaim` at 0:0);

   - `shared_self_borrows_epilogue_write`, `shared_self_borrows_field_var_method_call`, `vector_ref_at_removed` and `for_iter_body_mutates_the_collection` describe exclusive-only inference, `#lend_var` or `with_ref`;

   Rewrite the headers to describe the rule each file pins now, through `manual.tsv` as SL-420 did.
3. **`tests/corpus/conformance/INDEX.md` row X15** names `errors/place_window_beside_var_root.saw`, which never contained a `v.push`. This predates SL-420. Repoint X15 to the test that covers it, or write that test.

5. **SL:open-questions W3** (the user's call) decides `place_assignment_targets`. When it's ruled, re-aim that file to pin the ruling.
