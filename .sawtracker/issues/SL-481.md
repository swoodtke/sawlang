**Found by:** the Air's review of SL-475.p1. **Area:** typecheck (`compiler/typecheck/src/bodies.saw`, `add_capture`).

**The defect:** a `[copy x]` capture of a value whose type is a type parameter records nothing. It is accepted at a NoCopy instantiation, and MIR then copies it bitwise (or, after SL-475.p1's revision, has no `copy()` to call), so the environment and `x` both own one value.

**The repro** (`.build/scratch/air-review/sl475/probe_generic_copy_unbounded.saw`), with `Res: NoCopy` (a `String` field and a deinit) and a trait `Sized2` it conforms to:

```saw
func later<T: Sized2>(x: T) -> () -> Int {
    let y = run({ [copy x] in 1 })
    { [move x] in x.size() + y }
}
// main: later(Res(name: "abc"))
```

- **Stage 0** refuses: "cannot `copy` capture `x`: type `Res` implements NoCopy".
- **sawc2** `typecheck --check` is clean.

**The mechanism:** `add_capture` refuses `[copy x]` only when `not copies_silently(t) && tier is NoCopy` (`capture.copy`). `copies_silently` answers true for every `Param`, which is design 219's view of a silent copy inside a generic body, an *inferred* requirement checked at each call. No requirement is recorded for the capture, though, so no call is ever checked.

**The rows to settle** (design 219):

| `T`'s bounds | `[copy x]` is | the check |
|---|---|---|
| `T: Copy` | a silent copy | none needed |
| `T: ExplicitCopy` | a spelled copy, licensed by the bound | MIR calls the bound's `copy()` (SL-475.p1 r2) |
| neither | either an inferred `Copy` requirement checked at the call (refused at `T = Res`, like Stage 0), or a spelled `.copy()` on an unbounded `T`, refused at the definition per design 219's "`.copy()` on a value whose type mentions an unbounded type parameter is refused at the definition" | which reading is the lead's or the user's call |

**Sweep:** the same predicate in the other capture positions (a `[copy x]` of a type that *mentions* `T`, such as `(T, Int)` or `T?`), and any other typecheck site where `copies_silently(Param)` stands in for "no requirement needed".
