Approved patch SL-720.p2 (revision 1)

**Air: SL-720.p2 r1 approved; arming it.** `std.directory` is a faithful port, and it closes every stream it opens.

**Read:** `list` closes its `DIR*` on every exit: end of stream, the UTF-8 panic, a refused push, and normal return. Each entry name is copied before the next `readdir`. `create`/`remove` carry the real cause. The NUL check comes before C, as in `Env`. The magic bytes are named (`DIRECTORY_MODE`, `DOT`). `c_string_length` is reused from `std.env`, not duplicated.

**Probe** (`air-review/sl720b/dir_probe.saw`, on main + r1, both stages rebuilt; identical at -O0 and -O2):
- `create` works; creating it again is `already exists`.
- Listing a directory with two subdirectories gives 2 entries, both found; listing a missing directory is `not found`.
- 3000 consecutive `list` calls return 6000 entries with no error. One leaked stream per call would have exhausted macOS's 256-descriptor default.
- `exists` is true and false, and each `remove` succeeds.

**Checks:** `run.py --only resolver,std,std_cone,programs,subset` ok. `subset_check.py --std std/directory.saw std/env.saw`: 0 diagnostics. `corpusdiff.py gate --no-build`: all 2661 hold. No moved program appears in gmgate's lists.

**Follow-ups, none blocking (each Stage 0's behaviour too, or a kind-set question):**
1. **A `readdir` error reads as end of stream.** `readdir` returns NULL both at the end and on an I/O error, telling them apart only by `errno`. So a listing that fails midway returns a silently truncated `Ok`, which the doctrine forbids. Stage 0's `list` has the same loop. The fix is a status-carrying `readdir` seam, as `opendir` and `getcwd` have.
2. **`remove` on a non-empty directory says `rmdir failed (other error)`.** `SystemErrorKind` has no not-empty kind, so `ENOTEMPTY` lands on `Unknown`. That is the most common `Directory.remove` failure, so it may earn a kind (`DirectoryNotEmpty`, as Rust has). That is the user's call, since adding a kind breaks exhaustive matches by design.
3. **A non-UTF-8 entry name panics inside a `Result`-returning `list`.** That is stricter than Stage 0, which built the `String` unchecked, and consistent with `Env`. But a directory's contents are data the caller does not control, so an `Err` may suit better. It is a ruling question.
4. **Style:** the loop is `while true { guard let entry = readdir(stream) else { break } … }`. The drain idiom is `while let entry = readdir(stream) { … }`, which the skill names as replacing the guard-break spelling.
