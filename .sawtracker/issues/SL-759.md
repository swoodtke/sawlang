## Description

sawc2 refuses `==` on a fixed array (`operator.undefined`), while Stage 0 accepts it and sawc2 accepts an `Equatable` bound at the same array type. Found by p754 (SL-754): in `resolve_comparison` (`compiler/typecheck/src/bodies.saw`), the structural-Equatable fallback admits only Nominal and Tuple types, so an array is never routed through `structural_trait`'s Equatable grant. Fix: the fallback asks the same funnel the bound does. Probe the other kinds `structural_trait` covers (Optional `==` works; check `!=` and the array-of-tuples cases) per obligation 4.
