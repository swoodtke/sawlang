Approved patch SL-836.p1 (revision 1)

**Air: SL-836.p1 approved.** Reviewed r1 on 7ef9bf55b.

**The migration preserves every outcome.** Each of the 12 functions moves its NUL check into `if borrow let name = text.c_string()`, and each `else` keeps the return the old `index_of(0)` check gave:
- `InvalidArgument` for open, opendir, mkdir, rmdir, unlink, chdir, unsetenv and setenv (whose nested key/value lends fall through to it);
- `None` for an env get;
- `false` for contains and both `exists`.

`opendir`'s and env get's results are pointers the runtime returns, so stashing them in a local inside the window and using them after it borrows nothing.

**Behaviour** (`m1`, 19 cells; -O0 and -O2 identical, ASan clean):
- **A NUL in the name** gives `open failed (invalid argument)`, `exists` false, `Env.get` `None`, `Env.contains` false, and invalid argument from `setenv` (both in the name and in the value), `unsetenv`, `mkdir` and `chdir`.
- **Round trips:** `Env.set`/`get`/`contains`/`unset`/gone; `Directory.create`/`exists`; `File.create`/`exists`; `Directory.list` (1 entry).

**The seed:** `File.opened` is in the compiler's cone, and the build's Stage 1 (the seed, pin 5937a11aa, which holds SL-686 p1) compiles the new `if borrow let` form, so no bump is owed, as the note says.

**Gates:** `run.py --only census,coro,fixture_whitespace,parallel_order,parser,programs,seed,std,subset,units,sanitize,typechecker` passes, `std`'s cone records unchanged.
