**The run lane's stated-output probes conflict at every append.** Each new probe whose output is stated adds a `check_X` function at the end of the check functions in `compiler/tests/run/run_lane.py`, a call at the end of `run()`'s list, a bullet at the end of the module docstring's list, and a bullet at the end of `compiler/tests/run/README.md`'s list. Four patches on Oct 15 (SL-623, SL-642, SL-631, SL-643) each conflicted with the one before at all four places, and the lead resolved each by hand, keeping both sides. Most of these checks are the same three lines: read the probe's `// prints:` lines and compare.

**Fix shape:** one table of stated-output probes, `STATED_PROBES = (("borrow place reads", "borrow_place_reads.saw", "SL-642"), …)`, run by one loop, one entry per line, kept sorted. The probes that need more than the stated comparison (the test-only export link check) stay functions. Then either:
- add `run_lane.py`'s table region to `.gitattributes` `merge=union`, as SL-633 did for the conformance ledgers; or
- read the probes from a directory listing (`probes/*.saw` carrying a `// prints:` header), so adding one touches no shared line at all.

The README's list becomes one sentence about the directory, plus the table.

**Pin:** the lane fails if a `probes/*.saw` with `// prints:` is in neither the table nor the custom checks, and the reverse.

**SL-650.p1 (r650table): the run lane finds its probes by listing `probes/`, each held to its header.** Adding an ordinary probe now touches only its own file.

**Header directives:** `// probe: KIND` (`stated`, `panics`, `link-fails`, `custom`, `module`), `// about: TEXT (SL-N)`, `// stage 0: TEXT`, `// speeds: -O0 -O2`, `// prints:`, `// panics:`, `// undefined:`, `// ll defines:` and `// ll omits:`.

**The pin:** a probe with no kind, a line its kind doesn't take, or a missing required line fails the lane. So does a `custom` probe with no `CUSTOM_PROBES` entry, an entry with no matching probe, and a `module` that nothing imports. `executable_path.saw` is the one custom probe (it prints its own binary's real path), and `construction_override_gate.saw` is the one module.

**Every probe is converted,** including those from SL-638, SL-640, SL-648, SL-656 and A6 that landed while this was in flight: 13 stated, 2 panics, 2 link-fails, 1 custom and 1 module. The per-probe docstring and README bullets and the per-probe `check_X` functions are gone, and the README describes the directives once.

**Before and after:** the same checks run.
- Stated: 14, which is 9 before plus the 5 that landed since.
- Panics: 2.
- Link-fails: 2 (renamed from "test-only exports left undefined").
- `.ll` checks: they run at every listed speed, which is stronger than before (`test_only_export_unused` was -O0 only).
- Run programs matching Stage 0: 114.

**Injected failures,** one per kind and one per header rule, each caught.

**Reversible decisions:**
- `stage 0:` is required but not checked;
- `speeds:` has no default;
- a stale `.ll` is deleted before each build;
- probes run in parallel through `gate_jobs.map_ordered`;
- a probe failure now names the file path;
- `run_lane.py NAME` also selects probes.

Gate (agent): `run.py --only programs` and `battery.sh citations childgroups`, green on main with A6. The final rebase onto main was clean.
