**p721dyn: one cell of the position matrix STOPPED, the spec and Stage 0 disagree.** The cell is a `&any Trait` *parameter* of a suspending function whose dispatch spans the suspension.

**Repro** (`.build/scratch/p721/t/s1.saw` in the p721dyn worktree):

```saw
func spanning(s: &any Shape) -> Int {
    let a = s.area()
    __saw_suspend()
    a + s.area()
}
// main: print("{}", __saw_drive(spanning(&sq)))   with sq = Square(side: 3)
```

- **Stage 0** refuses it: "`s: &any Shape` cannot be a parameter of the suspending function `spanning`. A reference that spans a suspension is held in the frame as a handle to its referent (design 88), and an erased referent has no size for the frame to name."
- **sawc2** with this branch builds and runs it, printing `18`: a frame-resident `&any Shape` is its two words, like any other reference held in a frame.
- **The spec** says references may span suspensions, with no exception for an erased referent ("References may span suspensions", design 18 D6). The only text naming the refusal is historical narrative under "A dispatch whose every implementation is sync frames nothing" ("its erased parameter was then refused by the rule below — a reference that spans a suspension lives in the frame as a handle to its referent, and an erased referent has no size"), which describes Stage 0's mechanism rather than stating a rule.

**What I did:** nothing for this cell. sawc2 accepts it by construction, I added no refusal, and I pinned no run program for it, since Stage 0 can't be its oracle. The pinned suspending-function position is the shapes both compilers agree on: dispatches on a local box and on a reference to a local inside a driven body (`compiler/tests/run/existential_positions.saw`, `root`), and an erased helper called from a driven body.

**Needs a ruling:** should a `&any Trait` held across a suspension be legal, as the spec's general rule and sawc2 have it, or refused, as Stage 0 has it? If legal, the follow-up is a probe pinning sawc2's run and an SL:hazards entry for Stage 0's refusal. If refused, it's a typecheck or coroutine-lowering refusal at the parameter.
