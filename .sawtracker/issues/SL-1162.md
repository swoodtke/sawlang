## Description

**The test intrinsics `__saw_suspend`, `__saw_drive` and `__saw_drive_steps` resolve bare in every module** (`compiler/resolve/src/prelude.saw`), so any user program can call them (the SL-1112 sweep built one: `S/q_test_intrinsics.saw` in `.build/scratch/s1112/`, printing `driven: 5`). They exist for the compiler's own tests; their lowering calls std's executor entries. To decide: restrict them to test builds (`@test` files or a test flag), or to std's package, and what the coro and executor test lanes then use. Related: SL-1112.
