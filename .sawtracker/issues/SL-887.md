**Step 1 (p887):** the line-table prototype symbolizes a panic to `file:line`, on macOS through a .dSYM and on Linux in the ELF. A coroutine resume function resolves to its source function.
- **Cost:** driver IR +51%, compile +3%, binary +3.7% (identical after `strip -S`).
- **Findings:**
  - macOS's one-step `clang -x ir … -o` link can never keep debug info, so the link becomes two steps (reproducible: `-Wl,-reproducible -oso_prefix`, then `dsymutil --oso-prepend-path`);
  - the CU directory must be `.`, not empty;
  - invalid debug info is only a clang warning (exit 0);
  - a symbolization pin must look up the call address.
- **RULED:**
  - the one funnel in `debug.saw`; LineTablesOnly, columns kept; on by default at every `-O`, with `-g0` to turn it off and `-g` accepted;
  - the two-step link, where a dsymutil failure fails the build;
  - `build.py`'s `link_module` changes too, so the compiler symbolizes, and the fixpoint must stay byte-identical;
  - the seed IR is emitted `-g0`; the runtime is `-g0` for now (**SL-901**);
  - existing goldens `-g0` plus a new debug golden; the run lane rejects clang warnings at -O2 too.
