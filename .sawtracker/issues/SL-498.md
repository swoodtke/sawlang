**Found by:** misc459 (SL-459). **Area:** typecheck, the raw-backing check on an enum declaration.

**The defect:** sawc2 accepts `enum E: Byte { case A = 1 }`. LANGUAGE_SPEC (the `Byte` section) says: "`Byte` may not be an enum's raw backing (`enum E: Byte` is an error, since a raw backing is a fixed-width integer), so wire enums keep `UInt8`." The skill says the same.

**Mechanism to check:** sawc2 resolves aliases to their underlying type (SL-447), so the backing check probably sees `UInt8` and never sees `Byte`. The rule needs the spelled type, not the resolved one. That is the same distinction the spec relies on for `append(65)` versus `append(Byte(65))`.

**Sweep (obligation 4):**
- every user alias over an integer type as a backing (`type Code = UInt16; enum E: Code`). Decide from the spec whether only `Byte` is refused or any alias is, and ask if it's silent;
- an alias of `Byte`.

Pin the refusal and the `UInt8` control.

**Landed:** `type.raw-backing` refuses an alias backing (read from the written type), a non-integer backing, and a backing on an enum with a payload case. Five fixtures, with the `UInt8` control in `constant_positions`.
