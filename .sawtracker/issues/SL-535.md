- **`build.py`** builds Stage 1 (`.build/sawc2`, by Stage 0, as before), then Stage 2 (`.build/sawc2-stage2`, Stage 1's `build -O2` of the driver).
  - Stage 2 is cached under `.build/sawc2-stage2.key`. The key covers `.build/sawc2.o` (not Stage 1's binary: Stage 0's link writes a fresh LC_UUID and signature each time, while its `.o` and `.ll` repeat), the stage sources, the driver, `std/`, the link script, the runtime objects' contents and `clang --version`.
  - `build.SAWC2` selects Stage 2 by default, and `SAWC2_STAGE=1` (or `run.py --stage 1`) selects Stage 1 for bisecting.
  - `build.link_driver()` makes both the Stage 2 and the Stage 3 links, so they compare like with like.
- **The run lane** now passes the selected binary as `SAWC2_BIN`; before, the script silently ran `.build/sawc2`. `lexdump.py`'s freshness check includes `std/`.

The docstrings, messages and READMEs use conventional numbering. What the lane guards is unchanged: Stage 1's `.ll` is deterministic, Stage 2 writes the same `.ll`, Stage 3 equals Stage 2 byte for byte, and all lane invocations agree between Stage 1 and Stage 2.
