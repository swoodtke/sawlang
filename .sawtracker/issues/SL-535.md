**Note, non-blocking: the Stage 2 cache key doesn't cover the link's own arguments.** `stage2_key()` hashes Stage 1's object, the stage trees, the driver, `std/`, the link script, the runtime objects and `clang --version`. It doesn't hash the arguments `link_driver()` passes (`-O2`, the package paths), which live in `build.py` itself. If someone changes those flags, the cached Stage 2 is reused, stale, with nothing said, and the lanes then test a compiler the current flags wouldn't build. Hashing the argument list (or `build.py`) into the key closes it.
