## Description

The sawlang-vm prototype (prototypes/minivm): a subset Saw compiler WRITTEN IN SAW — single-pass frontend lowering to a typed linear instruction IR consumed by two independent engines, a VM and a textual LLVM emitter (no llvmlite), validated differentially with three oracles (VM output, clang-compiled native output, explicit expected text). Architecture: prototypes/minivm/DESIGN.md; per-milestone contracts M1..M13; dependency inventory LEXER_DEPENDENCIES.md (pinned to selfhost/lexer/src/lib.saw line numbers).

EPIC ACCEPTANCE: minivm compiles the UNCHANGED selfhost/lexer/src/lib.saw end-to-end, and the resulting lexer's token stream matches the sawc-built selfhost lexer across a corpus sweep — the first true self-hosting differential gate.

STRATEGY (user-ruled, Sep 10): the self-host track becomes a first-class scheduled lane running alongside the soundness pipeline — NOT a replacement for it (the Python compiler builds generation 0, so its miscompile class is the bootstrap's foundation risk; see SL-226/218/219/234/235/236). The prototype also becomes the prioritization oracle for Python-compiler backlog debt: bugs it actually hits get fixed, the tail waits. Flip-to-maintenance condition for sawc: bootstrap checkpoint passed (new compiler compiles itself, generational diff clean) + agreed examples/ subset covered.

LANDING PLAN: the 14 reviewed-milestone commits on branch sawlang-vm land as sequential sawtracker patches, one per milestone task issue (children of this epic), user-reviewed each. After landing: remaining lexer-milestone tasks (M12/M13 impl, StringBuilder, Vector, whole-lexer acceptance) schedule via the normal process, then the post-lexer bootstrap phases (AST + standalone parser reconciled with design 259 — arena/index AST ruled Sep 10 — semantic/lowering split, sync feature growth, bootstrap checkpoint) get their own epic + brief.

Server-gate note: prototypes/ is outside the compiler suite and freestanding gates; per-patch validation = the minivm harness (test_minivm.py, 336 cases at tip) run by the lead, plus the server's standard gate proving no production impact.
