**SL-874.p1 submitted** (0e8d16a00, on origin/main; closes SL-707).
- **The `Err` line:** a `Result`-returning `main` lowers at the backend's C entry through ONE `main_status` funnel. An `Err` writes `error: <rendered>` on stderr as one line under the output lock, after the background group closes, then exits 1, with no new seam.

- **Pins:**
  - 60 run probes, at -O0 and -O2 with `// leaks: none`, using the new `// exits:` / `// stderr:` directives;
  - the README, spec and skill doc examples as probes;
  - corpus `EXPECT-STDERR-CONTAINS`.
