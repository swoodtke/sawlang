## Description

**sawc2 has no "a public API names only public types" check** (design 193; SL:hazards S19; the SL-425 sweep, c7; main and seed alike).

A `struct Hidden` (module-private) returned by a `public func` is accepted:
- at nesting depth 1, 2, 8 and 9 (inside `Optional`, `Vector`, `Result` and tuples);
- from a dependency module.

No diagnostic id for the rule exists anywhere in `compiler/`. Stage 0 enforced it (design 193). The depth-bounded walks the S19 entry names (a reference 13 deep, a Result discarded through 33 forwarding levels, and so on) are all fine in sawc2; this is the one missing check.

**Obligation 1, a matrix:** every public surface position that can name a type:
- a parameter, a return or a field of a public struct;
- an enum payload;
- a type alias's target;
- a generic bound or default;
- a trait requirement's signature;
- a public static's type;
- an extension member's signature.

Each × the visibility tiers (private, module, `public(package)`, public). It goes through one funnel in typecheck whose docstring names those positions.

**Retires:** with the walk faces, the subset checker's `written-type-shape` rule (SL-425 batch B2 retires the walk faces; this check is separate).
