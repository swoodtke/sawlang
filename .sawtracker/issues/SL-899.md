Found by the lead's probe (Oct 25; `.build/scratch/probe_copy_variant.saw`). `if let c = borrow v.find(0).copy() { … }` builds for `Vector<Int>`, but for an automatic-Copy-tier struct element (`Named { name: String }`) and an `@synthesize` ExplicitCopy struct element (`Bag { items: Vector<Int> }`) MIR refuses with `slice.not-yet: a conditional lend's place read other than through `!` is not lowered to MIR in the bootstrap slice yet`. Typecheck accepts it: the spec says `.copy()` on an optional exists exactly when the payload's tier provides one. This is the spelling §12 (SL:borrowing) gives the copy-meaning sites (SL-897 Q5), so it matters for the v0.19.0 migration. Sweep: every way a conditional lend's optional place is read as a whole (`.copy()`, `??`, comparison, an argument, `is_some()`) × element tier (trivial, Copy struct, ExplicitCopy, enum payload).

**Step 1 (p899):** a whole read BY VALUE already works (`let`, `??`, by-value arguments, through `lent_copy`/`copy_out`). Reads by SHARED BORROW (`.copy()`, comparison, `is_some()`, `&` arguments, a P3 root) hit `realize_as`'s refusal at every tier.
- **RULED:**
  - **D1:** ONE `lent_optional_copy` funnel (front ends `copy_out` and `realize_read`, closing only the read's own windows).
  - **Presence:** presence-only lowering for `is_some`/`is_none`/`== None` at every tier (§2.4 t25).
  - **Value reads:** ExplicitCopy/NoCopy payloads read by value (`== want`, a `&` argument) are refused in typecheck, the text naming `.copy()` or `if let`.
  - **Writes:** whole writes (`&var E`, `.take()`, `E = None`) are refused in typecheck, naming `if var x = … { x = … }`.
  - **Teaching texts:** three fixed (the ExplicitCopy `let` names `.copy()`; the NoCopy texts lose 'borrow it' and 'move it').
