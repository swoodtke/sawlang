## Description

**User ruling (Sep 29):** SL:hazards S23 gets a subset-checker rule, as an exception to the Stage 1 leak ruling.

**Why.** Stage 0 leaks an owned value consumed without a binding at three positions its owned-temporary check does not list:
- a comparison operand;
- an interpolation segment;
- a format argument of `print`, `panic` or `assert`.

A Stage 1 parser comparing token text (`self.toks[self.pos].text == word`), or interpolating a diagnostic, would leak once per token over every file it compiles. S23 has the evidence (chat f13 and f14, and the lead's format-argument measurements).

**The rule.** In `compiler/` source, refuse an owned operand that sawc's `_is_owned_temporary` accepts, at those three positions.
- String literals are exempt, since they are static.
- Use the predicate itself, not a list of syntactic shapes. The Air's census tool (`probe_cmp_census.py`, f14) wraps `_generate_binary_op` the same way.
- The refusal names S23 and the fix: bind the operand to a `let` first.

**Tests.** A fixture per position, covering:
- leaking shapes: a call, a subscript read, a field through a subscript, an interpolation;
- exempt shapes: a named place, a literal, a receiver inside a trivial operand.

The checker over `compiler/` must stay clean; the census finds 0 today in sawc2's cone. Lanes: `compiler` and `citations`.
