Submitted patch SL-258.p1 (revision 1): M15: bounded Vector ownership in the Saw compiler prototype

Adds the bounded Vector support needed for the lexer milestone: compiler-known Vector<T> with Copy elements, empty construction, len/push/get/checked indexing, references, whole-local moves and vector-containing results. Elements can own Strings and Optional/Result payloads; get/index produce independent snapshots. Both the VM and textual LLVM backend implement unique ownership, cleanup and transactional push failure.

General generics, noncopyable elements, vector-bearing by-value parameters/reassignment and vector-valued control-flow joins remain outside this slice. Move analysis is conservative across branches and rejects moves of outer locals inside loops. M15_VECTORS.md specifies the source and instruction contracts; the inventory records StringBuilder.clear() and break as known remaining SL-259 integration work.

Validation: all 424 prototype cases pass (30 in the Vector section); all 13 selected Vector sawc differential cases agree. Independent verifier, VM and source contracts pass; native ownership/failure contracts pass at O0/O2 and under ASan. A separate 33-element String-owning record oracle agrees with VM, native O0/O2/ASan and Python sawc. Citation and conflict-marker checks pass.
