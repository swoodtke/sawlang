**S4. `LendingIterator` and collection `for`: a probe, then `Vector.iter`** (unit of SL-596; Sonnet tier for the probe, user Oct 15).

`Vector.iter` blocks 33 programs (main's baseline, Oct 15), Blade's 7 `for x in v.iter()` loops among them. It needs two things the new std doesn't have, so this unit starts with a probe (the Air's SL-596 c2 and SL-559's notes):
1. **The `LendingIterator` trait** in `std/prelude.saw`, with the spec's shape ("Two iterator traits": `func next(&var self) borrows -> &var Item?`). The new prelude has only `Iterator`.
2. **Whether sawc2 lowers `for x in it` over a borrowing iterator:** a borrowing struct (`VectorIterator` holding `lends self`), a per-iteration lend window, and the collection-`for` desugaring. A6 dropped collection-`for` from its narrowed scope, so this is unverified.

**The probe:** declare the trait, write a user-defined collection with a borrowing iterator (the spec's `grid.cells()` example), and build and run `for` over it with `sawc2 build --std-root std`, plain and inside a suspending function. Report each stage's verdict with the exact output.
- **If it lowers:** port `Vector.iter` and `enumerated` (`sawc/std/vector.saw`) in the same unit, with pins matching Stage 0 and the re-measured corpusdiff baseline.
- **If it doesn't:** stop with the refusal or ICE named. The lowering is an Opus compiler unit, filed from the evidence.

**Probe result (Sonnet s703iter, two rounds; scratch roots `.build/scratch/s703/` and `.build/scratch/s703iter/`).**

1. **The spec's `LendingIterator` + `for borrow`:** both compilers refuse it (Stage 0 has neither; the spec marks both as planned). That's planned work, filed as SL-738, and not the parity path.
2. **Stage 0's actual `Vector.iter` shape** (a plain `Iterator` over a `borrows struct` with a shared reference, `T: Copy`): Stage 0 builds and runs it, plain and inside a suspending loop. sawc2 refuses it with exactly ONE error, `syntax.expr.lends is not in the bootstrap slice yet`, at the `lends self` initializer argument. The struct, the conformance and the `for` head all pass.

So this unit is blocked on **SL-739** (the `lends` lowering, Opus). Once that lands, phase 2 ports `Vector.iter`/`enumerated` as Stage 0 has them. Non-Copy items are out, matching Stage 0's `T: Copy` bound.
