## Description

U3 (SL-418) migrated accessor *uses*, not accessor *declarations*. `examples/`, and so `tests/corpus/`, has 124 `(&var self) borrows` and 107 `(&self) borrows` accessor declarations, and no `@synthesize(shared)`.

Under SL:borrowing §3 (declared modes), the accessor's receiver is the charge on the root. A `borrow let` through a `&var self` accessor holds its root exclusively for the window, even though the body only reads. `borrow let` prefers a `&self` variant when one exists, and `@synthesize(shared)` derives one, where the body permits.

**To decide, per accessor:**
- whether its migrated uses need a shared twin (`@synthesize(shared)`, or an explicit `&self` accessor when the bodies differ, K1);
- or whether the exclusive charge is what the test means.

A read through a `let` root of a `&var self`-only accessor is the case to find first. The migrate instrument records `accessor_self` for each window, so it can list them.

This is not needed for the parser units (U4 and on), which parse either way. It matters when resolution and typecheck reach `tests/corpus/`.

## SL-421: accessor declarations under declared modes (brief)

The authority is SL:borrowing r24, in particular §3 (declared modes and the root charge, with D7's clarification of the Root column), §4 (`@synthesize(shared)`) and §5.2 (getitem and setitem derivation). The lead's reversible decision D8 applies: a type that declares an accessor pair derives getitem from the `&self` accessor and setitem from the `&var` one.

**The work, in order:**
1. **The sweep first (c2, item 1).** §5.2 derives getitem only from a `&self` place accessor. So on a type whose only accessor is `&var self`, a plain `x[i]` read and `x[i] += v` are refusals in the new language, and the migrate tool's rules G1 and A2 don't flag them. Extend the tool to flag every such site in `tests/corpus/`, including files already marked `copied` or `rewritten` (for example, K123's `b[0] += 1`). Report the count by file.
2. **One decision per user accessor** that the sweep or the description names. The description counts 124 `(&var self) borrows` and 107 `(&self) borrows` declarations. Each accessor gets exactly one of:
   - **(a) a shared twin**, when the body only reads the place: add `@synthesize(shared)` (§4). If the shared body differs, write an explicit `&self` accessor instead (K1).
   - **(b) keep it exclusive-only**, when the test means the exclusive charge. Every read through it must then be written as the exclusive form, or re-aimed as a refusal where the test pins one.
   - **(c) leave it flagged**, only when the test's meaning under declared modes is not determined. Name the open question in the note.

   Record each decision in the manifest note: which of (a), (b) or (c), and why, citing the section.
3. **Std accessors (c2, item 2).** SL:borrowing rules twins only for `Vector.[]`, `Vector.find` and `KeyedPlace.find`.
   - **Proposed default, which the lead records as a reversible D entry:** a std accessor whose body only reads gets a `@synthesize(shared)` twin.
   - **List every std accessor that tests/corpus relies on in a shared position**, for example `JsonValue.as_array` and `as_object` on a `let` root (`json_value_accessors`), with whether its body only reads. Don't edit `sawc/std`, which is frozen. The list is the deliverable, and the corpus files follow the default.

**Rules**
- **Edits go through the migrate tool.** Corpus edits go through `manual.tsv`, whole-file notes through `decisions.tsv`, and a tool change through `compiler/tools/migrate/`, with tests in `compiler/tests/migrate/`. Rerun `migrate.py apply` and the pairing check. Build sawc2 first with `compiler/tools/build.py` (SL-438's note).
- **Never invent an expectation or error wording.** A refusal re-aim says `// EXPECT: error`, and its note names the rule (SL-420 c4).
- **Guarantee rows:** a changed covering test in `tests/corpus/conformance/INDEX.md` gets its row re-texted in the same patch.
- **Stay inside** `tests/corpus/`, `compiler/tools/migrate/`, `compiler/tests/migrate/`, and `compiler/tests/grammar/corpus_expected.tsv` (only through `corpus.py --write`, after your final rebase). U4g is working in `compiler/parse/` and the parse corpus.
- **Findings:** a disagreement among the sources is a finding for the report. Pick no side.
- **Keep your context lean.** Update `.build/scratch/sl421/STATUS.md` at each commit, and work from the TSVs with probe scripts.

**Gates:** `compiler/tests/run.py` per commit; before reporting, `battery.sh compiler citations grammarcorpus` under the suite lock; `git diff --check`.

**Report:**
