The run lane's `aarch64-unknown-linux-gnu` Stage 0 snapshot is missing 28 records that have `arm64-apple-darwin` records. They're mostly today's landings: Arc, Data, the String core, Env/File, numeric/slab and the coro pins. The oracle looks up only the host triple, so this fails only the opt-in `linux` lane. Record them with `tools/linux.py stage0 NAME...` (VM side), then confirm sawc2 matches on Linux with `tools/linux.py run-lane --arch aarch64 NAME...`. `Range` in the list needs a look: a record name that isn't a program, or a program without a Linux run.
