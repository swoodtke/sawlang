## Description

From SL-405.p1's review (non-blocking). For `extension Optional {`, the generic-extension-params hint advises writing the type parameters. But Stage 0 also refuses `extension Optional<T>` ('cannot extend undefined struct'), so following the hint produces a second, `compile`-rule refusal. Make the Optional case's message say that Optional cannot be extended under Stage 0, instead of naming a spelling that fails. Result extends fine with its parameters, so its hint stays. Add a fixture for the new message.
