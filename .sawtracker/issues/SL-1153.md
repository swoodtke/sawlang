## Description

**Release v0.24.3.** The project owner's ruling (Nov 16, in the lead's session): tag after SL-1137 lands ("After SL-1137 lands"), because SL-1137.p1 also fixes SL-1151, a soundness bug on main. The sawos project waits on it to move its pin and build sosrt's `_start` calling `__saw_main` (SO-124).

**The patch:** `.sawtracker/version` becomes `v0.24.3` and `driver_version()` in `compiler/driver/src/main.saw` becomes `"0.24.3"`, which run.py's `version` step holds equal. The server creates the annotated tag at the patch's merge commit. **It lands AFTER SL-1137.p1, with nothing between them** (anything else approved may land before SL-1137.p1).

**What v0.24.3 holds beyond v0.24.2** (each merged; ancestors verified at landing):
- **SL-1151 and SL-1137, a safety fix and its feature.** A non-escaping function value could leave through a closure's result when that result's type was inferred, or through `move f`, an untyped `if`/`match` arm, a tuple, array or repeat element, or a `borrow` block's value, and safe code then read a stack frame that had returned (on main: `apply({ f })` with a generic `R`). Each is now refused with `escaping.stored`. And a closure literal called where it is written (`let n = { [&a] in a.len() }()`) is non-escaping: it may capture by borrow and consume a `[move x]` capture. A nested closure's capture-list entry that no body names no longer reaches an internal compiler error.
- **SL-1143: a freestanding `main` is the program's entry.** The compiler defines `__saw_main() -> i32` in an object whose entry module declares `main`; it runs `main` (driving a suspending one) under the exit-status contract and returns the status, never exiting; the runtime's `_start` calls it. `runtime/ABI.md` "The program entry". A freestanding `main` takes no parameters (`entry.parameters`); a disagreeing declaration of `__saw_main` is `extern.signature-disagree`; a hosted one is `extern.entry-hosted`. Hosted programs' output, status and symbols unchanged. `Task.spawn` stays refused freestanding (SL-1150 follows).
- **SL-1129: a const generic value takes every value of its parameter's type** (U1-U3): `Mask<0x8000_0000>` and `Mask<0x8000_0000u32>` build on riscv32 and are one instance; an unsuffixed literal written as a whole argument takes its parameter's type; a literal inside an expression argument stays an `Int`.
- **SL-1108: a path that names a constant fills a const generic parameter:** a static, an enum raw value, an integer limit (`Mask<Int8.max>`), through a type alias too.
- **SL-1126: `(move x)` as the base of a field read or a method call moves `x`**, and an optional chain's non-copy final field is refused only where it would be read by value.
- **SL-1139: `sawc` no longer panics** on `-9223372036854775808` for a 32-bit target (a clean `type.mismatch`).
- **SL-1083: an `@export` is kept by a collecting link,** as the spec says, and an `@export` that is also `@section`-placed keeps the retain flag a plain placement gets.
- **SL-1138:** the freestanding suite's windowed ABI check tells literal pools by section name; both Xtensa start-ups write the window registers through a2. **SL-1145:** the per-patch gate runs the freestanding runner's own unit test.
- **SL-1142:** the Vim/Neovim syntax plugins follow the current grammar.
- If merged before the tag: **SL-1092 U3** (`blade add` and `blade new` write names and values as valid TOML) and **U4** (`libs/toml` reads all of TOML 1.0: multi-line strings, floats, date-times).

**Known, not fixed in v0.24.3:** SL-1012 (type aliases are transparent; the design and the owner's rulings are done, units follow; constructing through an alias of a generic instance drops the alias's type arguments, SL-1147); SL-1150 (`Task.spawn` freestanding); SL-1146 (a windowed Xtensa frame over 32,760 bytes uses `movsp`); SL-1123, SL-1140.

**For a project moving its pin from v0.24.2** (sawos): the freestanding entry (a package that declares a `main` now gets the entry rule; sawos has none freestanding); the stricter non-escaping rule (a non-escaping function value in a tuple, an array, a `move`, or a closure's result is refused, never miscompiled); one rebuild of every package (a new `--build-id`).

**Landing:** `git rev-parse v0.24.3^{commit}`; check each merge above is an ancestor (SL-1137's merge, SL-1143 6b36fd3be, SL-1129 U3 f8fe41349, SL-1108 f524c064e, SL-1126 U2 f41fbbe8b, SL-1139 5ebe13afc, SL-1083 2a0983d2b, SL-1138 73ee2b67e, SL-1145 f277d0de2, SL-1142 33fe7b298); post the version and sha to the sawos lead.
