**sawc2's typecheck treats a declared getitem as a place accessor where its value is only borrowed** (found by std1, SL-597).

Probe (`.build/scratch/probe_getitem.saw` in the std1 worktree): a `Table` declaring a getitem `func [](&self, key: Int) -> Int` and no place accessor.

```
let a = t[1]          // accepted
let b = take(t[2])    // accepted: a by-value argument
let c = t[3] == 4     // subscript.role: "used as a place accessor"
let d = "{t[4]}"      // subscript.role
print(t[5])           // subscript.role
print("{}", t[6])     // subscript.role
```

**Mechanism.** Each refused position reads its operand by borrow (`TcUse.Borrow`): a comparison operand, an interpolation hole, `print`'s argument and a format argument. `settle_subscript` takes a borrow-read subscript as a place use and refuses it, because a declared getitem lends nothing. The spec says a plain subscript is a getitem "wherever it is read" (Subscripts), and `check_plain_subscript_reads` already lists these positions as reads.

**Fix:** a borrow-read of a plain subscript whose type declares a getitem calls the getitem into a temporary and borrows that. Pins: the four positions above. This bites any user type with a declared getitem. The new std declares none yet (the std profile cannot parse one, SL-600).
