## Description

**Type identity of symbolic const expressions: `[Int; K + 1 + 1]` and `[Int; K + 2]` should be one type.** Raised by SL-457's U4 design (identity is by spelling today). The project owner (Nov 14, typed): "my initial feeling is they should be the same type if the value is the same but i don't fee strongly about it either way."

**Where it bites.** Only inside generic bodies and signatures, where a length is still symbolic; at a concrete instance both sides fold to one number and are one type already.
- `grow<const N: Int>(z: Z<N>) -> Z<N + 1>` called twice gives `Z<K + 1 + 1>`; `let y: Z<K + 2> = grow(grow(x))` is a type mismatch, so the author spells the annotation as the calls spell it or wraps the calls in a function whose return type states `Z<N + 2>`.
- `concat(a: [T; A], b: [T; B]) -> [T; A + B]` nested: `[T; A + B + C]` against `[T; A + (B + C)]` or `[T; C + A + B]`.
- `[UInt8; H + P]` against `[UInt8; P + H]`.

**Proposed scope (lead; to be designed before it is built).** One canonical form for the linear part: sums, differences and multiplication by a constant over const parameters (a sum of terms, each a parameter with an integer coefficient, plus a constant). Two expressions with the same canonical form are the same type. Division, remainder, shifts, bit operators and a product of two parameters stay compared by spelling: equal-looking forms there can differ in where they overflow or divide by zero.

**To settle in the design.**
- `K + 1 - 1` normalizes to `K`, so an instance at which the spelled form overflows would no longer fault. Is the fault part of the type's meaning (keep the spelled form's faults by checking them at the instance as today, and normalize only for identity), or does the canonical form decide?
- What a diagnostic prints: the spelling the author wrote, or the canonical one.
- Mangling: two spellings of one type must be one instance.
- What exists already: `compiler/typecheck/src/arith.saw` has a `tc_arith_normalize`; find what it does today before designing.

Low priority. Related: SL-457 (closed), the unit for const values past the target's `Int`.
