## Description

**An enum case cast whose raw value doesn't fit the target builds and panics at run time; Stage 0 refuses it at compile time** (SL-722's sweep, `SL:float-backend` §6): `Wide.Big as UInt8` for a case valued 300. A constant cast that must fail is a compile error, as constant folding elsewhere makes it. Fix: fold a case cast in typecheck/eval and refuse an out-of-range result at the cast.
