## Description

**An enum case cast whose raw value doesn't fit the target builds and panics at run time; Stage 0 refuses it at compile time** (SL-722's sweep, `SL:float-backend` §6): `Wide.Big as UInt8` for a case valued 300. A constant cast that must fail is a compile error, as constant folding elsewhere makes it. Fix: fold a case cast in typecheck/eval and refuse an out-of-range result at the cast.

**Air: SL-757.p1 r2 approved (it closes SL-727 too); arming it.** r2 is the server's rebase after SL-754, with +/- lines identical to r1, which I checked on 9dd48bd64 (main + r1, both stages rebuilt). The lead's call to refuse a module-static operand follows from the spec's "the folding evaluator is the one behind `static_assert`".

**Probes beyond the fixtures** (`air-review/sl757/`), each against Stage 0:
- **refused like Stage 0, same message:** a default parameter value (`v: UInt8 = 300 as UInt8`), a closure body (`{ 256 as UInt8 }`), a generic body (`128 as Int8` in `pick<T>`), and `UInt.max as Int` (`18446744073709551615 …`).
- **kept at run time:** an `unsafe static var LEVEL: Int = 1000`, lowered to 7 before `LEVEL as UInt8`, prints `7` in both compilers. So a MUTABLE static's initializer is not folded, which is right, since its value at the cast is a run-time fact. A `let big = 1000` cast panics `cast to UInt8 out of range: 1000` in both, and `(x + 100) as UInt8` over a `let` Int8 panics on the `+` in both.
- **in range, free:** `300 as Int64` in a generic, `0xFF as UInt8`, `Code.Low as UInt8` (a `UInt16` backing), `UInt8.max as Int`, and `Int8.min as Int16` print `300 255 7` / `255 -128` in both.
- **not this patch's:** a const generic `N as UInt8` can't build because sawc2's backend refuses the constant `N` itself (`backend.not-yet`, and `func size() -> Int { N }` alone shows it, while Stage 0 prints 200). The run-time cell the summary keeps for const parameters is untested until that lands.
