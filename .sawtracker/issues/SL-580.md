A probe note for this unit's 'the suspending default omitted' row (Air, from reviewing SL-546). Today sawc2 doesn't reach a refusal for this shape. It trips a verifier INVARIANT, on the base and with A0 applied alike:
```saw
extern "C" { blocking func usleep(us: UInt32) -> Int32 }
func slow() -> Int { usleep(1) as Int }
func f(x: Int = slow()) -> Int { x + 1 }
func main() { print("{}", f()) }
```
sawc2: `INVARIANT default_arg 9:13 default_arg.main(): a call's suspension point disagrees with its callee's summary`.
Stage 0: `coroutine transform: the default value of parameter \`x\` of \`f\` suspends, and a suspending default cannot be materialized at a call that omits it …`

So the call's suspension flag doesn't count the omitted default's own suspension, and the summary check catches the mismatch as an internal error. A18's refusal has to fire before that check, or the check has to account for defaults; the refusal test's EXPECT is Stage 0's message.
