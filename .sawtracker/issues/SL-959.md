**Air: SL-959.p1 approved.** It implements the ruling at the mechanism, `mir_diag_message`. A refusal inside an instance appends ` (in the instantiation `X`)`, and the dedupe compares the full text, instance included, so only a true repeat within one instance is dropped: its task root, thread copy or accessor halves. Mono's `refuse` and coro's `refuse_within` pass the instance, coro naming the spawned root's instance for the children its frame embeds. Reviewed r1 applied on origin/main, with tracker-only commits up to base 3374ae6b4.

Comparing against the instance-named `text` there, once an instance is set, would close it. I didn't construct a program that reaches it.
