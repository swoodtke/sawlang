## Description

**sawc2 accepts a silent copy of `Self.Item` in a trait default body, and the MIR drops the value once per copy plus once for the original.** Found reviewing SL-453.p1, which names this as a pre-existing gap. Stage 0 refuses the same program.

**Repro** (`.build/scratch/air-review/sl453/probes/a4c_item_copy_policy_deinit.saw` on the Air):

```saw
struct Token { id: Int }
extension Token: NoCopy {
    func deinit(&var self) { print(self.id) }
}
trait Source {
    type Item
    func make(&self) -> Item
    func dup(&self) -> Int {
        let v = self.make()
        let a = v
        let b = v
        2
    }
}
struct Maker { n: Int }
extension Maker: Source {
    type Item = Token
    func make(&self) -> Token { Token(id: self.n) }
}
func main() { print(Maker(n: 5).dup()) }
```

- **sawc2** (`mir --check`, with SL-453.p1) accepts it. `Source.dup` lowers once, generically:
  `_5 = copy _2; _6 = copy _2; … drop(_6); drop(_5); drop(_2)`. Instantiated at `Token`, that is three `deinit`s of one value.
- **Stage 0** refuses both copies: "cannot copy value of type `Token` which implements NoCopy", twice. It checks the default body per conformer.

**Mechanism:** a trait's own associated type (`Self.Item`, or bare `Item` in the trait body) gets a copy policy that permits a silent copy. Nothing in the slice states its policy, so the only sound reading is the one SL-453 gives `T.Item`: NoCopy, meeting no bound.

**Likely fix:** treat a trait's own associated type as the projection on `Self`, with the same NoCopy reading. The body then writes `move v` or borrows, as a generic body does for `T.Item`. Pin: a refusal fixture with this repro (`transfer.implicit-copy` at both copies), plus an accepted golden using `move`.

**Sweep owed (obligation 4):** the other places a trait body reads an associated-type value by value:
- a default body's `return v` / tail with `v` read twice;
- passing `v` to two calls;
- a field of type `Self.Item` in a conformer's default helper;
- a closure capturing `v`.

**Ordering:** it must land before any backend lowers default bodies from this MIR.
