**Found by:** std496 (SL-496). **Area:** the new std (`std/`).

`Box.value` is an unconditional `(&var self) unsafe borrows -> &var T` lend with no shared twin. D9 (SL:open-questions) says a std accessor whose body only reads gets a shared twin, which is `@synthesize(shared)` now that sawc2 implements it. Without one, a `borrow let b.value` through a `&Box<T>` can't be written.

**Owed:**
- Add `@synthesize(shared)` to `Box.value`.
- Sweep the rest of `std/` for an exclusive accessor that has no twin and whose body only reads.
- Pin a shared `borrow` through `&Box<T>`.
