## Description

**An array literal is accepted for an array whose length is a const parameter, whatever the parameter's value: safe code reads uninitialized stack.** Found by SL-457's U4 detail pass (Nov 14; `.build/scratch/p457u4/lit.tsv`, `cells_lit/`), older than SL-457 (the same on main). Reproduced by the lead on main's compiler (`.build/scratch/p457u4/lead_lit_read.saw`).

```saw
func f<const N: Int>() -> Int {
    let a: [Int; N] = [1, 2]
    a[N - 1]
}
```

`f<5>()` builds. `a.len()` is 5, the literal wrote two elements, and `a[4]` passes its bounds check and reads whatever the stack held: with a call before it that filled an array with `0x5A5A5A5A`, the program prints `1515870810` at `-O0`. No `unsafe`, no diagnostic.

**Every position the pass tried accepts it** (`lit.tsv`): an annotation, a return (`-> [Int; N]` returning `[1, 2]`), an argument, a field's initializer, an assignment: each prints 5 at `f<5>()`. An empty literal for `[Int; N]` prints 3 at N = 3.

**Mechanism (by the pass's reading of `compiler/typecheck/src/bodies.saw`, `array_expr`):** a list literal checked against an expected array type compares its element count with the length only when the length is a known integer (`ConstInt`); a length that is a const parameter is accepted without a check, and the literal takes the expected type.

**The fix the detail gives (its unit U4a0, independent of the rest of SL-457):** where the expected array's length is not a known integer, the literal is refused: `type.mismatch`, "this array literal has 2 elements, and `[Int; N]` holds `N`, a length fixed only at each instantiation: write a repeat literal (`[v; …]`) to fill it". Inference in the other direction (`f([1, 2, 3])` binding `N` from the literal's own length) is untouched.

**Sweep before the fix (obligation 4):** every construct that takes its element count from the source and is checked against a length: a list literal in each position above and in a `match` arm, a nested literal (`[[1, 2], [3]]` against `[[Int; N]; 2]`), a string or byte-string literal against `[UInt8; N]` if the language allows it, a tuple against a parameter-length array, a collection literal for `Vector`/`Set`/`Map` (not sized by a length: confirm), and a pattern `[a, b]` matched against `[Int; N]` (does it destructure past the end?).
