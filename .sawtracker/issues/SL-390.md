## Description

Found by the SL-2 U0′ r3 implementer (Sep 24); the lead re-measured it on main (`.build/scratch/ref_depth.py` in the lead checkout).

The no-reference-in-a-field refusal stops looking after 12 levels of type nesting. The type is `(…((&Int, Int), Int)…, Int)`, wrapped N times, as a struct field:

| N | result |
|---|---|
| 1, 11, 12 | refused: "field `slot` of `Holder` may not be a reference" |
| 13, 14, 20 | COMPILES (exit 0) |

A struct that stores a reference escapes the rule that keeps references from outliving their frame. That is a soundness hole: a dangling pointer from safe code.

Mechanism (named by the implementer; verify): `first_reference_in` in `sawc/noescape.py` returns `None` once `depth > _MAX_ALIAS_DEPTH` (12). The bound exists to stop an alias CYCLE, but `depth` counts every level of type nesting, not only alias hops. So a deep but acyclic type reads as "no reference".

Positions to sweep (obligation 4): the same walk backs every no-escape check, and the typechecker's alias-aware twin shares it. Cover:
- struct fields;
- enum payloads;
- function return types;
- generic arguments (`Vector<(…(&T…)…)>`);
- closure and function types;
- `static` types;
- an alias chain deeper than 12 and an alias cycle (the refusal the bound was written for).

The fix bounds alias hops by their own cycle detection, for example a visited set of alias names. It does not bound structural depth at all, because a type's depth is bounded by its source and SL-2's depth funnel already caps that at 256.

## Where each position stops being refused on main (ebf67de3)
The shape is `(…(&Int, Int)…, Int)`, wrapped N times.
- Field, enum payload, return type, function type in a field: refused at N=12. N=13 through 32 COMPILE. N≥33 is refused only by #5's depth message.
- Generic argument and `static`: the reference refusal is missing from N=13 up. A static of this shape is still refused by the initializer and Sync rules.
- Alias chain: refused at 12 links; 13 and 20 links compile.
- **Alias CYCLES are not refused cleanly.** `type A = A`, A/B mutual cycles, `A = A?`, `A = (A, Int)` and a cycle used as a local's type all end in an ICE: maximum recursion depth, from `copy_tier`, `_send_sync` and `_get_underlying_type`. A cycle nobody uses gives a raw traceback. `A = Vector<A>`, `Box<A>` and `() -> A` are refused only by accident, through #5.
- A deep type with NO reference compiles at 12, 13 and 20, and is wrongly refused at N≥33 (28 errors at 40).
- Borrowing structs: the alias-chain producer is wrongly refused at 13+. A `borrows struct` field through a 12-link chain fails with "expects R11" (registration resolves one alias hop only).
