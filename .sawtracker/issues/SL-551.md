- **Scope:** before Stage 0 retires (SL-539, the seed), record for each of §3.2's 490 programs:
  - Stage 0's stdout and exit status;
  - its frame sizes from `--emit-frame-layout`;
  - its backtrace table's frame and state counts.

  These go in `compiler/tests/coro/stage0/`, as a TSV and per-program expectations. The run lane keeps comparing against live Stage 0 while it exists, and falls back to the snapshot after.

  **Settled with the Air (t9):**
  - **Each row records its target triple.** Frame sizes and backtrace offsets depend on pointer width and alignment, and SL-536 brings Linux and an x86_64 cross target. B4 compares only rows of the same triple.

On the a0b report's plan finding (Air). Both real pins have substitutes that need no std port, so the units keep their shapes:
- **A6, collection `for` with a borrowing iterator (K149):** the shape is the lowering, not `Vector` or `Map`. The spec's own example iterates a user type: `for borrow var c in grid.cells()`, through `LendingIterator` (`func next(&var self) borrows -> &var Item?`, LANGUAGE_SPEC around its 'Two iterator traits' paragraph). The new `std/prelude.saw` declares `Iterator` but NOT `LendingIterator`. So A6 adds that trait to the prelude (a declaration of a few lines, not a port) and pins the row with a user-defined collection plus borrowing iterator, a suspension inside the loop body, and the window record resident across it. K149 itself then moves to the `Vector.iter`/`Map` port's issue as a gated program.
- **A12b, the io-budget fairness pin (`net_budget_fairness`):** the program needs `Arc<Mutex<…>>` only for a shared counter. A `static HITS: Atomic<Int>` does the same under the new std (accepted, per SL-537's pins). Rewrite the pin's counter that way and A12b keeps a 89-c fairness pin with nothing gated.
- **`coro_discarded_tail_move_cross_module`** is not a unit pin. It's the evidence §3.1 cites (my t3) that `__saw_drive_steps` runs to completion, so nothing moves.

On the file-list contradiction: A0b's done-when needs `run.py` and its file list excludes it, and the hook is 68 lines of lane wiring. Landing it with A0b keeps 'the census runs in run.py' true at A0b's own close.
