## Description

**Unit 8 of SL-661: rename sawc2 to `sawc`.**

Once `sawc/` is gone (unit 6), the self-hosted compiler takes the name, so the resolver's public names reach it with no consumer change.

**What it covers:**
- the binary (`.build/sawc2`, `sawc2-stage2`, `sawc2-runtime.txt`), and `build.py`'s outputs and stage names;
- the driver's usage text;
- `bin/sawc` and `make install`;
- the env knobs (`SAWC2_CLANG` and any other `SAWC2_*`);
- `tools/linux.py`, the lanes, the docs, the skills and the tracker docs (SL:architecture, SL:coroutines, SL:hazards);
- the package names, if any carry `2`.

**Owed:**
- **The consumer sweep (obligation 2):** every `sawc2` string in tracked files, renamed or explicitly kept with a reason. History in designs/ and done files stays.
- **A compatibility shim**, only if a consumer needs one, with a removal date.
- **A version bump:** the first release with sawc2 as `sawc` gets a version and a tag (`.sawtracker/version` next to the version constant), so a consumer's pin can name it.

**Depends on:** units 6 and 7.
