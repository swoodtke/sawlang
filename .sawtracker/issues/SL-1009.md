Found by the SL-1005 spec review (F15).

LANGUAGE_SPEC "Data" documents:
- `iter()`, whose elements are `Byte`s;
- "Iterating holds a retain: `iter()` returns a `DataIterator` that owns a `Data`".

In sawc:
- `member.unknown`: `std.data.Data` has no method `iter`;
- `DataIterator` is undefined;
- `for b in d` is refused, since the type has no `next` that hands out an Optional.

`grep DataIterator std/` finds nothing.
