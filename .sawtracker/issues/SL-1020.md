Found by the SL-1016 spec review. Each is refused correctly, but the message lacks what LANGUAGE_SPEC promises the reader:
- **F7, a tuple holding a NoCopy element:** `.copy()` is refused naming the tuple type, not the offending element "by position and type".
- **F8, a refused optional transfer:** it names `.copy()` and `move`, but not `.take()`, the third way out the spec lists.
- **F11, `(move h.res).close()` on a field:** transfer.partial-move doesn't name `h.res.take()`.
- **F13, `consumes` together with `borrows`:** this gets loan.move-while-borrowed instead of a clean error naming the exclusion. Every other `consumes` boundary is clean.
- **F16, assigning into `&var any Trait`:** this gets a plain type.mismatch or transfer.implicit-copy, with no pointer to the `Box<any Trait>` level.
