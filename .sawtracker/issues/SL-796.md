## Description

**`File.close` drops close(2)'s errno: it raises `SystemErrorKind.Unknown` with no code** (the Air, SL-785.p1 review; probe `air-review/sl785p/k1_close_ebadf.saw`). `std/file.saw`'s `close` returns `SystemError.raised("close", SystemErrorKind.Unknown)` when close(2) fails, so an EBADF prints `close failed (other error)`, with neither SL-785's `InvalidDescriptor` nor the errno that `Unknown` now names. Never hide errors.

**Obligation 4, a class:** the mechanism is "a std site calls a libc or seam operation that fails with an errno, then raises a fixed kind with `SystemError.raised` instead of classifying" (`SystemError.of(op, tag)` from a status-returning seam). Sweep every `SystemError.raised(` (and `IoError`'s equivalent) in `std/`. For each, say whether a failing OS call precedes it (then it must classify, routed through a status-returning seam if the call is bare libc) or whether it's a std-raised condition with no errno (then it stays). A bare libc `close` may need a `__saw_rt_fs_close -> 0/-tag` seam, which is an ABI addition (both runtime trees, `runtime_table`).

**Pins:** k1's shape reads `close failed (invalid descriptor)`, plus one pin per other site the sweep fixes. Small; Sonnet-suitable once the sweep says whether a seam is needed.
