U6d1's conformance census (chat m347), confirmed by the lead on main 188e4307: sawc2 refuses none of the 'References are parameters only' rows. A reference return type, a reference field, a reference-typed binding, a tuple element and a type argument are all accepted (`func keep(r: &Int) -> &Int { r }` passes typecheck and mir). Stage 0 refuses them in the parser (sawc/parser/types.py) and the typechecker (typechecker/types.py and expressions.py, the 'PARAMETERS ONLY' diagnostics). borrowing.containment covers only borrowing structs. This is a soundness hole: SL:architecture §3.6's 'never looks outside the function' assumes it. Per obligation 1 the rule is a funnel or a matrix. Every position a TYPE is written or inferred gets a row: return type, field, local and static binding, tuple element, type argument (`Vector<&Int>`), Optional payload, closure return, an inferred binding from a reference-producing expression, and a generic instantiated at a reference. Each row is refused, or allowed with its reason: the conditional lend `borrows -> &T?` and lend windows (SL:borrowing), parameters, and borrowing-struct fields under containment. One typecheck rule id (`type.reference-position` or similar) with a fixture per row, plus the conformance rows R01-R34 mapped in compiler/tests/borrowck/CONFORMANCE.md. Typecheck is U5b2's area until it lands, so this is scheduled after U5b2, beside SL-459's typecheck half.
