**Found by SL-681's sweep (n681nomove).** A `match` on an owned NoCopy local whose arm is a plain binding pattern (`case q ->`, binding the whole scrutinee) fails the MIR verifier: an internal error, not a diagnostic. Stage 0 builds and runs the program.

**Repro** (`sawc2 mir --check --std-root std`, sawc2 at main 2ffb3ad2f):

```saw
struct Res { id: Int }
extension Res: NoCopy {}

func main() {
    let p = Res(id: 5)
    match p {
        case q -> print("arm sees {}", q.id)
    }
}
```

gives

```
INVARIANT	c05b_match_nocopy_struct	27:13 c05b_match_nocopy_struct.main(): owned local _3 may still be live at a `return` in bb1: a scope exit does not drop it
```

at `q` (the line numbers are the probe's, which had a longer prelude). `typecheck --check` is clean; `mir`, `borrowck` and `drops --check` all report the same invariant, so it is the MIR stage's. Stage 0 prints `arm sees 5`. With `case _ ->` instead of `case q ->` sawc2 builds and runs it.

**Mechanism, UNVERIFIED:** typecheck gives the owned scrutinee origin `Owned` (`scrutinee_origin`), so the binding `q` takes the whole moved value (`bind_part`, `TcUse.Move`); MIR's lowering of a binding arm over a consumed scrutinee then holds the value in a local that no scope exit drops. What would confirm it: `sawc2 mir --dump` of the repro, read for the local `_3`'s scope and the arm's drop list, beside the same dump for `case Has(q)` on an enum, which works.

**Sweep owed (obligation 4):** a binding arm over an owned struct, enum, tuple and optional local; with a guard; in a value `match`; in a driven body.
