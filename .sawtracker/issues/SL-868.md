## Description

**An accessor with two `lend` sites, each through its own window, trips a MIR INVARIANT ("window may still be open at a return")** (found by p861, SL-861 step 1, Oct 23; repro `scratchpad/p861/extra2/x1c_two_sites_vectors.saw`; it predates SL-861).

```saw
func pick(&var self, first: Bool, i: Int) borrows -> &var Int {
    if first { lend self.a[i] } else { lend self.b[i] }
}
```
The MIR verifier reports "window w0/w1 may still be open at a `return`" in the epilogue, and since SL-844 the command exits 1. It happens with no inner local; a branch choosing which of two places to lend is ordinary accessor code.

**Mechanism (UNVERIFIED):** each `lend` site opens its own window (`self.a[i]` through `Vector.[]`), and the epilogue's close covers only one of them, or closes both without knowing which path opened which.

**Obligation 4:** lend sites {2, 3} × how they're chosen {`if`/`else`, `match`, early `return` of one} × each site's place {a field, a `Vector.[]` place, a forwarded accessor} × the accessor {plain, conditional `-> &T?`} × the caller {sync, suspending}. Each cell runs with the right epilogue on the taken path only, with `// leaks: none`.
