## Description

**sawc2 accepts the wrapping operators `&+ &- &*` on Float; the spec and Stage 0 refuse them** (found by SL-722's planning sweep, `SL:float-backend` §6). The Float printing gap hides it today; once Float prints, `wrapping_requires_integers` reads "accepts a refusal test". Fix: typecheck refuses a wrapping operator whose operands aren't integers, with its own rule. Obligation 4: every integer-only operator (`<<`, `>>`, `&`, `|`, `^`, `~`, `%`?) per the spec.
