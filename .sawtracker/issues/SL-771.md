## Description

**`compiler/tools/std_cone.py` reads symbol names inside LLVM string constants as edges** (the Air, SL-573 c8).

sawc2's backend emits IR as text, so the compiler binary's own `.ll` contains string constants such as `c"... call i64 @__saw_rt_offload_start(..."` (`compiler/llvm/src/calls.saw`). `graph`'s `_SYMBOL_REF.finditer` matches `@__saw_rt_offload_start` inside the constant, and because the linked runtime really defines that symbol, the edge is kept. SL-573 recorded the result in `compiler/tools/std_cone.txt`: all of `rt.common.offload` and `rt.common.pthread`, 14 runtime declarations, plus `__saw_rt_thread_spawn`/`pthread_join` as external symbols. That says the compiler reaches thread spawn, which it doesn't.

**Fix:** remove the `c"..."` spans from the text before the symbol scan, then rewrite `std_cone.txt` with `--write` and list the lines removed. That ends it for every seam name the backend spells. A small, mechanical unit.
