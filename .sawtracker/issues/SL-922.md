Found by p920's SL-920 survey (Q8b); reproduced by the lead on main.

**A negative array length is accepted as a type.** `let a: [UInt8; 2 - 3] = []` is refused only incidentally, by `type.mismatch` ("this array literal has 0 elements, and `[UInt8; -1]` holds -1"). The type `[UInt8; -1]` itself is accepted, where the spec makes a negative length an error at the type.

Repro: `.build/scratch/probe_neg_len.saw`.

The fix belongs where a length folds: one check, shared by array types, repeat counts and const-generic `Int` arguments used as lengths, with a fixture per position. It's natural to do it with SL-920's static-constant funnel, or right after it.
