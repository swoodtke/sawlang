Submitted patch SL-257.p1 (revision 1): minivm M14: local StringBuilder, snapshots and fallible append

Adds the lexer subset of StringBuilder to the Saw-written compiler, VM and textual LLVM emitter. Local builders append String/Byte/Int/Scalar, produce independent String snapshots and forward through shared/mutable references. Append returns Result<Void, AllocError>; allocation failure preserves content and snapshots.

Builders remain local, noncopyable values: by-value APIs, aggregate storage, assignment and general move analysis are deferred. The verifier checks builder references, operation layouts and nominal AllocError metadata. Native append uses a private recoverable allocator; the VM documents its host-allocation limits. Internal one-shot failure injection is available only to contract tests.

Validation:
- Full prototype harness: 394 cases, VM and native O0/O2.
- Builder differential: 14 cases agree with Python sawc.
- Unchanged lexer char_str and escape_text extracts.
- Independent 51-code-point UTF-8/snapshot oracle: VM, native O0/O2/ASan and Python sawc.
- Verifier contract plus identical VM/native failure, recovery, empty-append, forwarding and inactive-drop contracts.
- Source-level propagated append failure and subsequent recovery, including an untaken builder branch.
- Citation and whitespace checks.

Python's nested implicit receiver exclusivity gap is filed as SL-284; this implementation enforces the documented rule. Intentional prototype restrictions are excluded from shared-subset comparisons.

Based on the merged M13 Scalar implementation in SL-255.p2 (cbd32918). This diff contains only M14 changes. Rebasing onto main changed only tracker metadata; the validated source tree is identical.
