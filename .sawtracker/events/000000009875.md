Terms\n\n- **Executor record** (`ExecutorRecord`): one per thread that drives tasks. Therefore, across any call that\ncan run user code (a resume; a result's drop; any join, teardown, drive or\nthread-context wait), the executor keeps no group address, slot index, cell\npointer or frame pointer in a local, unless:\n\n1. **it is pinned for the whole call**: the slot is `active` on this thread\n   (the teardown refuses, K200), the thing lives in a frame on this thread's\n   stack, or it is the group of a handle the caller holds (the borrow rules and\n   the outstanding check); or\n2. **it is kept where invalidation reaches it**: in a walk cursor, which the\n   unlink funnel (`TaskGroup.unregister` → `move_walks_past`) moves; or in a\n   sleep-queue entry, read only after the `regroups`/`seen` rebuild check and\n   through `SleepEntry.live`.\n\nA reader checks a new line against it by asking: does this read follow a call\nthat can run user code, and if so, which of (1) or (2) covers the name?\n\n## 5. In prose:\n\n1. `ExecutorRecord` gains `walks: Int` (after `regroups`), the address of the\n   innermost open sweep's `WalkCursor`, 0 with none; `claim_record` builds it 0.\n2. New `struct WalkCursor { group: Int, slot: Int, outer: Int }` and\n   `static WALK_ENTER: Int = -2`, beside `sweep_passes`.\n3. `sweep` builds a `WalkCursor(group: 0, slot: WALK_ENTER, outer:\n   record[0].walks)` in its own frame, stores its address in `record[0].walks`,\n   passes it to `sweep_passes`, and restores `record[0].walks = cursor.outer`\n   after. (A panic aborts, so no unwinding path needs the restore.)\n4. `sweep_passes` takes `cursor: UnsafePointer<WalkCursor>`. At each pass it\n   sets `cursor[0].group` to the list head and `slot` to `WALK_ENTER`, and loops\n   while `cursor[0].group != 0`: `g` from the cursor, `i` from `next_live(0)`\n   (cooperative) or -1 (pool), `moved = false`, and the slot loop runs\n   `while i >= 0 && not moved`. Before `resume_queued` it stores\n   `cursor[0].slot = i`. After `sweep_finished`: if `cursor[0].slot != i` the\n   unlink moved it, so `moved = true` and `g` is never read again; else if the\n   turn was `(g, i)` itself, `i = g[0].next_live(i + 1)`; else (a hand-off) the\n   walk stays. New `move_walks_past(record, me, after_me)`: for every cursor on\n   `record[0].walks`'s chain whose `group == me`, set `group = after_me`,\n   `slot = WALK_ENTER`. Its comment is the funnel (THE WALK RULE, ENTRY POINTS:\n   `TaskGroup.unregister`).\n7. `resume_slot` returns `Bool`: true exactly when the frame reported `Pending`\n   with a timer park (set beside `take_sleep_order`), false on its early return\n   and otherwise. `resume_queued` calls `timer_parked(g, slot)` and notes the\n   entry only when it answered true.
